08. The FFT/

Cooley and Tukey (1965) — and Gauss around 1805 — noticed that an N-point DFT is two N/2-point DFTs plus N/2 multiplications. Repeat until the pieces have one sample.

X[k] = E[k] + WNkO[k] and X[k+N/2] = E[k] − WNkO[k]: one multiplication serves two outputs.
  • Why O(N²) is a bottleneck
  • Decimation in time: even/odd split
  • The identity WN² = WN/2
  • Half-period symmetry Wk+N/2 = −Wk
  • The recursion T(N) = 2T(N/2) + N/2

BASICThe complexity challenge

A strain record of N = 2²⁰ ≈ 10⁶ samples (64 s at 16 384 Hz) costs N² ≈ 10¹² complex multiplications by direct DFT, against ≈ 10⁷ for the FFT. Repeated over many templates, channels or antennas, O(N²) is prohibitive.

COREDecimation in time

Take N = 2q. Split the samples by index parity: e[m] = x[2m], o[m] = x[2m+1], m = 0 … N/2−1; let E[k], O[k] be their N/2-point DFTs.

  1. Split the DFT sum: \(X[k]=\sum_m x[2m]W_N^{2mk}+\sum_m x[2m+1]W_N^{(2m+1)k}=\sum_m e[m](W_N^2)^{km}+W_N^k\sum_m o[m](W_N^2)^{km}\).
  2. Twiddle reduction: \(W_N^2=e^{-j2\pi\cdot2/N}=e^{-j2\pi/(N/2)}=W_{N/2}\). The two sums are N/2-point DFTs: \(X[k]=E[k]+W_N^kO[k]\).
  3. E, O have period N/2 in k, and \(W_N^{k+N/2}=-W_N^k\): the second half of the outputs needs no new products.
ALGORITHMRadix-2 recombination (butterfly)hover the symbols ↓
\h{Xk}{X[k]}=\h{Ek}{E[k]}+\h{WN}{W_N^k}\,\h{Ok}{O[k]},\qquad \h{Xk}{X\big[k+\tfrac N2\big]}=\h{Ek}{E[k]}-\h{WN}{W_N^k}\,\h{Ok}{O[k]},\qquad k=0,\dots,\tfrac N2-1
def fft_recursive(x):
    N = len(x)
    if N <= 1: return x.astype(complex)
    E, O = fft_recursive(x[0::2]), fft_recursive(x[1::2])
    t = np.exp(-2j*np.pi*np.arange(N//2)/N) * O
    return np.concatenate([E + t, E - t])
! recursion is possible (recursive subroutine), but the in-place iterative
! version of fft_radix2.f90 is what libraries do
t = w(j)*a(k+j+half+1);  u = a(k+j+1)
a(k+j+1) = u + t;        a(k+j+half+1) = u - t

Each butterfly takes two numbers, multiplies one by a twiddle, and writes the sum and the difference back into the same two slots.

Step through the stages above: the pairs are 1, 2, 4 … apart.

Dealing the samples by their least significant bit first puts index n at position rev(n): read the bits backwards.

Each radix-2 step deals the samples into even and odd piles (by the lowest bit), the next step by the next bit, and so on. To work in place every sub-transform must occupy a contiguous block: the last-dealt bit becomes the most significant bit of the position.

ALGORITHMBit-reversal table in O(N)hover the symbols ↓
\mathrm{rev}[i]=\big(\mathrm{rev}[i\gg1]\gg1\big)\ \big|\ \big((i\ \&\ 1)\ll(q-1)\big)
rev = np.zeros(N, int)
for i in range(1, N):
    rev[i] = (rev[i >> 1] >> 1) | ((i & 1) << (q - 1))
rev(i) = ior(ishft(rev(ishft(i, -1)), -1), ishft(iand(i, 1), q - 1))

COREThe iterative in-place FFT

  1. Permute x[n] ↔ x[rev(n)].
  2. For s = 1 … log₂N: block size m = 2s, twiddles Wmj (a precomputed table is more accurate than the running product w ← w·Wm).
  3. For every block start k = 0, m, 2m, …: for j = 0 … m/2−1, t = Wmj x[k+j+m/2], u = x[k+j]; x[k+j] = u + t, x[k+j+m/2] = u − t.
def fft_iterative(x):
    x = np.asarray(x, complex)[bit_reverse_table(len(x))]
    m = 2
    while m <= len(x):
        w_m = np.exp(-2j*np.pi*np.arange(m//2)/m)
        for k in range(0, len(x), m):
            t = w_m * x[k+m//2:k+m]; u = x[k:k+m//2].copy()
            x[k:k+m//2], x[k+m//2:k+m] = u + t, u - t
        m *= 2
    return x
m = 2
do while (m <= npts)

! fftw_demo.f90  --  Lecture 8: calling FFTW from modern Fortran (plan, execute, destroy)
! Build:  gfortran fftw_demo.f90 -I/usr/include -lfftw3 -lm -o fftw_demo && ./fftw_demo
! (Windows: MSYS2 package mingw-w64-ucrt-x86_64-fftw; Linux: libfftw3-dev)
program fftw_demo
  use, intrinsic :: iso_c_binding
  implicit none
  include 'fftw3.f03'
  integer(C_INT), parameter :: n = 1024
  real(C_DOUBLE), parameter :: pi = 4*atan(1.0_C_DOUBLE)
  type(C_PTR) :: plan, plan_back, plan_r2c
  complex(C_DOUBLE_COMPLEX) :: x(n), xk(n), xb(n), ck(n/2+1)
  real(C_DOUBLE) :: xr(n)
  integer :: i, kmax(1)

  ! plan first: FFTW_MEASURE would overwrite the arrays (ESTIMATE does not)
  plan      = fftw_plan_dft_1d(n, x, xk, FFTW_FORWARD,  FFTW_ESTIMATE)
  plan_back = fftw_plan_dft_1d(n, xk, xb, FFTW_BACKWARD, FFTW_ESTIMATE)
  plan_r2c  = fftw_plan_dft_r2c_1d(n, xr, ck, FFTW_ESTIMATE)

  do i = 1, n                                   ! pure tone in bin k = 50
     x(i) = cmplx(cos(2*pi*50*(i-1)/n), 0.0_C_DOUBLE, C_DOUBLE_COMPLEX)
  end do
  xr = real(x)
  call fftw_execute_dft(plan, x, xk)            ! reusable for new data
  kmax = maxloc(abs(xk(1:n/2)))
  print '(a, i0, a, f9.3)', 'peak at k = ', kmax(1) - 1, ',  |X| = ', abs(xk(kmax(1)))

  call fftw_execute_dft(plan_back, xk, xb)
  print '(a, es10.2)', 'FFTW is unnormalised: backward(forward(x))/n - x, max = ', maxval(abs(xb/n - x))

  call fftw_execute_dft_r2c(plan_r2c, xr, ck)   ! real input: n/2+1 bins
  print '(a, i0, a, es10.2)', 'r2c gives ', size(ck), ' bins, max |c2c - r2c| = ', maxval(abs(ck - xk(1:n/2+1)))

  call fftw_destroy_plan(plan); call fftw_destroy_plan(plan_back); call fftw_destroy_plan(plan_r2c)
end program fftw_demo
  • Unnormalised: divide the backward transform by N. Sign: FFTW_FORWARD uses e−j2πkn/N.
  • Column-major: for a(n1, n2) call fftw_plan_dft_2d(n2, n1, …) — dimensions reversed.
  • Planning: ESTIMATE is instant; MEASURE times kernels and overwrites the arrays — plan before filling them. Plan once, execute many times.
  • Threads: -fopenmp -lfftw3_omp; distributed memory: fftw3_mpi.

A plane wave cos[2π(ux + vy)] is a pair of points at ±(u, v) in the 2D spectrum. Any image is a sum of such waves.

The 2D kernel factorises: transform every row, then every column. Cost O(M log M) for M = N₁N₂ pixels.

BASIC2D signals

CCD images (FITS), flat-sky CMB patches, and radio interferometers — which measure the 2D transform of the sky directly (the visibilities V(u, v)). The image f(x, y) is sampled on a grid of pitch (X, Y): its spectrum is replicated with periods (1/X, 1/Y) and the Nyquist condition applies along each axis.

CORENotch filtering

  1. Compute F = fft2(f), centre it (fftshift).
  2. Find the spike coordinates (u₀, v₀) in |F|.
  3. Multiply by H = 1 − Gaussian at (u₀, v₀) and at (−u₀, −v₀).
  4. Inverse-transform: fclean = Re F⁻¹{F·H}.
def notch_filter(img, spikes, sigma=2.0):
    F = np.fft.fftshift(np.fft.fft2(img))
    rows, cols = F.shape;  rr, cc = np.ogrid[:rows, :cols]
    H = np.ones(F.shape)
    for r0, c0 in spikes:
        for r, c in ((r0, c0), (rows - r0, cols - c0)):        # conjugate partner
            H *= 1 - np.exp(-((rr - r)**2 + (cc - c)**2) / (2*sigma**2))
    return np.real(np.fft.ifft2(np.fft.ifftshift(F * H)))

# ---------------------------------------------------------------- 1. three FFTs
def fft_recursive(x):
    """Recursive radix-2 decimation in time (N a power of two)."""
    N = len(x)
    if N <= 1:
        return x.astype(complex)
    even = fft_recursive(x[0::2])
    odd = fft_recursive(x[1::2])
    tw = np.exp(-2j * np.pi * np.arange(N // 2) / N) * odd      # W_N^k O[k]
    return np.concatenate([even + tw, even - tw])                # butterflies


def bit_reverse_table(N):
    q = N.bit_length() - 1
    rev = np.zeros(N, dtype=int)
    for i in range(1, N):
        rev[i] = (rev[i >> 1] >> 1) | ((i & 1) << (q - 1))
    return rev


def fft_iterative(x):
    """In-place iterative radix-2 FFT: bit reversal, then log2 N stages of butterflies."""
    x = np.asarray(x, dtype=complex).copy()
    N = len(x)
    assert N & (N - 1) == 0, "N must be a power of two"
    x = x[bit_reverse_table(N)]
    m = 2
    while m <= N:
        w_m = np.exp(-2j * np.pi * np.arange(m // 2) / m)        # precomputed twiddles
        for k in range(0, N, m):
            t = w_m * x[k + m // 2: k + m]
            u = x[k: k + m // 2].copy()
            x[k: k + m // 2] = u + t
            x[k + m // 2: k + m] = u - t
        m *= 2
    return x


def fft_vectorized(x):
    """Vectorised Cooley-Tukey (after J. VanderPlas, 2013)."""
    x = np.asarray(x, dtype=complex)
    N = x.shape[0]
    Nmin = min(N, 2)
    n = np.arange(Nmin)
    X = np.exp(-2j * np.pi * n * n[:, None] / Nmin) @ x.reshape((Nmin, -1))
    while X.shape[0] < N:
        even, odd = X[:, : X.shape[1] // 2], X[:, X.shape[1] // 2:]
        factor = np.exp(-1j * np.pi * np.arange(X.shape[0]) / X.shape[0])[:, None]
        X = np.vstack([even + factor * odd, even - factor * odd])
    return X.ravel()

def notch_filter(img, spikes, sigma=2.0):
    """Gaussian notch at each spike and at its conjugate partner (fftshift-ed indices)."""
    F = np.fft.fftshift(np.fft.fft2(img))
    rows, cols = F.shape
    rr, cc = np.ogrid[:rows, :cols]
    H = np.ones(F.shape)
    for r0, c0 in spikes:
        for r_, c_ in ((r0, c0), (rows - r0, cols - c0)):
            H *= 1.0 - np.exp(-((rr - r_) ** 2 + (cc - c_) ** 2) / (2 * sigma ** 2))
    return np.real(np.fft.ifft2(np.fft.ifftshift(F * H)))

! fft_radix2.f90  --  Lecture 8: an in-place iterative radix-2 FFT from scratch
!   bit-reversal permutation, log2(N) stages of butterflies, precomputed twiddles;
!   checked against the direct DFT, inverse round trip, timing O(N log N) vs O(N^2)
! Compile & run:  gfortran -O2 fft_radix2.f90 -o fft_radix2 && ./fft_radix2
module fft_mod
  implicit none
  integer,  parameter :: dp = kind(1.0d0)
  real(dp), parameter :: pi = 4.0_dp*atan(1.0_dp)
contains
  subroutine fft_inplace(a, sgn)
    ! a(1:npts), npts = 2**q; sgn = -1 forward, +1 inverse (unnormalised)
    complex(dp), intent(inout) :: a(:)
    integer, intent(in) :: sgn
    integer :: npts, q, i, j, m, k, half
    integer, allocatable :: rev(:)
    complex(dp), allocatable :: w(:)
    complex(dp) :: t, u
    npts = size(a)
    q = nint(log(real(npts, dp))/log(2.0_dp))
    if (2**q /= npts) stop 'fft_inplace: N must be a power of two'
    ! 1. bit-reversal table: rev(i) = (rev(i/2)/2) | ((i&1) << (q-1)), 0-based
    allocate(rev(0:npts-1));  rev(0) = 0
    do i = 1, npts - 1
       rev(i) = ior(ishft(rev(ishft(i, -1)), -1), ishft(iand(i, 1), q - 1))
    end do
    do i = 0, npts - 1
       if (i < rev(i)) then                       ! swap each pair once
          t = a(i+1); a(i+1) = a(rev(i)+1); a(rev(i)+1) = t
       end if
    end do
    ! 2. stages: sub-transforms of size m = 2, 4, ..., npts
    m = 2
    do while (m <= npts)
       half = m/2
       allocate(w(0:half-1))
       do j = 0, half - 1                          ! precomputed table: accurate twiddles
          w(j) = exp(cmplx(0.0_dp, sgn*2.0_dp*pi*j/m, dp))
       end do
       do k = 0, npts - 1, m                       ! block start
          do j = 0, half - 1                       ! butterflies of this block
             t = w(j)*a(k + j + half + 1)
             u = a(k + j + 1)
             a(k + j + 1)        = u + t
             a(k + j + half + 1) = u - t
          end do
       end do
       deallocate(w)
       m = 2*m
    end do
  end subroutine fft_inplace
end module fft_mod

program fft_radix2
  use fft_mod
  implicit none
  integer :: npts, j, k, t0, t1, rate, reps, r
  real(dp), allocatable :: re(:)
  complex(dp), allocatable :: a(:), b(:), dft(:)
  real(dp) :: tfft, err

  ! ---- correctness against the direct DFT (N = 256)
  npts = 256
  allocate(re(npts), a(npts), b(npts), dft(npts))
  call random_number(re);  a = cmplx(re - 0.5_dp, 0.0_dp, dp);  b = a
  do k = 0, npts - 1
     dft(k+1) = sum(b*exp(cmplx(0.0_dp, -2.0_dp*pi*real(mod(k*[(j, j = 0, npts-1)], npts), dp)/npts, dp)))
  end do
  call fft_inplace(a, -1)
  print '(a, es10.2)', 'max |FFT - direct DFT|        ', maxval(abs(a - dft))
  call fft_inplace(a, +1);  a = a/npts
  print '(a, es10.2)', 'inverse round trip max error  ', maxval(abs(a - b))
  deallocate(re, a, b, dft)

  ! ---- timing: N log N
  print '(a)', '        N   time per FFT [ms]   N log2 N / 1e6'
  npts = 1024
  do while (npts <= 2**20)
     allocate(re(npts), a(npts))
     call random_number(re);  a = cmplx(re, 0.0_dp, dp)
     reps = max(1, 2**20/npts)
     call system_clock(t0, rate)
     do r = 1, reps
        call fft_inplace(a, -1)
     end do
     call system_clock(t1)
     tfft = 1000.0_dp*(t1 - t0)/rate/reps
     err = npts*log(real(npts, dp))/log(2.0_dp)/1e6_dp
     print '(i9, f16.4, f17.3)', npts, tfft, err
     deallocate(re, a)
     npts = 4*npts
  end do
end program fft_radix2
