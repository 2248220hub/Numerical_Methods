Lecture 12 ended with a problem: every Bayesian answer is an integral over the posterior, and a grid costs Kd.

Monte Carlo: evaluate the function at random points. Start with the simplest version — throw darts at a square and count how many land in the circle.

A Monte Carlo result always comes with its error bar, computed from the same samples at no extra cost. A result without it is not a Monte Carlo result.

BASICThe problem: integrals we cannot put on a grid

\h{E}{\mathbb E}[g(\theta)\mid x] = \h{integral}{\int} g(\theta)\,\h{post}{p(\theta\mid x)}\dd\theta Means, variances, intervals, marginals: all integrals. Grid with K points per axis: Kd evaluations (30 µs each for the knee: 4 s for d = 3, 3 hours for d = 5, 9 months for d = 7) and 2462 of 10⁶ points (0.25%) hold 99% of the mass.

Monte Carlo = a wide class of algorithms that obtain numerical results by repeated random sampling. The name dates from the 1940s at Los Alamos (Ulam, von Neumann, Metropolis — after the casino). Key idea: use randomness to solve problems that may be deterministic. For integration: evaluate the function at random points. It needs only the ability to evaluate the integrand, and it shines in many dimensions. Used “backwards”, the same idea simulates: noise records, sky maps, detector responses — every simulated record of the knee is a Monte Carlo sample.

Three approaches to \(I=\int_a^b f(x)\,{\rm d}x\): (1) hit-or-miss (geometric), (2) sample mean (mean-value theorem), (3) importance sampling (sample mean with points where they matter — needs sampling from a distribution, hence part II of the lecture).

BASICHit-or-miss

Area of an irregular figure A inside a box of known area Abox: throw N points uniformly in the box, count the Nin inside.

\h{I}{I}\approx \h{Abox}{A_{\rm box}}\,\frac{\h{Nin}{N_{\rm in}}}{\h{N}{N}} Classic example: π from a circle inscribed in a square. In the quarter-circle version the fraction of hits estimates π/4. x, y = rng.random(n), rng.random(n) p_hat = np.mean(x**2 + y**2 < 1.0) pi_hat = 4.0 * p_hat call random_number(x); call random_number(y) p_hat = count(x**2 + y**2 < 1.0_dp) / real(n, dp) pi_hat = 4.0_dp * p_hat

COREThe error of hit-or-miss

Each point is a Bernoulli trial with success probability p = A/Abox (unknown, estimated by p̂ = Nin/N). The number of successes is binomial with variance Np(1−p). Propagate to I = Abox Nin/N:

\h{dI}{\delta I}\simeq\frac{\h{Abox}{A_{\rm box}}}{\sqrt{\h{N}{N}}}\sqrt{\h{phat}{\hat p}(1-\h{phat}{\hat p})},\qquad \frac{\h{dI}{\delta I}}{\h{I}{I}}\simeq\sqrt{\frac{1-\h{phat}{\hat p}}{\h{phat}{\hat p}\,\h{N}{N}}} p replaced by p̂: the same points give the error. Quarter circle, 1500 points: Nin = 1164, p̂ = 0.776, π ≈ 3.104 ± 0.043. The absolute error is largest at p = ½; the relative error grows without bound as p → 0: a small figure in a big box needs ~1/p points just to be hit once. err = 4.0 * np.sqrt(p_hat * (1 - p_hat) / n) err = 4.0_dp*sqrt(p_hat*(1.0_dp - p_hat)/n) 1500 random points in the unit square, 1164 inside the quarter circle. BASICThe estimator

\h{fmean}{\langle f\rangle}=\frac{1}{\h{ab}{b-a}}\h{integral}{\int_a^b} f(x)\dd x\quad\Longrightarrow\quad \h{I}{I}=\h{ab}{(b-a)}\,\h{fmean}{\langle f\rangle} \h{IN}{I_N}=\h{ab}{(b-a)}\frac1{\h{N}{N}}\h{sum}{\sum_{i=1}^{N}} f(\h{xi}{x_i}),\qquad \h{xi}{x_i}\sim U(a,b) In d dimensions (b − a) becomes the volume V of the domain and xi is a d-vector: only the shape of the array changes. def mc_integrate(func, a, b, n, rng): x = rng.uniform(a, b, n) y = func(x) return (b - a) * y.mean(), (b - a) * y.std(ddof=1) / np.sqrt(n) call random_number(x); x = a + (b - a)*x fx = x**2 est = (b - a)*sum(fx)/n err = (b - a)*sqrt(sum((fx - sum(fx)/n)**2)/(n - 1))/sqrt(real(n, dp)) Estimate \(\int_0^2 x^2{\rm d}x\) with the four “random” points x = 0.2, 0.8, 1.4, 1.6. COREIts error, from the same samples

  1. IN is (b−a) times a mean of N independent random variables f(xi).
  2. Variance of a mean of N i.i.d. variables = (variance of one)/N: \(\sigma_I^2=(b-a)^2\sigma_f^2/N\).
  3. σf is unknown: estimate it with the same samples, \(\hat\sigma_f^2=\frac1{N-1}\sum(f_i-\bar f)^2\).
  4. Central limit theorem: for large N, IN is Gaussian around I with that width.
\h{dI}{\delta I}=\frac{\h{ab}{b-a}}{\sqrt{\h{N}{N}}}\,\h{sigf}{\hat\sigma_f},\qquad \h{sigf}{\sigma_f^2}=\langle f^2\rangle-\langle f\rangle^2,\qquad \h{IN}{I_N}\sim\mathcal N(I,\delta I^2) Requirement: σf finite (a heavy-tailed f can break it). Every Monte Carlo result comes with its error bar at no extra cost. err = (b - a) * y.std(ddof=1) / np.sqrt(n) err = (b - a)*sqrt(sum((fx - sum(fx)/n)**2)/(n - 1))/sqrt(real(n, dp))

COREHow errors scale

\text{MC: }\ \h{dI}{\delta I}\propto\frac{\h{sigf}{\sigma_f}}{\sqrt{\h{N}{N}}}\quad\text{(any } d),\qquad\text{grid of order }\h{kord}{k}:\ \ \h{dI}{\delta I}\propto \h{N}{N}^{-\h{kord}{k}/\h{d}{d}} A 1-D rule with error ∝ n−k (trapezoid k = 2, Simpson k = 4) on a product grid of N = nd points has error ∝ N−k/d. Simpson: N⁻⁴ in 1-D, N⁻¹ in 4-D, N−½ in 8-D. Monte Carlo becomes competitive when k/d < ½, i.e. d > 2k: d > 4 (trapezoid), d > 8 (Simpson). # appendix A: MC error = V sigma_f / sqrt(N) by independence alone, no d in the argument err_mc = sigma_f / np.sqrt(N) err_grid = C * N ** (-k / d) err_mc = sigma_f / sqrt(real(N, dp)) err_grid = C * real(N, dp)**(-real(k, dp)/d)

Measured on \(\int_{[0,1]^d}\prod_i\frac\pi2\sin(\pi x_i)=1\) (σf² = (π²/8)d − 1): d ≤ 4 Simpson wins by orders of magnitude; d = 8 same slope, Monte Carlo 3–17 times more accurate, and needs no grid (Simpson needs at least 3⁸ = 6561 points to start). σf grows with d (0.48 at d = 1, 2.1 at d = 8): the error does not depend on d through N, but the prefactor can. COREThe method

\h{I}{I}=\h{integral}{\int} f(x)\dd x=\h{integral}{\int}\frac{f(x)}{\h{g}{g(x)}}\,\h{g}{g(x)}\dd x=\h{Eg}{\mathbb E_g}\!\left[\frac fg\right]\approx\frac1{\h{N}{N}}\h{sum}{\sum_i}\h{w}{w_i},\quad \h{w}{w_i}=\frac{f(x_i)}{\h{g}{g(x_i)}},\ x_i\sim \h{g}{g} g must be a density with g > 0 wherever f ≠ 0 (support condition). The weight corrects for non-uniform sampling: points drawn often (g large) count less. Error as before from the spread of the weights: δI = σ̂w/√N. EXPERTTails: a proposal that fails silently

∫ t₃(x) dx = 1 (Student t with 3 dof, tails ∝ |x|⁻⁴). With a Gaussian proposal (tails e−x²/2, lighter): \(\mathbb E_g[w^2]=\infty\). 200 runs of 10⁴: median error 0.026 looks fine, the worst run is off by 17.9 with one weight at 95% of the total. The running estimate stays low, then jumps when a rare far point arrives. With a Cauchy proposal (∝ x⁻², heavier): rms error 0.004, no weight above 0.01%. Diagnostic: the largest weight against the total; for a posterior, the effective sample size (next lesson).

EXPERTThe limit: importance sampling in high dimension

Target 𝒩(0, Id), proposal 𝒩(0, s²Id). For one dimension, \(\mathbb E_g[w^2]=\int f^2/g\,{\rm d}x\). With f = φ(x), g = φ(x/s)/s: the integrand is \(\frac{s}{\sqrt{2\pi}}e^{-x^2(1-1/(2s^2))}\), a Gaussian integral giving \(s^2/\sqrt{2s^2-1}\). Dimensions are independent, so the factors multiply:

\frac{\h{Neff}{N_{\rm eff}}}{\h{N}{N}}\approx\big(\h{Egw2}{\mathbb E_g[w^2]}\big)^{-1}=\left(\frac{\h{s}{s}^2}{\sqrt{2\h{s}{s}^2-1}}\right)^{-\h{d}{d}} s = 1.2: 95% at d = 1, 37% at d = 20, ~1% at d = 100. s = 2: 13% at d = 5, 1.6% at d = 10; from d ≈ 50 two or three points carry all the weight. A posterior with tens of parameters is out of reach of any fixed proposal. ess_frac = (s**2 / np.sqrt(2*s**2 - 1)) ** (-d) ess_frac = (s**2/sqrt(2*s**2 - 1.0_dp))**(-d)
s = 1.2, d = 20: ESS/N? Per dimension: 1.44/√1.88 = 1.0502.1.0502⁻²⁰ = 0.375 (measured with 10⁵ samples: 0.377). s = 2, d = 10: ESS/N? Per dimension 4/√7 = 1.5119.1.5119⁻¹⁰ = 0.0160: 1.6%.
Importance sampling draws all points from one fixed proposal; in many dimensions the weights degenerate. The way out (Lecture 14): let each new point depend on the previous one, so the sampler walks into the region of high probability and stays there — Markov chain Monte Carlo, Metropolis–Hastings.
