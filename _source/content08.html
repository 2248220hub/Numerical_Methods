Cooley and Tukey (1965) — and Gauss around 1805 — noticed that an N-point DFT is two N/2-point DFTs plus N/2 multiplications. Repeat until the pieces have one sample.

X[k] = E[k] + WNkO[k] and X[k+N/2] = E[k] − WNkO[k]: one multiplication serves two outputs.

BASICThe complexity challenge

A strain record of N = 2²⁰ ≈ 10⁶ samples (64 s at 16 384 Hz) costs N² ≈ 10¹² complex multiplications by direct DFT, against ≈ 10⁷ for the FFT. Repeated over many templates, channels or antennas, O(N²) is prohibitive.

COREDecimation in time

Take N = 2q. Split the samples by index parity: e[m] = x[2m], o[m] = x[2m+1], m = 0 … N/2−1; let E[k], O[k] be their N/2-point DFTs.

  1. Split the DFT sum: \(X[k]=\sum_m x[2m]W_N^{2mk}+\sum_m x[2m+1]W_N^{(2m+1)k}=\sum_m e[m](W_N^2)^{km}+W_N^k\sum_m o[m](W_N^2)^{km}\).
  2. Twiddle reduction: \(W_N^2=e^{-j2\pi\cdot2/N}=e^{-j2\pi/(N/2)}=W_{N/2}\). The two sums are N/2-point DFTs: \(X[k]=E[k]+W_N^kO[k]\).
  3. E, O have period N/2 in k, and \(W_N^{k+N/2}=-W_N^k\): the second half of the outputs needs no new products.
\h{Xk}{X[k]}=\h{Ek}{E[k]}+\h{WN}{W_N^k}\,\h{Ok}{O[k]},\qquad \h{Xk}{X\big[k+\tfrac N2\big]}=\h{Ek}{E[k]}-\h{WN}{W_N^k}\,\h{Ok}{O[k]},\qquad k=0,\dots,\tfrac N2-1 def fft_recursive(x): N = len(x) if N <= 1: return x.astype(complex) E, O = fft_recursive(x[0::2]), fft_recursive(x[1::2]) t = np.exp(-2j*np.pi*np.arange(N//2)/N) * O return np.concatenate([E + t, E - t]) ! recursion is possible (recursive subroutine), but the in-place iterative ! version of fft_radix2.f90 is what libraries do t = w(j)*a(k+j+half+1); u = a(k+j+1) a(k+j+1) = u + t; a(k+j+half+1) = u - t

Each butterfly takes two numbers, multiplies one by a twiddle, and writes the sum and the difference back into the same two slots.

Step through the stages above: the pairs are 1, 2, 4 … apart.

Each radix-2 step deals the samples into even and odd piles (by the lowest bit), the next step by the next bit, and so on. To work in place every sub-transform must occupy a contiguous block: the last-dealt bit becomes the most significant bit of the position.

\mathrm{rev}[i]=\big(\mathrm{rev}[i\gg1]\gg1\big)\ \big|\ \big((i\ \&\ 1)\ll(q-1)\big) rev = np.zeros(N, int) for i in range(1, N): rev[i] = (rev[i >> 1] >> 1) | ((i & 1) << (q - 1)) rev(i) = ior(ishft(rev(ishft(i, -1)), -1), ishft(iand(i, 1), q - 1))

COREThe iterative in-place FFT

  1. Permute x[n] ↔ x[rev(n)].
  2. For s = 1 … log₂N: block size m = 2s, twiddles Wmj (a precomputed table is more accurate than the running product w ← w·Wm).
  3. For every block start k = 0, m, 2m, …: for j = 0 … m/2−1, t = Wmj x[k+j+m/2], u = x[k+j]; x[k+j] = u + t, x[k+j+m/2] = u − t.

CORENotch filtering

  1. Compute F = fft2(f), centre it (fftshift).
  2. Find the spike coordinates (u₀, v₀) in |F|.
  3. Multiply by H = 1 − Gaussian at (u₀, v₀) and at (−u₀, −v₀).
  4. Inverse-transform: fclean = Re F⁻¹{F·H}.
def notch_filter(img, spikes, sigma=2.0): F = np.fft.fftshift(np.fft.fft2(img)) rows, cols = F.shape; rr, cc = np.ogrid[:rows, :cols] H = np.ones(F.shape) for r0, c0 in spikes: for r, c in ((r0, c0), (rows - r0, cols - c0)): # conjugate partner H *= 1 - np.exp(-((rr - r)**2 + (cc - c)**2) / (2*sigma**2)) return np.real(np.fft.ifft2(np.fft.ifftshift(F * H)))
