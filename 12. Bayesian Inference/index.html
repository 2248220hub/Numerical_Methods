12. Bayesian Inference/

The whole module (Lectures 12–14) answers one question: from one noisy detector record, what are the three numbers of its noise model, and how sure are we?

Before any formula we need a language for “how sure”. That language is probability — and there are three ways to read it.

Frequentists and Bayesians use the same maths (Kolmogorov's axioms). They disagree on what a probability can be attached to: only repeatable data, or also an unknown parameter.

BASICThe problem of the module: three numbers from one record

A detector records noise for 64 s at 100 Hz: N = 6400 samples. Its power spectrum is not flat: at low frequency there is extra power (“1/f noise”) that bends up below a knee frequency. The model used in every lecture of this module is

MODELThe knee noise modelhover the symbols ↓
\h{Sf}{S(f)} = \h{s2}{\sigma^2}\left[1+\left(\frac{\h{fk}{f_k}}{\h{f}{f}}\right)^{\h{alpha}{\alpha}}\right]
Three parameters θ = (σ², fk, α). The simulation's truth is (10⁻³, 1 Hz, 1). Above the knee the noise is white (flat, level σ²); below it, power grows like f−α.
def S(f, sigma2, fk, alpha):
    return sigma2 * (1.0 + (fk / f) ** alpha)
pure elemental real(dp) function S(f, sigma2, fk, alpha)
  real(dp), intent(in) :: f, sigma2, fk, alpha
  S = sigma2 * (1.0_dp + (fk/f)**alpha)
end function S

Fitting one record (Maximum Likelihood, lesson 3) gives \(\hat f_k = 0.93\) Hz and \(\hat\alpha = 0.82\). The truth is 1 and 1. How far from the truth can we be, with one record? What does “\(f_k = 0.93 \pm 0.2\) Hz” actually mean? Answering that honestly is the goal of Lecture 12.

CMB satellites (Planck LFI)Radiometers have exactly this 1/f + white noise; the knee frequency sets how the sky must be scanned.
Gravitational waves (LIGO, LISA)Noise spectra are estimated from data with the Whittle likelihood before any signal search.

BASICTwo kinds of uncertainty

  • Epistemic — from our limited knowledge or finite instrument precision. The system may be deterministic (a tossed coin), but we don't know its initial conditions. Reducible by collecting more information. → Our ignorance of (σ², fk, α).
  • Aleatory (intrinsic) — in the phenomenon itself (a quantum measurement), or variability we choose to model as random. → The detector noise: another record, another periodogram.

BASICThree definitions of probability

DEFINITIONClassical probability (Laplace)hover the symbols ↓

Bayesian probability: the degree of belief (plausibility) in a proposition, given the information available. It applies to single events and to parameters: “\(P(0.8 \lt f_k \lt 1.2\ {\rm Hz} \mid {\rm data})\)” makes sense. It is not arbitrary: Cox (1946) showed that any consistent calculus of plausibility obeying common-sense requirements is probability theory. “Subjective” means conditional on the information, not “as you please”.

COREThe law of large numbers

The frequency nE/N does not equal p after N trials; it wanders around p with a typical distance that shrinks like 1/√N. Precisely, nE is binomial, so

RESULTSpread of a relative frequencyhover the symbols ↓
\h{sdfreq}{\sigma\!\left(\tfrac{n_E}{N}\right)} = \sqrt{\frac{\h{p}{p}\,(1-\h{p}{p})}{\h{N}{N}}} \qquad\Longrightarrow\qquad P\!\left(\left|\tfrac{n_E}{N}-p\right|\gt\epsilon\right)\to 0
The law of large numbers is a theorem of the axioms (convergence in probability), not the definition. The 1/√N law is the seed of everything in Lecture 13: every Monte Carlo error bar is this formula in disguise.
se = np.sqrt(p * (1 - p) / N)
se = sqrt(p*(1.0_dp - p)/N)

COREKolmogorov's axioms: the shared calculus

Whatever the interpretation, a probability on a sample space \(\h{Omega}{\Omega}\) with a σ-algebra of events \(\mathcal F\) must satisfy:

AXIOMSKolmogorov axioms (1933)hover the symbols ↓
\text{(1)}\;\; \h{P}{P}(E)\ge 0 \qquad \text{(2)}\;\; \h{P}{P}(\h{Omega}{\Omega}) = 1 \qquad \text{(3)}\;\; \h{P}{P}\Big(\bigcup_{i=1}^{\infty} \h{Ei}{E_i}\Big)=\h{sum}{\sum_{i=1}^{\infty}} \h{P}{P}(\h{Ei}{E_i})\ \ \text{(disjoint } E_i)
Non-negativity, normalisation, countable additivity. Two-set additivity is not enough for continuous variables: densities, integrals and limits (the law of large numbers) need the countable version.

BASICConditional probability

We often want the probability of A knowing that B happened (with P(B) > 0). We restrict the world to B and ask which fraction of it is also A:

DEFINITIONConditional probabilityhover the symbols ↓
\h{PAB}{P(A\mid B)} = \frac{\h{cap}{P(A\cap B)}}{\h{PB}{P(B)}}
Example: one die, A = “6”, B = “even”. P(A∩B) = 1/6, P(B) = 1/2, so P(6 | even) = 1/3.
p_A_given_B = p_AB / p_B
p_A_given_B = p_AB / p_B

Multiplying out gives the product rule, written two ways because ∩ is symmetric:

RULEProduct rulehover the symbols ↓
\h{cap}{P(A\cap B)} = \h{PAB}{P(A\mid B)}\,\h{PB}{P(B)} = \h{PBA}{P(B\mid A)}\,\h{PA}{P(A)}

If A₁ … An split Ω into disjoint pieces (a partition: exactly one is true), then B happens through exactly one of them:

RULELaw of total probabilityhover the symbols ↓
\h{PB}{P(B)} = \h{sum}{\sum_i} \h{PBAi}{P(B\mid A_i)}\,\h{PAi}{P(A_i)}
p_B = np.sum(p_B_given_A * p_A)      # arrays over the partition
p_B = sum(p_B_given_A * p_A)

A and B are independent if \(P(A\cap B) = P(A)P(B)\), i.e. \(P(A\mid B)=P(A)\): knowing B teaches nothing about A.

BASICBayes' theorem in two lines

  1. Write the product rule both ways: \(P(A\mid B)P(B) = P(B\mid A)P(A)\).
  2. Divide by \(P(B)\) and expand \(P(B)\) with the total probability. Done.
THEOREMBayes' theoremhover the symbols ↓
\h{PAB}{P(A\mid B)} = \frac{\h{PBA}{P(B\mid A)}\;\h{PA}{P(A)}}{\h{PB}{P(B)}},\qquad \h{PB}{P(B)}=\h{sum}{\sum_i}\h{PBAi}{P(B\mid A_i)}\h{PAi}{P(A_i)}
The engine of inference: it inverts the conditioning, from “effect given cause” (easy to model) to “cause given observed effect” (what we want).
def bayes(like, prior):
    """like[i] = P(B | A_i), prior[i] = P(A_i)  ->  P(A_i | B)"""
    joint = like * prior
    return joint / joint.sum()          # divide by the evidence P(B)
post = like * prior
post = post / sum(post)                ! divide by the evidence P(B)

For a model with parameters θ and data x (plus background information I, usually left implicit) every piece gets a name:

THEOREMBayes' theorem for parametershover the symbols ↓
\underbrace{\h{post}{p(\theta\mid x)}}_{\text{posterior}} = \frac{\overbrace{\h{like}{p(x\mid\theta)}}^{\text{likelihood}}\ \overbrace{\h{prior}{p(\theta)}}^{\text{prior}}}{\underbrace{\h{evid}{p(x)}}_{\text{evidence}}},\qquad \h{evid}{p(x)} = \h{integral}{\int} \h{like}{p(x\mid\theta)}\,\h{prior}{p(\theta)}\dd\theta
The evidence normalises the posterior: a constant for one model (ignore it for parameter estimation), the key quantity to compare models (lesson 7, Expert).
# on a grid of theta values:
post = like(theta_grid) * prior(theta_grid)
post /= np.trapz(post, theta_grid)     # = dividing by the evidence
post = like * prior
post = post / (sum(post) * dtheta)      ! Riemann-sum evidence
Before data you have a belief (prior). The data say how well each possible value explains what you saw (likelihood). Multiply, renormalise: that's your new belief (posterior).

BASICWorked example: the two urns (from the lecture)

Urn A₁: 3 blue, 7 red. Urn A₂: 6 blue, 4 red. One is chosen at random: P(A₁) = P(A₂) = ½. We draw a ball: blue.

  1. Likelihoods: P(B | A₁) = 0.3, P(B | A₂) = 0.6.
  2. Evidence: P(B) = 0.3·½ + 0.6·½ = 0.45.
  3. Posterior: P(A₁ | B) = 0.3·½ / 0.45 = 1/3, P(A₂ | B) = 2/3.
  4. Put the ball back, draw again: blue. Yesterday's posterior is today's prior: P(A₁ | BB) = 0.3·⅓ / (0.3·⅓ + 0.6·⅔) = 0.2.
  5. Same in one go with the likelihood of two draws: 0.3²·½ / (0.3²·½ + 0.6²·½) = 0.2. The order in which data arrive does not matter.

COREThe base-rate trap: why priors matter

A transient-detection pipeline (supernovae, GW alerts, a satellite fault monitor) raises an alarm. It catches 99% of real events (sensitivity) and has a 5% false-alarm rate. Real events are rare: 1% of candidates. Given an alarm, what is the probability it's real? Most people say “99%”. Bayes says:

APPLICATIONPosterior probability of a real eventhover the symbols ↓
\h{PRA}{P(\text{real}\mid\text{alarm})} = \frac{\h{sens}{P(\text{alarm}\mid\text{real})}\;\h{prev}{P(\text{real})}}{\h{sens}{P(\text{alarm}\mid\text{real})}\h{prev}{P(\text{real})} + \h{fa}{P(\text{alarm}\mid\text{noise})}\,[1-\h{prev}{P(\text{real})}]}
With 0.99, 0.01, 0.05: 0.0099 / (0.0099 + 0.0495) = 0.167. Five out of six alarms are false, because noise candidates are 99 times more numerous.
post = sens * prev / (sens * prev + fa * (1 - prev))
post = sens*prev / (sens*prev + fa*(1.0_dp - prev))

BASICInference is probability run backwards

  • Probability (deduction): given a model and its parameters, predict the data — our noise generator.
  • Inference (induction): given the data, estimate the parameters of the model that generated them — our problem.
DEFINITIONLikelihood functionhover the symbols ↓
\h{L}{\mathcal L(\theta)} = \h{like}{p(x\mid\theta)}\quad\text{read as a function of }\h{theta}{\theta}\text{ at fixed data }\h{x}{x}
For independent data the joint probability factorises: \(\mathcal L(\theta) = \prod_i p(x_i\mid\theta)\). Always work with ln 𝓛 (a sum) — a product of 3000 numbers smaller than 1 underflows.
def log_like(theta, x):
    return np.sum(log_p_single(x, theta))   # sum of logs, never prod
lnL = sum(log_p_single(x, theta))           ! elemental function on the array
PRINCIPLEMaximum likelihood estimator (MLE)hover the symbols ↓
\h{thetahat}{\hat\theta_{\rm ML}} = \h{argmax}{\arg\max_\theta}\ \h{L}{\mathcal L(\theta)} = \h{argmin}{\arg\min_\theta}\ \big[-\h{lnL}{\ln\mathcal L(\theta)}\big]
The value of θ that makes the observed data most probable. In practice we minimise −ln 𝓛 (optimisers minimise).

COREGaussian data: the likelihood becomes χ²

If the data xi are independent Gaussians with known errors σi and model means μi(θ):

LIKELIHOODGaussian likelihoodhover the symbols ↓
\h{L}{\mathcal L(\theta)} = \h{prod}{\prod_{i=1}^{N}}\frac{1}{\sqrt{2\pi}\,\h{sigmai}{\sigma_i}}\exp\!\left[-\frac{(\h{xi}{x_i}-\h{mui}{\mu_i(\theta)})^2}{2\h{sigmai}{\sigma_i}^2}\right]

Take the logarithm, term by term — the product becomes a sum, the exponential disappears:

RESULTLog-likelihood and χ²hover the symbols ↓
\h{lnL}{\ln\mathcal L(\theta)} = -\frac12\h{sum}{\sum_{i=1}^{N}}\frac{(\h{xi}{x_i}-\h{mui}{\mu_i(\theta)})^2}{\h{sigmai}{\sigma_i}^2} - \h{sum}{\sum_i}\ln\!\big(\sqrt{2\pi}\,\h{sigmai}{\sigma_i}\big) = -\frac12\,\h{chi2}{\chi^2(\theta)} + \text{const}
Maximising the likelihood = minimising χ² (least squares) — only if the σi are known and do not depend on θ. If the noise level is itself a parameter (our σ²!), the term Σ ln σi stays and plain least squares is wrong.

COREThe likelihood of a spectrum: Whittle

Our noise samples are correlated (that's what a non-white spectrum means), so the time-domain likelihood is not a product of independent Gaussians. Go to the frequency domain: for a stationary Gaussian process, the periodogram bins Pj (DC and Nyquist excluded) are asymptotically independent and exponential with mean S(fj), i.e. Pj = S(fj) χ²₂/2.

LIKELIHOODDistribution of one periodogram binhover the symbols ↓
p(\h{Pj}{P_j}\mid\h{theta}{\theta}) = \frac{1}{\h{Sj}{S_j}}\,e^{-\h{Pj}{P_j}/\h{Sj}{S_j}},\qquad \h{Sj}{S_j}=\h{Sf}{S(f_j;\theta)}
Why exponential? The DFT coefficient Xj is a complex Gaussian: real and imaginary parts independent with equal variance. |Xj|² is then a sum of two squared Gaussians, χ²₂, which is an exponential. Mean and standard deviation of Pj are both Sj: a periodogram is 100% noisy per bin.
P = -S * np.log(1.0 - rng.random(S.size))   # simulate a periodogram (inversion, L13)
call random_number(r);  P = -S*log(1.0_dp - r)
LIKELIHOODWhittle likelihoodhover the symbols ↓
-\h{lnL}{\ln\mathcal L(\theta)} = \h{sum}{\sum_j}\left[\ln \h{Sj}{S_j} + \frac{\h{Pj}{P_j}}{\h{Sj}{S_j}}\right]
Fast: O(N) per evaluation (after one FFT). Each bin alone would be fitted best by Sj = Pj (set ∂/∂Sj = 0: 1/S − P/S² = 0). The model ties the 3199 bins together with 3 parameters. Approximations: leakage for steep spectra, correlated lowest bins, χ²₁ at DC/Nyquist.
def neg_log_like(theta, f, P):
    log10_s2, log10_fk, alpha = theta
    S = 10**log10_s2 * (1 + (10**log10_fk / f) ** alpha)
    return np.sum(np.log(S) + P / S)
S = s2 * (1.0_dp + (fk/f)**alpha)
nll = sum(log(S) + P/S)

BASICSharp peak = precise parameter

Near its minimum, −ln 𝓛 looks like a parabola. A narrow parabola means a small change of θ makes the data much less probable: θ is well constrained. The curvature (second derivative) measures this.

DEFINITIONFisher information matrixhover the symbols ↓
\h{F}{F_{ab}} = \h{E}{\mathbb E}\!\left[-\frac{\partial^2 \h{lnL}{\ln\mathcal L}}{\partial\h{theta}{\theta_a}\,\partial\h{theta}{\theta_b}}\right],\qquad\text{Whittle: }\ \h{F}{F_{ab}}=\h{sum}{\sum_j}\partial_a\ln \h{Sj}{S_j}\;\partial_b\ln \h{Sj}{S_j}

def fisher(theta, f, h=1e-5):

Derivation for the simplest case: the mean of N Gaussians

  1. \(-\ln\mathcal L(\mu) = \sum_i (x_i-\mu)^2/(2\sigma^2) + {\rm const}\).
  2. Second derivative: \(\partial^2(-\ln\mathcal L)/\partial\mu^2 = N/\sigma^2\) (no data left: expectation is trivial).
  3. So \(F = N/\sigma^2\) and the error is \(\sigma_\mu = 1/\sqrt F = \sigma/\sqrt N\). The famous “standard error of the mean” is a Fisher error.

knee.py
"""
knee.py  --  the model signal of Lectures 12-14 (Computing Methods for Astrophysics)

Noise with a "knee":   S(f) = sigma2 * [ 1 + (fk / f)**alpha ]

  sigma2 : white-noise level           (units^2 / Hz)
  fk     : knee frequency              (Hz)   below fk the 1/f part dominates
  alpha  : slope of the 1/f part       (alpha = 1 -> "pink" 1/f noise)

We never need the time series to do inference: for a stationary Gaussian
process each periodogram bin P_j is (asymptotically) EXPONENTIAL with mean S(f_j)
  ->  P_j = -S_j * ln(u),  u ~ U(0,1]          (inversion sampling, Lecture 13)
and the bins are independent, which gives the Whittle likelihood (Lecture 12):
  -ln L(theta) = sum_j [ ln S_j + P_j / S_j ]
"""
import numpy as np

TRUTH = dict(sigma2=1e-3, fk=1.0, alpha=1.0)      # the simulation's truth


def frequencies(T=64.0, fs=100.0):
    """Fourier frequencies of a record of length T [s] sampled at fs [Hz].
    DC (j=0) and Nyquist (j=N/2) are excluded: 64 s at 100 Hz -> 3199 bins."""
    N = int(round(T * fs))
    j = np.arange(1, N // 2)
    return j / T


def spectrum(f, sigma2, fk, alpha):
    """Model power spectral density S(f)."""
    return sigma2 * (1.0 + (fk / f) ** alpha)


def simulate_periodogram(f, sigma2, fk, alpha, rng):
    """One noisy periodogram: exponential bins with mean S(f) (inversion)."""
    S = spectrum(f, sigma2, fk, alpha)
    u = 1.0 - rng.random(f.size)          # in (0,1]: never log(0)
    return -S * np.log(u)


def neg_log_like(theta, f, P):
    """Whittle -ln L for theta = (log10 sigma2, log10 fk, alpha).
    We fit log10 of the positive parameters: the posterior is more Gaussian there."""
    log10_s2, log10_fk, alpha = theta
    S = spectrum(f, 10.0 ** log10_s2, 10.0 ** log10_fk, alpha)
    return np.sum(np.log(S) + P / S)


if __name__ == "__main__":
    rng = np.random.default_rng(12)
    f = frequencies()
    P = simulate_periodogram(f, **TRUTH, rng=rng)
    print(f"{f.size} frequency bins from {f[0]:.4f} to {f[-1]:.2f} Hz")
    print("mean of P/S (should be ~1):", np.mean(P / spectrum(f, **TRUTH)))
    print("-lnL at the truth:", neg_log_like((-3.0, 0.0, 1.0), f, P))

"""
knee_inference.py  --  Lecture 12 end to end, on one simulated record.

  1. simulate a 64 s record (periodogram) of knee noise
  2. maximum likelihood (Whittle) + Laplace/Hessian error bars
  3. posterior on a 3-D grid (log-sum-exp normalisation, sigma2 factor trick)
  4. marginals, MAP / median / mean, equal-tailed and HPD intervals
  5. prior flat in log10(fk) versus prior flat in fk  (the Jacobian!)
  6. coverage of  theta_hat +- 1 sigma  over many simulated records
Figures are saved as PNG next to this script.

Run:  python knee_inference.py          (about 20-40 s on a laptop)
"""
import time
import numpy as np
from scipy.optimize import minimize
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

from knee import frequencies, spectrum, simulate_periodogram, neg_log_like, TRUTH

rng = np.random.default_rng(12)          # one seed, written down
f = frequencies(T=64.0)
P = simulate_periodogram(f, **TRUTH, rng=rng)
names = ["log10 sigma2", "log10 fk", "alpha"]
theta_true = np.array([-3.0, 0.0, 1.0])

# ---------------------------------------------------------------- 2. MLE
def fit_mle(f, P, start=(-3.0, 0.0, 1.0)):
    res = minimize(neg_log_like, start, args=(f, P), method="Nelder-Mead",
                   options=dict(xatol=1e-7, fatol=1e-7, maxiter=4000))
    return res.x, res.fun


def hessian(fun, x, h=1e-4):
    """Central finite-difference Hessian: O(d^2) function evaluations."""
    d = len(x)
    H = np.zeros((d, d))
    for i in range(d):
        for j in range(d):
            e_i = np.eye(d)[i] * h
            e_j = np.eye(d)[j] * h
            H[i, j] = (fun(x + e_i + e_j) - fun(x + e_i - e_j)
                       - fun(x - e_i + e_j) + fun(x - e_i - e_j)) / (4 * h * h)
    return H


theta_hat, nll_min = fit_mle(f, P)
H = hessian(lambda t: neg_log_like(t, f, P), theta_hat)
C = np.linalg.inv(H)                       # Laplace covariance  C = H^-1
err = np.sqrt(np.diag(C))
corr = C / np.outer(err, err)
print("=== Maximum likelihood (Whittle) + Laplace errors ===")
for n, t, e, tt in zip(names, theta_hat, err, theta_true):
    print(f"  {n:13s} = {t:+.4f} +- {e:.4f}   (truth {tt:+.3f}, pull {(t-tt)/e:+.2f})")
print(f"  fk_hat = {10**theta_hat[1]:.3f} Hz")
print("  correlation matrix:\n", np.array2string(corr, precision=2))

# ---------------------------------------------------------------- 3. grid
t0 = time.time()
u = np.linspace(-3.25, -2.75, 51)          # log10 sigma2   (+-0.25 dex)
v = np.linspace(-2.0, np.log10(50.0), 161)  # log10 fk       (0.01 - 50 Hz)
a = np.linspace(0.0, 3.0, 121)             # alpha
s2 = 10.0 ** u
N = f.size
lnf = np.log(f)
lp = np.empty((u.size, v.size, a.size))
for k, alpha in enumerate(a):
    # g = 1 + (fk/f)^alpha  for all fk at once:  shape (nv, nf)
    g = 1.0 + np.exp(alpha * (v[:, None] * np.log(10.0) - lnf[None, :]))
    A = np.log(g).sum(axis=1)              # sum ln g_j      (depends on fk, alpha only)
    B = (P[None, :] / g).sum(axis=1)       # sum P_j / g_j
    # -lnL = N ln s2 + A + B / s2   -> each sigma2 costs one operation
    lp[:, :, k] = -(N * np.log(s2)[:, None] + A[None, :] + B[None, :] / s2[:, None])
# flat priors in (log10 s2, log10 fk, alpha): ln pi = const inside the box
post = np.exp(lp - lp.max())               # subtract the max BEFORE exp (underflow!)
post /= post.sum()
print(f"\n=== Grid posterior: {post.size:,} points in {time.time()-t0:.2f} s ===")

# fraction of the grid that matters
sorted_p = np.sort(post.ravel())[::-1]
n99 = np.searchsorted(np.cumsum(sorted_p), 0.99) + 1
print(f"  {n99} of {post.size} points ({100*n99/post.size:.2f}%) hold 99% of the mass")

# ---------------------------------------------------------------- 4. summaries
m_v = post.sum(axis=(0, 2))                # marginal of log10 fk
m_a = post.sum(axis=(0, 1))                # marginal of alpha
m_va = post.sum(axis=0)                    # 2-D marginal (log10 fk, alpha)


def summarise(x, p, label):
    p = p / p.sum()
    cdf = np.cumsum(p) - 0.5 * p             # cdf at the bin centres
    mean = np.sum(x * p)
    std = np.sqrt(np.sum((x - mean) ** 2 * p))
    q = lambda c: np.interp(c, cdf, x)
    print(f"  {label:9s} mean {mean:+.3f} +- {std:.3f}   median {q(0.5):+.3f}"
          f"   68% equal-tailed [{q(0.16):+.3f}, {q(0.84):+.3f}]   MAP {x[np.argmax(p)]:+.3f}")
    return mean, std


def hpd(x, p, mass=0.68):
    """Highest-posterior-density set on a grid: take the highest points first."""
    order = np.argsort(p)[::-1]
    keep = order[: np.searchsorted(np.cumsum(p[order]) / p.sum(), mass) + 1]
    return x[keep].min(), x[keep].max()


print("=== Posterior summaries (prior flat in log10 fk) ===")
summarise(v, m_v, "log10 fk")
summarise(a, m_a, "alpha")
lo, hi = hpd(v, m_v)
print(f"  68% HPD of log10 fk: [{lo:+.3f}, {hi:+.3f}]  ->  fk in [{10**lo:.2f}, {10**hi:.2f}] Hz")

# ---------------------------------------------------------------- 5. prior flat in fk
# A prior flat in fk is, in the variable v = log10 fk, proportional to dfk/dv = fk ln10:
m_v_flatfk = m_v * 10.0 ** v
m_v_flatfk /= m_v_flatfk.sum()
med = lambda p: np.interp(0.5, np.cumsum(p / p.sum()) - 0.5 * p / p.sum(), v)
print("\n=== Does the prior matter? (64 s of data) ===")
print(f"  median fk, prior flat in log fk: {10**med(m_v):.3f} Hz")
print(f"  median fk, prior flat in fk    : {10**med(m_v_flatfk):.3f} Hz")
print("  (re-run with T=8 in frequencies() to see the prior take over)")

# ---------------------------------------------------------------- 6. coverage
n_rec = 300
inside = np.zeros(3)
for r in range(n_rec):
    Pr = simulate_periodogram(f, **TRUTH, rng=rng)
    th, _ = fit_mle(f, Pr, start=theta_hat)
    Hr = hessian(lambda t: neg_log_like(t, f, Pr), th)
    er = np.sqrt(np.diag(np.linalg.inv(Hr)))
    inside += np.abs(th - theta_true) < er
print(f"\n=== Coverage of theta_hat +- 1 sigma over {n_rec} records (nominal 68.3%) ===")
for n, c in zip(names, inside / n_rec):
    print(f"  {n:13s} {100*c:.1f}%")

# ---------------------------------------------------------------- figures
fig, ax = plt.subplots(1, 3, figsize=(15, 4.3))
ax[0].loglog(f, P, ",", color="0.6", label="periodogram")
ax[0].loglog(f, spectrum(f, **TRUTH), "k", lw=2, label="truth")
ax[0].loglog(f, spectrum(f, 10**theta_hat[0], 10**theta_hat[1], theta_hat[2]), "r--", lw=2, label="MLE")
ax[0].set(xlabel="f [Hz]", ylabel="S(f)", title="one 64 s record")
ax[0].legend()
ax[1].contourf(a, v, m_va, levels=20, cmap="Greens")
ax[1].plot(1, 0, "r*", ms=14, label="truth")
ax[1].set(xlabel="alpha", ylabel="log10 fk", title="2-D marginal (fk, alpha): degeneracy")
ax[1].legend()
ax[2].plot(10**v, m_v / m_v.max(), label="prior flat in log fk")
ax[2].plot(10**v, m_v_flatfk / m_v_flatfk.max(), "--", label="prior flat in fk")
ax[2].set(xscale="log", xlabel="fk [Hz]", ylabel="marginal (peak = 1)", title="prior sensitivity")
ax[2].legend()
fig.tight_layout()
fig.savefig("knee_inference.png", dpi=120)
print("\nsaved knee_inference.png")
! knee_grid.f90  --  the posterior of the knee on a 3-D grid, from scratch (Lecture 12)
!
!   model     S(f) = sigma2 * [1 + (fk/f)**alpha]
!   data      one periodogram, simulated by inversion: P_j = -S_j * ln(u)
!   likelihood (Whittle)  -ln L = sum_j [ ln S_j + P_j/S_j ]
!   priors    flat in log10 sigma2, log10 fk, alpha  (inside the box)
!
! Compile & run:   gfortran -O2 knee_grid.f90 -o knee_grid && ./knee_grid
! Output:          marginal_log10fk.txt, marginal_alpha.txt  (plot them in Python)
program knee_grid
  implicit none
  integer,  parameter :: dp = kind(1.0d0)
  integer,  parameter :: n = 3199, nu = 51, nv = 161, na = 121
  real(dp), parameter :: T = 64.0_dp, ln10 = log(10.0_dp)
  real(dp) :: f(n), lf(n), P(n), S(n), r(n)
  real(dp) :: u(nu), v(nv), a(na), mv(nv), ma(na)
  real(dp), allocatable :: lp(:,:,:)
  real(dp) :: g, Asum, Bsum, s2, lpmax, mean_a, sd_a, mean_v, cum
  integer  :: i, j, k, l, nseed, t0, t1, rate
  integer, allocatable :: seed(:)

  ! ---- explicit seed: results are reproducible (same compiler)
  call random_seed(size=nseed)
  allocate(seed(nseed));  seed = 12
  call random_seed(put=seed)

  ! ---- frequencies and one simulated periodogram (truth: 1e-3, 1 Hz, 1)
  do l = 1, n
     f(l) = real(l, dp) / T
  end do
  lf = log(f)                                   ! once, outside the loops
  S  = 1.0e-3_dp * (1.0_dp + (1.0_dp / f)**1.0_dp)
  call random_number(r)                          ! r in [0,1)
  P  = -S * log(1.0_dp - r)                      ! 1-r in (0,1]: no log(0)

  ! ---- the grid axes
  do i = 1, nu
     u(i) = -3.25_dp + 0.5_dp * real(i-1, dp) / real(nu-1, dp)
  end do
  do j = 1, nv
     v(j) = -2.0_dp + (log10(50.0_dp) + 2.0_dp) * real(j-1, dp) / real(nv-1, dp)
  end do
  do k = 1, na
     a(k) = 3.0_dp * real(k-1, dp) / real(na-1, dp)
  end do

  allocate(lp(nu, nv, na))                       ! column major: u runs fastest
  call system_clock(t0, rate)
  do k = 1, na                                   ! alpha
     do j = 1, nv                                ! log10 fk
        Asum = 0.0_dp;  Bsum = 0.0_dp
        do l = 1, n                              ! frequency bins
           g    = 1.0_dp + exp(a(k) * (v(j)*ln10 - lf(l)))   ! no ** in the inner loop
           Asum = Asum + log(g)
           Bsum = Bsum + P(l) / g
        end do
        do i = 1, nu                             ! sigma2: no sum over bins
           s2 = 10.0_dp**u(i)
           lp(i, j, k) = -( n*log(s2) + Asum + Bsum/s2 )
        end do
     end do
  end do
  call system_clock(t1)

  ! ---- from ln p to p: subtract the maximum first (exp(-18600) = 0 in double!)
  lpmax = maxval(lp)
  lp = exp(lp - lpmax)
  lp = lp / sum(lp)                              ! lp now holds the normalised posterior

  ! ---- marginals: SUM with DIM, like numpy sum(axis=...)
  mv = sum(sum(lp, dim=3), dim=1)                ! over alpha, then sigma2 -> log10 fk
  ma = sum(sum(lp, dim=2), dim=1)                ! over fk, then sigma2     -> alpha

  mean_a = sum(a * ma);  sd_a = sqrt(sum((a - mean_a)**2 * ma))
  mean_v = sum(v * mv)
  print '(a,i0,a,f6.3,a)', 'grid of ', size(lp), ' points in ', real(t1-t0,dp)/rate, ' s'
  print '(a,f7.4,a,f6.4)', 'alpha    : mean ', mean_a, '  std ', sd_a
  print '(a,f7.4,a,f6.3,a)', 'log10 fk : mean ', mean_v, '  -> fk ~ ', 10.0_dp**mean_v, ' Hz'

  cum = 0.0_dp                                   ! median of log10 fk from the cumulative sum
  do j = 1, nv
     cum = cum + mv(j)
     if (cum >= 0.5_dp) then
        print '(a,f7.4)', 'log10 fk : median ', v(j)
        exit
     end if
  end do

  open(10, file='marginal_log10fk.txt', status='replace')
  do j = 1, nv
     write(10, '(2es16.7)') v(j), mv(j)
  end do
  close(10)
  open(11, file='marginal_alpha.txt', status='replace')
  do k = 1, na
     write(11, '(2es16.7)') a(k), ma(k)
  end do
  close(11)
  print *, 'wrote marginal_log10fk.txt and marginal_alpha.txt'
end program knee_grid

"""
bayes_basics.py  --  the small numerical examples of Lecture 12, one function each.
Run:  python bayes_basics.py

import numpy as np


def urns(draws="BB", prior_A1=0.5):
    """Two urns: A1 has 3 blue / 7 red, A2 has 6 blue / 4 red (with replacement).
    Yesterday's posterior is today's prior."""
    p_blue = {"A1": 0.3, "A2": 0.6}
    post = np.array([prior_A1, 1 - prior_A1])
    for d in draws:
        like = np.array([p_blue["A1"], p_blue["A2"]]) if d == "B" else \
               np.array([1 - p_blue["A1"], 1 - p_blue["A2"]])
        evidence = np.sum(like * post)           # law of total probability
        post = like * post / evidence            # Bayes' theorem
        print(f"  after '{d}': P(A1|data) = {post[0]:.4f}   P(A2|data) = {post[1]:.4f}")
    return post


def alarm(prevalence=0.01, sensitivity=0.99, false_alarm=0.05):
    """P(real event | alarm): the base-rate trap."""
    num = sensitivity * prevalence
    return num / (num + false_alarm * (1 - prevalence))


def gaussian_update(mu_L, s_L, mu_0, s_0):
    """Gaussian likelihood x Gaussian prior -> Gaussian posterior (precisions add)."""
    w_L, w_0 = 1 / s_L**2, 1 / s_0**2
    s_post = 1 / np.sqrt(w_L + w_0)
    mu_post = s_post**2 * (w_L * mu_L + w_0 * mu_0)
    return mu_post, s_post


def mle_variance_bias(N=5, sigma2=4.0, n_sets=200_000, seed=19):
    """The MLE of a Gaussian variance divides by N: biased by (N-1)/N."""
    rng = np.random.default_rng(seed)
    x = rng.normal(0.0, np.sqrt(sigma2), size=(n_sets, N))
    s2_ml = x.var(axis=1, ddof=0)      # 1/N
    s2_un = x.var(axis=1, ddof=1)      # 1/(N-1)
    return s2_ml.mean(), s2_un.mean(), (N - 1) / N * sigma2


if __name__ == "__main__":
    print("Urns, two blue draws (lecture: 1/3 then 0.2):")
    urns("BB")
    print(f"\nAlarm: P(real | alarm) = {alarm():.4f}")
    m, s = gaussian_update(0.82, 0.12, 1.00, 0.10)
    print(f"\nalpha: likelihood 0.82+-0.12, prior 1.00+-0.10 -> posterior {m:.3f} +- {s:.3f}")
    ml, un, th = mle_variance_bias()
    print(f"\nVariance N=5, sigma2=4: <MLE> = {ml:.3f} (theory {th:.3f}),  <1/(N-1)> = {un:.3f}")

module stats_tools
  implicit none
  integer,  parameter :: dp = kind(1.0d0)
  real(dp), parameter :: pi = 4.0_dp * atan(1.0_dp)
contains
  subroutine normal_deviates(z)
    ! Box-Muller: two uniforms -> two independent N(0,1)  (Lecture 13)
    real(dp), intent(out) :: z(:)
    real(dp), allocatable :: u1(:), u2(:)
    integer :: n, m
    n = size(z);  m = (n + 1) / 2
    allocate(u1(m), u2(m))
    call random_number(u1);  call random_number(u2)
    u1 = 1.0_dp - u1                                 ! (0,1]: no log(0)
    z(1:m)   = sqrt(-2.0_dp*log(u1)) * cos(2.0_dp*pi*u2)
    z(m+1:n) = sqrt(-2.0_dp*log(u1(1:n-m))) * sin(2.0_dp*pi*u2(1:n-m))
  end subroutine normal_deviates
end module stats_tools

program bayes_basics
  use stats_tools
  implicit none
  real(dp) :: post(2), like(2), evidence
  real(dp) :: wL, w0, s_post, mu_post
  real(dp) :: x(5), xbar, acc_ml, acc_un
  character(len=2) :: draws = 'BB'
  integer :: i, k, nseed
  integer, parameter :: nsets = 200000, N = 5
  integer, allocatable :: seed(:)

  ! ---- 1. urns: P(blue | A1) = 0.3, P(blue | A2) = 0.6, prior 1/2 each
  post = [0.5_dp, 0.5_dp]
  do i = 1, len(draws)
     if (draws(i:i) == 'B') then
        like = [0.3_dp, 0.6_dp]
     else
        like = [0.7_dp, 0.4_dp]
     end if
     evidence = sum(like * post)                     ! total probability
     post = like * post / evidence                   ! Bayes
     print '(a,a,a,f7.4)', 'after ', draws(i:i), ':  P(A1|data) = ', post(1)
  end do

  ! ---- 2. Gaussian update: precisions add
  wL = 1.0_dp / 0.12_dp**2;  w0 = 1.0_dp / 0.10_dp**2
  s_post  = 1.0_dp / sqrt(wL + w0)
  mu_post = s_post**2 * (wL*0.82_dp + w0*1.00_dp)
  print '(a,f6.3,a,f6.3)', 'alpha posterior: ', mu_post, ' +- ', s_post

  ! ---- 3. MLE variance bias, sigma2 = 4, N = 5
  call random_seed(size=nseed);  allocate(seed(nseed));  seed = 19
  call random_seed(put=seed)
  acc_ml = 0.0_dp;  acc_un = 0.0_dp
  do k = 1, nsets
     call normal_deviates(x)
     x = 2.0_dp * x                                  ! sigma = 2
     xbar = sum(x) / N
     acc_ml = acc_ml + sum((x - xbar)**2) / N
     acc_un = acc_un + sum((x - xbar)**2) / (N - 1)
  end do
  print '(a,f6.3,a,f6.3,a)', '<s2_ML> = ', acc_ml/nsets, '   <s2_unbiased> = ', acc_un/nsets, &
        '   (theory 3.200 and 4.000)'
end program bayes_basics
