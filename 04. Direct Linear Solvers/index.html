04. Direct Linear Solvers/

Roots of x² + bx + 1 = 0 with |b| large: the textbook formula subtracts two almost equal numbers and loses almost all its digits.

Above: move b and compare the naive and the stable formula in single and double precision.

Numerical analysis is not only finding a solution: it is knowing how accurate and how reliable that solution is.
  • Three requirements: accuracy, stability, efficiency
  • Bisection vs Newton–Raphson
  • Stopping criteria
  • Catastrophic cancellation
  • Overflow in intermediate steps

BASICThree questions for every algorithm

  1. Accuracy: how close is the computed answer to the true one, compared with the floating-point precision?
  2. Stability: are the unavoidable rounding errors kept small, or amplified during the computation?
  3. Efficiency: how many floating-point operations (flops) and how much memory does it need?

They will be asked of root finders, linear systems, optimisers, differential-equation solvers and inverse problems alike.

BASICIterative root finding and stopping criteria

ALGORITHMNewton–Raphson iterationhover the symbols ↓
\h{xk}{x_{k+1}}=x_k-\frac{\h{fx}{f(x_k)}}{f'(x_k)},\qquad \text{stop when } |f(x_k)|<\varepsilon\ \ \text{or}\ \ \frac{|x_k-x_{k-1}|}{|x_k|}<\varepsilon\ \ \text{or}\ \ k=k_{\max}
Bisection halves an interval with a sign change: always converges, one binary digit per step (linear). Newton doubles the number of correct digits per step near the root (quadratic) but needs a good start and f′ ≠ 0. For f = x² − 10x + 9, root 9 to 10⁻¹²: bisection 42 iterations, Newton from x₀ = 12: 6.
x = 12.0
while True:
    x_new = x - f(x) / df(x)
    if abs(x_new - x) / abs(x_new) < 1e-12: break
    x = x_new
x = 12.0_dp
do
   xn = x - f(x)/df(x)
   if (abs(xn - x)/abs(xn) < 1.0e-12_dp) exit
   x = xn
end do

CORECatastrophic cancellation

ALGORITHMStable quadratic rootshover the symbols ↓
u=-b-\mathrm{sgn}(b)\sqrt{b^2-4ac},\qquad x_1=\frac{u}{2a},\qquad x_2=\frac{c}{a\,x_1}
With b² ≫ 4ac the naive −b + √(b²−4ac) subtracts two nearly equal numbers. The stable form only adds numbers of the same sign and gets the second root from the product x₁x₂ = c/a. Measured (a = c = 1): at |b| = 1.6×10⁴ the naive small root has 100% error in float32; at |b| = 10⁸ still 25% error in float64. The stable formula stays at rounding level.
u = -b - np.sign(b) * np.sqrt(b*b - 4*a*c)
x1 = u / (2*a);  x2 = c / (a*x1)
u  = -b - sign(1.0_dp, b)*sqrt(b*b - 4*a*c)
x1 = u/(2*a);  x2 = c/(a*x1)

Intermediate overflow: √(a² + b²) with a = b = 10²⁰⁰ is 1.4×10²⁰⁰, well inside the double range, yet a² overflows to ∞. Use hypot(a, b) (Fortran 2008: hypot, or norm2), which rescales internally. Instability can hide in any intermediate step, not only in the final formula.

Discretised differential equations, least-squares fits, implicit time steps, map-making: all end in Ax = b with n from a few to billions.

We never need A⁻¹ or det(A) to solve Ax = b. We need a triangular system — which is trivial to solve.

FORMULACramer's rulehover the symbols ↓
x_i=\frac{\det(\h{A}{A}_i)}{\det(\h{A}{A})},\qquad \det(A)=\h{sum}{\sum_{\sigma\in S_n}}\mathrm{sgn}(\sigma)\h{prod}{\prod_{i=1}^n}a_{i,\sigma(i)}
Ai: A with column i replaced by b. n + 1 determinants, each a sum over n! permutations: about (n+1)! products. Measured: n = 8 takes 2 s (LU: 0.2 ms); n = 20 would take ~1600 years at 1 Gflop/s.
for p in itertools.permutations(range(n)):       # n! terms
    s += sign(p) * np.prod([A[i, p[i]] for i in range(n)])
! do not: the cost is (n+1)! — use dgesv (LU) instead

COREWhy determinants are numerically dangerous

  • Scaling: det(cA) = cⁿ det(A). A 400×400 matrix with entries ~10 has |det| ≈ 10832: overflow, although the system is perfectly well behaved. Its log-determinant (1914.9) is fine.
  • Cancellation: det = Σ₊ − Σ₋, two huge sums of products that nearly cancel.
  • Small det ≠ ill-conditioned: 10⁻³·I has det 10−3n and is perfectly conditioned (Lecture 5).

BASICWhat we actually compute

Not A⁻¹ (three times more work and more rounding), not det(A). The target is an equivalent triangular system Ux = y, obtained by operations that do not change the solution.

Subtract multiples of the pivot row to zero the column below the diagonal, column after column. With a tiny pivot the multipliers are huge and the rounding of large numbers wipes out the small ones.

Partial pivoting picks the largest entry of the column as pivot: every multiplier satisfies |mik| ≤ 1, so intermediate entries cannot blow up.

COREForward reduction

ALGORITHMElimination step khover the symbols ↓
\h{mik}{m_{ik}}=\frac{a^{(k)}_{ik}}{a^{(k)}_{kk}},\qquad a^{(k+1)}_{ij}=a^{(k)}_{ij}-m_{ik}\,a^{(k)}_{kj},\qquad b^{(k+1)}_i=b^{(k)}_i-m_{ik}\,b^{(k)}_k,\qquad i,j>k
Allowed operations: scale a row, subtract a multiple of one row from another, swap rows. They change the matrix but not the solution. Cost: Σ(n−k)² · 2 ≈ (2/3)n³ flops.
for k in range(n - 1):
    for i in range(k + 1, n):
        m = A[i, k] / A[k, k]
        A[i, k:] -= m * A[k, k:];  b[i] -= m * b[k]
do k = 1, n-1
   do i = k+1, n
      m = A(i,k)/A(k,k)
      A(i,k:n) = A(i,k:n) - m*A(k,k:n);  b(i) = b(i) - m*b(k)
   end do
end do

ALGORITHMPartial pivotinghover the symbols ↓
p_k=\arg\max_{k\le i\le n}\big|a^{(k)}_{ik}\big|,\quad \text{swap rows }k\leftrightarrow p_k\ \text{in }A\text{ and }b\ \ \Longrightarrow\ \ |\h{mik}{m_{ik}}|\le1
Search cost O(n²) in total, negligible. Full pivoting searches the whole trailing block (O(n³) comparisons), swaps rows and columns and must record the column order q to unscramble x. Theoretically more stable; in practice partial pivoting is the standard (LAPACK dgesv). Random 60×60: errors 2.7×10⁻¹³ (none), 6.2×10⁻¹⁵ (partial), 8.4×10⁻¹⁵ (full).

A[[k, p]] = A[[p, k]];  b[[k, p]] = b[[p, k]]
p = k - 1 + maxloc(abs(A(k:n,k)), dim=1)
tmp = A(k,:); A(k,:) = A(p,:); A(p,:) = tmp
t = b(k); b(k) = b(p); b(p) = t
RESULTDeterminant from the eliminationhover the symbols ↓
\det(A)=(-1)^{p}\h{prod}{\prod_{i=1}^n}u_{ii}\qquad(p=\text{number of row swaps})
Adding a multiple of a row leaves det unchanged, a swap flips its sign. O(n) extra work after the (2/3)n³ reduction, against O(n!) for the cofactor expansion. For big matrices compute log|det| = Σ log|uii| to avoid overflow.

Gaussian elimination works on [A | b] together: a new b means starting again. LU stores the elimination itself — L holds the multipliers, U the reduced matrix — so b can come later.

Step through the factorisation above: watch the multipliers fill the zeros they create.

Factor once (O(n³)), solve many times (O(n²)). Memory: L and U overwrite A, P is an integer array.

THEOREMPivoted LU factorisationhover the symbols ↓
\h{P}{P}\h{A}{A}=\h{L}{L}\h{U}{U},\qquad L=\begin{bmatrix}1&&&\\ l_{21}&1&&\\ \vdots&&\ddots&\\ l_{n1}&\cdots&l_{n,n-1}&1\end{bmatrix},\quad l_{ik}=m_{ik}
For every non-singular A there is a permutation P with PA = LU, and with lii = 1 (Doolittle) the factors are unique (Crout fixes uii = 1 instead). Unpivoted A = LU exists only if all leading principal minors are non-zero: A = [[0, 1], [1, 0]] is invertible but has no LU.
lu, piv = scipy.linalg.lu_factor(A)      # LAPACK dgetrf
x = scipy.linalg.lu_solve((lu, piv), b)  # LAPACK dgetrs
call dgetrf(n, n, A, n, ipiv, info)              ! A <- L\U in place
call dgetrs('N', n, 1, A, n, ipiv, b, n, info)   ! b <- x

COREThe algorithm, in place

def lu_inplace(A):
    A = A.copy(); n = A.shape[0]; p = np.arange(n)
    for k in range(n - 1):
        r = k + np.argmax(np.abs(A[k:, k]))
        A[[k, r]] = A[[r, k]]; p[[k, r]] = p[[r, k]]
        A[k+1:, k] /= A[k, k]                              # multipliers l_ik
        A[k+1:, k+1:] -= np.outer(A[k+1:, k], A[k, k+1:])   # trailing update
    return A, p
do k = 1, n
  r = k - 1 + maxloc(abs(a(k:n,k)), dim=1);  piv(k) = r
  if (r /= k) then; tmp = a(k,:); a(k,:) = a(r,:); a(r,:) = tmp; end if
  if (k == n) exit
  a(k+1:n,k) = a(k+1:n,k) / a(k,k)
  do j = k+1, n                      ! column-oriented: Fortran is column-major
    a(k+1:n,j) = a(k+1:n,j) - a(k+1:n,k)*a(k,j)
  end do
end do

Solving with the factors

  1. Permute: b̃ = Pb (apply the recorded swaps).
  2. Forward substitution Ly = b̃: n² − n flops, no divisions.
  3. Back substitution Ux = y: n² flops.

Measured, n = 800, 50 right-hand sides: 968 ms re-solving from scratch each time, 38 ms factoring once. Our hand-written LU matches LAPACK: ‖PA − LU‖/‖A‖ = 2×10⁻¹⁵, max |lik| = 1.

RESULTInverse via LU (only when explicitly needed)hover the symbols ↓
A\,X=I\ \Rightarrow\ LU\,\mathbf x_i=P\mathbf e_i,\quad \text{cost }\tfrac23n^3+n\cdot2n^2=\tfrac83n^3;\qquad \text{LAPACK getri: }A^{-1}=U^{-1}L^{-1}P,\ \ 2n^3
To solve a system never form A⁻¹: inv(A) @ b costs more and is less accurate (n = 200: 1.9×10⁻¹² vs 8.8×10⁻¹³). Needed explicitly e.g. for a covariance matrix = inverse of a Fisher matrix (Lecture 12).

# ---------------------------------------------------------------- 1. quadratic cancellation
print("1. roots of x^2 + b x + 1 = 0: relative error of the small root")
print(f"{'b':>8} {'naive f32':>11} {'stable f32':>11} {'naive f64':>11} {'stable f64':>11}")
bs = np.logspace(1, 8, 36)
errs = {k: [] for k in ("n32", "s32", "n64", "s64")}
for b in bs:
    b = -b
    exact = 1.0 / (-b / 2 + math.sqrt(b * b / 4 - 1))            # small root, computed stably in extended reasoning
    for dt, tag in ((np.float32, "32"), (np.float64, "64")):
        a_, b_, c_ = dt(1), dt(b), dt(1)
        disc = np.sqrt(b_ * b_ - dt(4) * a_ * c_)
        naive = (-b_ - disc) / (dt(2) * a_)                          # the root that suffers cancellation
        u = -b_ - np.sign(b_) * disc
        x1 = u / (dt(2) * a_)
        stable = c_ / (a_ * x1)
        errs["n" + tag].append(abs(float(naive) - exact) / exact)
        errs["s" + tag].append(abs(float(stable) - exact) / exact)
for i in (0, 8, 16, 24, 35):
    print(f"{bs[i]:8.1e} {errs['n32'][i]:11.2e} {errs['s32'][i]:11.2e} {errs['n64'][i]:11.2e} {errs['s64'][i]:11.2e}")
with np.errstate(over="ignore"):

print("   overflow in an intermediate step, a = b = 1e200: sqrt(a^2 + b^2) =", naive_c, "; math.hypot(a, b) =", math.hypot(1e200, 1e200))

    a, b = (a, m) if f(a) * f(m) <= 0 else (m, b)
    k += 1

    if abs(xn - x) / abs(xn) < 1e-12: break

print(f"\n2. root x = 9 to 1e-12: bisection {k} iterations ({0.5 * (a + b):.13f}), Newton {kn} iterations ({xn:.13f})")

def det_leibniz(A):
    n = A.shape[0]; s = 0.0
    for p in itertools.permutations(range(n)):
        inv = sum(1 for i in range(n) for j in range(i + 1, n) if p[i] > p[j])
        s += (-1) ** inv * np.prod([A[i, p[i]] for i in range(n)])
    return s

    for i in range(len(b)):
        Ai = A.copy(); Ai[:, i] = b; x[i] = det_leibniz(Ai) / d
    return x

# ---------------------------------------------------------------- 4. pivoting
def gauss(A, b, pivot="partial"):
    A = A.astype(float).copy(); b = b.astype(float).copy(); n = len(b); q = np.arange(n)
    for k in range(n - 1):
        if pivot == "partial":
            p = k + np.argmax(np.abs(A[k:, k])); A[[k, p]] = A[[p, k]]; b[[k, p]] = b[[p, k]]
        elif pivot == "full":
            sub = np.abs(A[k:, k:]); p, r = np.unravel_index(np.argmax(sub), sub.shape); p += k; r += k
            A[[k, p]] = A[[p, k]]; b[[k, p]] = b[[p, k]]; A[:, [k, r]] = A[:, [r, k]]; q[[k, r]] = q[[r, k]]
        for i in range(k + 1, n):
            m = A[i, k] / A[k, k]; A[i, k:] -= m * A[k, k:]; b[i] -= m * b[k]
    x = np.zeros(n)
    for i in range(n - 1, -1, -1):
        x[i] = (b[i] - A[i, i + 1:] @ x[i + 1:]) / A[i, i]
    out = np.empty(n); out[q] = x
    return out

# ---------------------------------------------------------------- 5. PA = LU from scratch
def lu_inplace(A):
    A = A.astype(float).copy(); n = A.shape[0]; p = np.arange(n); swaps = 0
    for k in range(n - 1):
        r = k + np.argmax(np.abs(A[k:, k]))
        if A[r, k] == 0: raise np.linalg.LinAlgError("singular")
        if r != k: A[[k, r]] = A[[r, k]]; p[[k, r]] = p[[r, k]]; swaps += 1
        A[k + 1:, k] /= A[k, k]                                      # multipliers l_ik stored in place
        A[k + 1:, k + 1:] -= np.outer(A[k + 1:, k], A[k, k + 1:])    # update of the trailing submatrix
    return A, p, swaps


def lu_solve(LU, p, b):
    n = len(b); y = b[p].astype(float).copy()
    for i in range(1, n): y[i] -= LU[i, :i] @ y[:i]                 # forward, unit diagonal: no division
    x = y.copy()
    for i in range(n - 1, -1, -1): x[i] = (y[i] - LU[i, i + 1:] @ x[i + 1:]) / LU[i, i]
    return x

# ---------------------------------------------------------------- 7. Cholesky
def cholesky(A):
    A = A.astype(float).copy(); n = A.shape[0]
    for j in range(n):
        s = A[j, j] - A[j, :j] @ A[j, :j]
        if s <= 0: raise np.linalg.LinAlgError("not positive definite")
        A[j, j] = math.sqrt(s)
        A[j + 1:, j] = (A[j + 1:, j] - A[j + 1:, :j] @ A[j, :j]) / A[j, j]
    return np.tril(A)

# ---------------------------------------------------------------- 8. Thomas algorithm
def thomas(a, b, c, d):
    """a: sub-diagonal (n-1), b: diagonal (n), c: super-diagonal (n-1)."""
    n = len(b); cp = np.empty(n - 1); dp = np.empty(n)
    cp[0] = c[0] / b[0]; dp[0] = d[0] / b[0]
    for i in range(1, n):
        den = b[i] - a[i - 1] * cp[i - 1]
        if i < n - 1: cp[i] = c[i] / den
        dp[i] = (d[i] - a[i - 1] * dp[i - 1]) / den
    x = np.empty(n); x[-1] = dp[-1]
    for i in range(n - 2, -1, -1): x[i] = dp[i] - cp[i] * x[i + 1]
    return x

! lu_cholesky.f90 -- Lecture 4: in-place PA = LU with partial pivoting, forward/back substitution,
! determinant, Cholesky A = L L^T, and a timing comparison with LAPACK (dgetrf/dgetrs, dpotrf).
!
! Build:  gfortran -O2 lu_cholesky.f90 -llapack -lblas -o lu_cholesky && ./lu_cholesky
!         (Linux: sudo apt install liblapack-dev; macOS: brew install lapack, or -framework Accelerate)
!
! Fortran stores arrays by COLUMN: the inner loops below run down a column (first index) for speed.
module direct_solvers
  implicit none
  integer, parameter :: dp = kind(1.0d0)
contains

  ! In-place LU with partial pivoting. On exit: strict lower triangle = multipliers l_ik (unit diagonal
  ! implied), upper triangle = U. piv(k) = row swapped with row k at step k (LAPACK convention).
  subroutine lu_factor(a, piv, nswap)
    real(dp), intent(inout) :: a(:,:)
    integer, intent(out) :: piv(:), nswap
    integer :: n, k, j, r
    real(dp) :: tmp(size(a,1))
    n = size(a,1); nswap = 0
    do k = 1, n
      r = k - 1 + maxloc(abs(a(k:n,k)), dim=1)       ! partial pivoting: largest entry in column k
      piv(k) = r
      if (a(r,k) == 0.0_dp) stop "lu_factor: matrix is singular"
      if (r /= k) then
        tmp = a(k,:); a(k,:) = a(r,:); a(r,:) = tmp; nswap = nswap + 1
      end if
      if (k == n) exit
      a(k+1:n,k) = a(k+1:n,k) / a(k,k)               ! multipliers, |l_ik| <= 1
      do j = k+1, n                                  ! column-oriented rank-1 update of the trailing block
        a(k+1:n,j) = a(k+1:n,j) - a(k+1:n,k) * a(k,j)
      end do
    end do
  end subroutine lu_factor

  subroutine lu_solve(a, piv, b)
    real(dp), intent(in) :: a(:,:)
    integer, intent(in) :: piv(:)
    real(dp), intent(inout) :: b(:)                  ! in: right-hand side, out: solution
    integer :: n, i, k
    real(dp) :: t
    n = size(a,1)
    do k = 1, n                                      ! apply the row swaps to b, in the same order
      if (piv(k) /= k) then
        t = b(k); b(k) = b(piv(k)); b(piv(k)) = t
      end if
    end do
    do i = 2, n                                      ! forward substitution, L has unit diagonal
      b(i) = b(i) - dot_product(a(i,1:i-1), b(1:i-1))
    end do
    do i = n, 1, -1                                  ! back substitution
      b(i) = (b(i) - dot_product(a(i,i+1:n), b(i+1:n))) / a(i,i)
    end do
  end subroutine lu_solve

  ! Cholesky A = L L^T, column by column; L overwrites the lower triangle.
  subroutine cholesky(a)
    real(dp), intent(inout) :: a(:,:)
    integer :: n, j, i
    real(dp) :: s
    n = size(a,1)
    do j = 1, n
      s = a(j,j) - dot_product(a(j,1:j-1), a(j,1:j-1))
      if (s <= 0.0_dp) stop "cholesky: matrix is not positive definite"
      a(j,j) = sqrt(s)
      do i = j+1, n
        a(i,j) = (a(i,j) - dot_product(a(i,1:j-1), a(j,1:j-1))) / a(j,j)
      end do
    end do
    do j = 2, n
      a(1:j-1,j) = 0.0_dp                            ! clear the upper triangle
    end do
  end subroutine cholesky
end module direct_solvers

program lu_cholesky
  use direct_solvers
  implicit none
  integer, parameter :: sizes(3) = [200, 500, 1000]
  real(dp), allocatable :: a(:,:), a0(:,:), x(:), xt(:), b(:), l(:,:)
  integer, allocatable :: piv(:)
  integer :: n, is, nswap, info, i
  integer(8) :: c0, c1, rate
  real(dp) :: t_mine, t_lapack, logdet
  external :: dgetrf, dgetrs, dpotrf

  call random_seed(put=[(42, i = 1, 64)])
  call system_clock(count_rate=rate)
  allocate(a(4,4), piv(4)); call random_number(a); call dgetrf(4, 4, a, 4, piv, info); deallocate(a, piv)  ! warm-up
  print '(a)', "     n   my LU [ms]  LAPACK dgetrf+s [ms]   error mine   error LAPACK   log|det|"
  do is = 1, size(sizes)
    n = sizes(is)
    allocate(a(n,n), a0(n,n), x(n), xt(n), b(n), piv(n))
    call random_number(a0); a0 = a0 - 0.5_dp
    call random_number(xt)
    b = matmul(a0, xt)
    a = a0; x = b
    call system_clock(c0); call lu_factor(a, piv, nswap); call lu_solve(a, piv, x); call system_clock(c1)
    t_mine = 1.0e3_dp * real(c1 - c0, dp) / real(rate, dp)
    logdet = sum(log(abs([(a(i,i), i = 1, n)])))
    a = a0; xt = xt; b = matmul(a0, xt)
    call system_clock(c0)
    call dgetrf(n, n, a, n, piv, info); call dgetrs('N', n, 1, a, n, piv, b, n, info)
    call system_clock(c1)
    t_lapack = 1.0e3_dp * real(c1 - c0, dp) / real(rate, dp)
    print '(i6, f12.1, f22.1, es14.2, es15.2, f11.2)', n, t_mine, t_lapack, maxval(abs(x - xt)), maxval(abs(b - xt)), logdet
    deallocate(a, a0, x, xt, b, piv)
  end do

  ! Cholesky on an SPD matrix S = M M^T + n I
  n = 400
  allocate(a(n,n), l(n,n))
  call random_number(a); a = a - 0.5_dp
  l = matmul(a, transpose(a))
  do i = 1, n
    l(i,i) = l(i,i) + n
  end do
  a = l
  call cholesky(l)
  print '(/,a,i0,a,es10.2)', "Cholesky n = ", n, ": max |S - L L^T| = ", maxval(abs(a - matmul(l, transpose(l))))
  call dpotrf('L', n, a, n, info)
  print '(a,es10.2)', "  difference from LAPACK dpotrf: ", maxval(abs([(a(i,i) - l(i,i), i = 1, n)]))
end program lu_cholesky
