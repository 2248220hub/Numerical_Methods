Computational Methods in Astrophysics

An open, interactive study guide to the numerical methods of astrophysics: linear systems and their solvers, signals and spectra, Fourier transforms, convolution, spectral estimation, signals on the sphere, Bayesian inference and Monte Carlo. Every formula is hoverable (name, meaning, Python, Fortran), every idea has a widget to play with, and every unit ends with tested code. A hyperspectral-imaging project applies all of it to real data.

HOW TOUse this site

  1. Learn — open a unit. The bar at the top (“In this lesson”) stays visible while you scroll; each lesson starts with a widget and a short story in the right panel. Use ← → to move between lessons.
  2. Hover the maths — every symbol that lights up shows its name, why it matters, and the same thing in Python and Fortran. Click to pin the card.
  3. Practice (top tab) — all exercises of the unit on one page, checked automatically (fractions like 1/3 are accepted).
  4. Code Lab (top tab) — all code of the unit; the full, tested files are in each unit's code folder.
  5. Cheatsheet (top tab) — every formula of the unit on one page.
  6. Project — the orange buttons at the end of a concept jump to the matching part of the hyperspectral project (last unit).

Each unit is self-contained: the first lessons are written for a complete beginner, the later parts (marked EXPERT) go deeper. Lessons marked “soon” are added as the course notes become available.

CREDITSSources

The units follow the structure and notation of the lecture notes of Computing Methods for Astrophysics by G. de Gasperis and L. Graziani (Sapienza University of Rome). Explanations, widgets, exercises and code are written for this guide; references to the original papers and books are given in each lesson.
