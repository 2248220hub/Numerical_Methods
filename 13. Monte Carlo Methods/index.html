13. Monte Carlo Methods/

Lecture 12 ended with a problem: every Bayesian answer is an integral over the posterior, and a grid costs Kd.

Monte Carlo: evaluate the function at random points. Start with the simplest version — throw darts at a square and count how many land in the circle.

A Monte Carlo result always comes with its error bar, computed from the same samples at no extra cost. A result without it is not a Monte Carlo result.

BASICThe problem: integrals we cannot put on a grid

THE PROBLEMPosterior expectationshover the symbols ↓
\h{E}{\mathbb E}[g(\theta)\mid x] = \h{integral}{\int} g(\theta)\,\h{post}{p(\theta\mid x)}\dd\theta
Means, variances, intervals, marginals: all integrals. Grid with K points per axis: Kd evaluations (30 µs each for the knee: 4 s for d = 3, 3 hours for d = 5, 9 months for d = 7) and 2462 of 10⁶ points (0.25%) hold 99% of the mass.

Monte Carlo = a wide class of algorithms that obtain numerical results by repeated random sampling. The name dates from the 1940s at Los Alamos (Ulam, von Neumann, Metropolis — after the casino). Key idea: use randomness to solve problems that may be deterministic. For integration: evaluate the function at random points. It needs only the ability to evaluate the integrand, and it shines in many dimensions. Used “backwards”, the same idea simulates: noise records, sky maps, detector responses — every simulated record of the knee is a Monte Carlo sample.

Three approaches to \(I=\int_a^b f(x)\,{\rm d}x\): (1) hit-or-miss (geometric), (2) sample mean (mean-value theorem), (3) importance sampling (sample mean with points where they matter — needs sampling from a distribution, hence part II of the lecture).

BASICHit-or-miss

Area of an irregular figure A inside a box of known area Abox: throw N points uniformly in the box, count the Nin inside.

ESTIMATORHit-or-miss estimatorhover the symbols ↓
\h{I}{I}\approx \h{Abox}{A_{\rm box}}\,\frac{\h{Nin}{N_{\rm in}}}{\h{N}{N}}
Classic example: π from a circle inscribed in a square. In the quarter-circle version the fraction of hits estimates π/4.
x, y = rng.random(n), rng.random(n)
p_hat = np.mean(x**2 + y**2 < 1.0)
pi_hat = 4.0 * p_hat
call random_number(x);  call random_number(y)
p_hat  = count(x**2 + y**2 < 1.0_dp) / real(n, dp)
pi_hat = 4.0_dp * p_hat

COREThe error of hit-or-miss

Each point is a Bernoulli trial with success probability p = A/Abox (unknown, estimated by p̂ = Nin/N). The number of successes is binomial with variance Np(1−p). Propagate to I = Abox Nin/N:

RESULTStandard error (hit-or-miss)hover the symbols ↓
\h{dI}{\delta I}\simeq\frac{\h{Abox}{A_{\rm box}}}{\sqrt{\h{N}{N}}}\sqrt{\h{phat}{\hat p}(1-\h{phat}{\hat p})},\qquad \frac{\h{dI}{\delta I}}{\h{I}{I}}\simeq\sqrt{\frac{1-\h{phat}{\hat p}}{\h{phat}{\hat p}\,\h{N}{N}}}
p replaced by p̂: the same points give the error. Quarter circle, 1500 points: Nin = 1164, p̂ = 0.776, π ≈ 3.104 ± 0.043. The absolute error is largest at p = ½; the relative error grows without bound as p → 0: a small figure in a big box needs ~1/p points just to be hit once.
err = 4.0 * np.sqrt(p_hat * (1 - p_hat) / n)
err = 4.0_dp*sqrt(p_hat*(1.0_dp - p_hat)/n)

The area under f equals (width) × (mean height). Estimate the mean height by averaging f at random points.

The error bar comes from the spread of the f values themselves.

δI = V σf/√N: ten times more precision costs a hundred times more points — but nothing in the formula knows the dimension.

BASICThe estimator

DEFINITIONMean value of a functionhover the symbols ↓
\h{fmean}{\langle f\rangle}=\frac{1}{\h{ab}{b-a}}\h{integral}{\int_a^b} f(x)\dd x\quad\Longrightarrow\quad \h{I}{I}=\h{ab}{(b-a)}\,\h{fmean}{\langle f\rangle}
ESTIMATORSample-mean Monte Carlohover the symbols ↓
\h{IN}{I_N}=\h{ab}{(b-a)}\frac1{\h{N}{N}}\h{sum}{\sum_{i=1}^{N}} f(\h{xi}{x_i}),\qquad \h{xi}{x_i}\sim U(a,b)
In d dimensions (b − a) becomes the volume V of the domain and xi is a d-vector: only the shape of the array changes.
def mc_integrate(func, a, b, n, rng):
    x = rng.uniform(a, b, n)
    y = func(x)
    return (b - a) * y.mean(), (b - a) * y.std(ddof=1) / np.sqrt(n)
call random_number(x);  x = a + (b - a)*x
fx  = x**2
est = (b - a)*sum(fx)/n
err = (b - a)*sqrt(sum((fx - sum(fx)/n)**2)/(n - 1))/sqrt(real(n, dp))

COREIts error, from the same samples

  1. IN is (b−a) times a mean of N independent random variables f(xi).
  2. Variance of a mean of N i.i.d. variables = (variance of one)/N: \(\sigma_I^2=(b-a)^2\sigma_f^2/N\).
  3. σf is unknown: estimate it with the same samples, \(\hat\sigma_f^2=\frac1{N-1}\sum(f_i-\bar f)^2\).
  4. Central limit theorem: for large N, IN is Gaussian around I with that width.
RESULTStatistical error of Monte Carlohover the symbols ↓
\h{dI}{\delta I}=\frac{\h{ab}{b-a}}{\sqrt{\h{N}{N}}}\,\h{sigf}{\hat\sigma_f},\qquad \h{sigf}{\sigma_f^2}=\langle f^2\rangle-\langle f\rangle^2,\qquad \h{IN}{I_N}\sim\mathcal N(I,\delta I^2)
Requirement: σf finite (a heavy-tailed f can break it). Every Monte Carlo result comes with its error bar at no extra cost.
err = (b - a) * y.std(ddof=1) / np.sqrt(n)
err = (b - a)*sqrt(sum((fx - sum(fx)/n)**2)/(n - 1))/sqrt(real(n, dp))

Worked example: where does 2.385/√N come from?

f = x² with x uniform on [0, 2]: \(\langle f\rangle=\frac12\int_0^2x^2=\frac43\), \(\langle f^2\rangle=\frac12\int_0^2x^4=\frac{16}{5}=3.2\), so \(\sigma_f^2 = 3.2-\frac{16}9 = 1.4222\), σf = 1.1926, and (b−a)σf = 2.385. The lecture measured exactly 2.385/√N.

A grid rule of order k has error N−k/d: excellent in 1-D, hopeless in 10-D. Monte Carlo is N−1/2 always.

Above: Simpson against Monte Carlo on a smooth product integrand. Raise d and watch the lines cross.

Almost all the volume of a high-dimensional cube is in its corners. A posterior is like the inscribed ball: uniform points never hit it. We need points drawn where the distribution is.

COREHow errors scale

SCALINGMonte Carlo vs product gridhover the symbols ↓
\text{MC: }\ \h{dI}{\delta I}\propto\frac{\h{sigf}{\sigma_f}}{\sqrt{\h{N}{N}}}\quad\text{(any } d),\qquad\text{grid of order }\h{kord}{k}:\ \ \h{dI}{\delta I}\propto \h{N}{N}^{-\h{kord}{k}/\h{d}{d}}
A 1-D rule with error ∝ n−k (trapezoid k = 2, Simpson k = 4) on a product grid of N = nd points has error ∝ N−k/d. Simpson: N⁻⁴ in 1-D, N⁻¹ in 4-D, N−½ in 8-D. Monte Carlo becomes competitive when k/d < ½, i.e. d > 2k: d > 4 (trapezoid), d > 8 (Simpson).
# appendix A: MC error = V sigma_f / sqrt(N) by independence alone, no d in the argument
err_mc   = sigma_f / np.sqrt(N)
err_grid = C * N ** (-k / d)
err_mc   = sigma_f / sqrt(real(N, dp))
err_grid = C * real(N, dp)**(-real(k, dp)/d)

Measured on \(\int_{[0,1]^d}\prod_i\frac\pi2\sin(\pi x_i)=1\) (σf² = (π²/8)d − 1): d ≤ 4 Simpson wins by orders of magnitude; d = 8 same slope, Monte Carlo 3–17 times more accurate, and needs no grid (Simpson needs at least 3⁸ = 6561 points to start). σf grows with d (0.48 at d = 1, 2.1 at d = 8): the error does not depend on d through N, but the prefactor can. The price of Monte Carlo: it does not exploit smoothness (quasi-Monte Carlo and variance reduction try to recover part of it).

EXPERTFew or no hits: intervals that don't lie

With 0 hits the Gaussian formula gives p̂ = 0 ± 0 — “exactly zero, no uncertainty”. Wrong. Use the binomial distribution itself:

INTERVALWilson score intervalhover the symbols ↓
\text{all } \h{p}{p}\ \text{with}\ \ |\h{phat}{\hat p}-\h{p}{p}|\le 1.96\sqrt{\h{p}{p}(1-\h{p}{p})/\h{N}{N}}\qquad(\text{0 hits: } [0,\ 3.84/N])

BASICInversion

Uniform points waste effort where f ≈ 0. Draw them from a proposal g shaped like f, and correct each point with a weight w = f/g.

Above: three bumps on [−4, 4]. Change the proposal width and watch the error over repeated runs.

The proposal must have heavier tails than the target. Otherwise the variance can be infinite while every single run looks fine — check the largest weight.

  • Weights and their error bar
  • Optimal g ∝ |f|: zero variance
  • Choosing a width: too narrow is worse than uniform

COREThe method

ESTIMATORImportance samplinghover the symbols ↓
\h{I}{I}=\h{integral}{\int} f(x)\dd x=\h{integral}{\int}\frac{f(x)}{\h{g}{g(x)}}\,\h{g}{g(x)}\dd x=\h{Eg}{\mathbb E_g}\!\left[\frac fg\right]\approx\frac1{\h{N}{N}}\h{sum}{\sum_i}\h{w}{w_i},\quad \h{w}{w_i}=\frac{f(x_i)}{\h{g}{g(x_i)}},\ x_i\sim \h{g}{g}
g must be a density with g > 0 wherever f ≠ 0 (support condition). The weight corrects for non-uniform sampling: points drawn often (g large) count less. Error as before from the spread of the weights: δI = σ̂w/√N. Uniform sampling is the special case g = 1/(b−a).
def importance_sampling(f, g_pdf, g_draw, n, rng):
    x = g_draw(n, rng)           # 1. samples from g
    w = f(x) / g_pdf(x)          # 2. weights f/g
    return w.mean(), w.std(ddof=1) / np.sqrt(n)
x = draw_from_g(n)               ! 1.
w = f(x) / g(x)                  ! 2. elemental functions
est = sum(w)/n
err = sqrt(sum((w - est)**2)/(n - 1))/sqrt(real(n, dp))

COREHow to choose g

THEOREMOptimal proposalhover the symbols ↓
\h{g}{g^*(x)}=\frac{|f(x)|}{\h{integral}{\int}|f|\dd x}\quad\Rightarrow\quad \h{w}{w_i}=I\ \ \forall i\ \ (f\ge0):\ \text{zero variance}
Needs I itself — what we're computing. In practice: a g easy to sample (Gaussian, exponential, Student t) that roughly matches the shape of f, with heavier tails. Three bumps, g = 𝒩(0, s²): s = 0.5 → 1.95% (worse than uniform's 1.75%: tails too light), s = 0.7 → 0.59% (best), s = 1 → 0.69%, s = 2 → 1.3%. Variance reduced 6.5× with a rough match.

"""
importance.py  --  Lecture 13, parts III-IV: importance sampling
  A. three bumps: uniform vs Gaussian proposals of several widths
  B. a rare event, P(X > 4), with a shifted-exponential proposal
  C. tails: integral of a Student t3 with a Gaussian (fails) and a Cauchy proposal
  D. self-normalised importance sampling of a posterior + effective sample size
  E. why it collapses: ESS/N versus dimension
Run:  python importance.py   -> prints numbers, saves importance.png
"""
import numpy as np
from scipy import stats
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

rng = np.random.default_rng(2027)


def importance_sampling(f, g_pdf, g_draw, n, rng):
    x = g_draw(n, rng)              # 1. samples from g
    w = f(x) / g_pdf(x)             # 2. weights f/g
    return w.mean(), w.std(ddof=1) / np.sqrt(n), w


# ---------------------------------------------------------------- A. three bumps
def bumps(x):
    return (np.exp(-0.5 * ((x + 1.5) / 0.3) ** 2) + 2 * np.exp(-0.5 * (x / 0.25) ** 2)
            + 1.5 * np.exp(-0.5 * ((x - 1.2) / 0.35) ** 2))


I_true = np.sqrt(2 * np.pi) * (0.3 + 2 * 0.25 + 1.5 * 0.35)
n, runs = 10**4, 300
print("A. three bumps, N=1e4, relative rms error over", runs, "runs")
res = [rng.uniform(-4, 4, n) for _ in range(runs)]
rel = np.std([8 * bumps(x).mean() for x in res]) / I_true
print(f"   uniform on [-4,4]        : {100*rel:.2f}%")
for s in (0.5, 0.7, 1.0, 2.0):
    est = [importance_sampling(bumps, stats.norm(0, s).pdf,
                               lambda m, r: r.normal(0, s, m), n, rng)[0] for _ in range(runs)]
    print(f"   Gaussian proposal s={s:<4}: {100*np.std(est)/I_true:.2f}%")

# ---------------------------------------------------------------- B. rare event
lam = 4.0
I, err, w = importance_sampling(
    f=stats.norm.pdf,
    g_pdf=lambda x: lam * np.exp(-lam * (x - 4)),
    g_draw=lambda m, r: 4 + r.exponential(1 / lam, m),
    n=10**4, rng=rng)
plain = np.mean(rng.standard_normal(10**6) > 4)
print(f"B. P(X>4): IS (1e4 pts) {I:.4e} +- {err:.1e}  | plain MC (1e6 pts) {plain:.2e}"
      f" | exact {stats.norm.sf(4):.4e}")

# ---------------------------------------------------------------- C. tails
t3 = stats.t(3).pdf
for name, prop in (("Gaussian (lighter tails)", stats.norm(0, 1)), ("Cauchy (heavier tails)", stats.cauchy())):
    errs, wmax = [], []
    for _ in range(200):
        I, _, w = importance_sampling(t3, prop.pdf, lambda m, r: prop.rvs(size=m, random_state=r), 10**4, rng)
        errs.append(abs(I - 1)); wmax.append(w.max() / w.sum())
    print(f"C. {name:26s}: median error {np.median(errs):.4f}, worst {np.max(errs):.3f},"
          f" largest weight up to {100*np.max(wmax):.2f}% of the total")

# ---------------------------------------------------------------- D. self-normalised
# a skewed 1-D "posterior" known up to a constant: q(t) = exp(-ln-normal shape)
def log_q(t):                        # unnormalised log-posterior (a lognormal in t > 0)
    lt = np.log(np.where(t > 0, t, 1.0))           # safe log (value unused where t <= 0)
    return np.where(t > 0, -lt - 0.5 * (lt / 0.4) ** 2, -np.inf)


# Laplace proposal: mode and curvature of log q
grid = np.linspace(1e-3, 6, 200001)
lq = log_q(grid)
mode = grid[np.argmax(lq)]
h = 1e-4
H = -(log_q(mode + h) - 2 * log_q(mode) + log_q(mode - h)) / h**2
print(f"D. Laplace proposal: mode {mode:.4f}, sigma {1/np.sqrt(H):.4f}")
true_mean = np.exp(0.4**2 / 2)
for scale in (1.0, 1.5, 2.5):
    g = stats.norm(mode, scale / np.sqrt(H))
    t = g.rvs(size=5000, random_state=rng)
    lw = log_q(t) - g.logpdf(t)                    # ln w = ln q - ln g
    w = np.exp(lw - lw.max())                      # subtract the max, then exp
    mean = np.sum(w * t) / np.sum(w)               # self-normalised: Z cancels
    neff = w.sum() ** 2 / np.sum(w**2)
    print(f"   proposal x{scale}: mean {mean:.4f} (exact {true_mean:.4f}), Neff/N {neff/5000:.2f},"
          f" largest weight {100*w.max()/w.sum():.2f}%")

# ---------------------------------------------------------------- E. ESS vs dimension
print("E. target N(0,I_d), proposal N(0, s^2 I_d):  ESS/N = [s^2/sqrt(2 s^2 - 1)]^(-d)")
ds = np.arange(1, 101)
for s in (1.2, 2.0):
    theory = (s**2 / np.sqrt(2 * s**2 - 1)) ** (-ds)
    d = 20
    x = rng.normal(0, s, (10**5, d))
    lw = stats.norm.logpdf(x).sum(1) - stats.norm(0, s).logpdf(x).sum(1)
    w = np.exp(lw - lw.max())
    print(f"   s={s}: d=20 measured {w.sum()**2/np.sum(w**2)/1e5:.2e}, theory {theory[19]:.2e};"
          f"  d=100 theory {theory[-1]:.2e}")
    plt.semilogy(ds, theory, label=f"proposal width {s}")
plt.axhline(1e-5, color="k", ls=":", label="ESS = 1 (N = 1e5)")
plt.xlabel("dimension d"); plt.ylabel("ESS / N"); plt.legend(); plt.title("importance sampling collapses with d")
plt.savefig("importance.png", dpi=120)
print("saved importance.png")

"""
mc_integrals.py  --  Lecture 13, part I: Monte Carlo integration
  1. hit-or-miss: pi from a quarter circle, with its binomial error
  2. sample mean: integral of x^2 on [0,2], error from the SAME samples
  3. rms error versus N  (the 1/sqrt(N) law), hit-or-miss vs sample mean
  4. grid (Simpson) versus Monte Carlo in d dimensions
  5. the empty cube: volume of the unit ball by hit-or-miss, Wilson interval
Run:  python mc_integrals.py      -> prints numbers, saves mc_integrals.png
"""
import numpy as np
from scipy.special import gamma
from scipy.stats import binomtest
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

rng = np.random.default_rng(13)          # one seed, written down


# ---------------------------------------------------------------- 1. hit-or-miss
def hit_or_miss_pi(n, rng):
    x, y = rng.random(n), rng.random(n)
    p_hat = np.mean(x**2 + y**2 < 1.0)       # fraction of hits in the unit square
    pi_hat = 4.0 * p_hat                     # A_box = 1, quarter circle = pi/4
    err = 4.0 * np.sqrt(p_hat * (1 - p_hat) / n)
    return pi_hat, err


pi_hat, err = hit_or_miss_pi(1500, rng)
print(f"1. hit-or-miss, N=1500: pi = {pi_hat:.3f} +- {err:.3f}")


# ---------------------------------------------------------------- 2. sample mean
def mc_integrate(func, a, b, n, rng):
    x = rng.uniform(a, b, n)                 # n points in [a, b]
    y = func(x)
    I = (b - a) * y.mean()
    err = (b - a) * y.std(ddof=1) / np.sqrt(n)
    return I, err


I, err = mc_integrate(lambda x: x**2, 0, 2, 10**4, rng)
print(f"2. sample mean, N=1e4: I = {I:.4f} +- {err:.4f}   (exact 8/3 = 2.6667)")
print(f"   predicted error 2.385/sqrt(N) = {2.385/np.sqrt(1e4):.4f}")

# ---------------------------------------------------------------- 3. rms error vs N
Ns = np.unique(np.logspace(2, 5, 10).astype(int))
rms_sm, rms_hm = [], []
for n in Ns:
    e_sm, e_hm = [], []
    for _ in range(200):
        e_sm.append(mc_integrate(lambda x: x**2, 0, 2, n, rng)[0] - 8 / 3)
        x, y = rng.uniform(0, 2, n), rng.uniform(0, 4, n)          # box [0,2]x[0,4]
        e_hm.append(8.0 * np.mean(y < x**2) - 8 / 3)
    rms_sm.append(np.sqrt(np.mean(np.square(e_sm))))
    rms_hm.append(np.sqrt(np.mean(np.square(e_hm))))
k_sm = np.mean(np.array(rms_sm) * np.sqrt(Ns))
k_hm = np.mean(np.array(rms_hm) * np.sqrt(Ns))
print(f"3. rms*sqrt(N): sample mean {k_sm:.3f} (theory 2.385), hit-or-miss {k_hm:.3f} (3.771)")
print(f"   hit-or-miss needs {(k_hm/k_sm)**2:.1f}x more points for the same error")


# ---------------------------------------------------------------- 4. Simpson vs MC
def simpson_1d(n):
    """Composite Simpson of (pi/2) sin(pi x) on [0,1] with n points (n odd)."""
    x = np.linspace(0, 1, n)
    w = np.ones(n); w[1:-1:2] = 4; w[2:-1:2] = 2
    return np.sum(w * np.pi / 2 * np.sin(np.pi * x)) / (3 * (n - 1))


print("4. product integrand prod_i (pi/2) sin(pi x_i) on [0,1]^d, exact = 1")
for d in (1, 2, 4, 8):
    n = 3 if d == 8 else 9
    N = n**d
    err_grid = abs(simpson_1d(n) ** d - 1)     # product rule = (1-D rule)^d
    sig_f = np.sqrt((np.pi**2 / 8) ** d - 1)
    print(f"   d={d}: Simpson with N={N:6d}: error {err_grid:.2e} | MC sigma_f/sqrt(N) = {sig_f/np.sqrt(N):.2e}")

# ---------------------------------------------------------------- 5. empty cube
print("5. unit ball in the cube [-1,1]^d, N = 1e6")
for d in (2, 5, 10, 15, 20):
    hits = 0
    for _ in range(10):                          # 10 chunks of 1e5 points: low memory
        x = rng.uniform(-1, 1, (100_000, d))
        hits += np.count_nonzero(np.sum(x * x, axis=1) < 1)
    N = 1_000_000
    exact = np.pi ** (d / 2) / gamma(d / 2 + 1)
    ci = binomtest(hits, N).proportion_ci(method="wilson")
    print(f"   d={d:2d}: hits {hits:7d}  estimate {2**d*hits/N:8.4f}  exact {exact:8.4f}"
          f"  Wilson 95% on p: [{ci.low:.2e}, {ci.high:.2e}]")

# ---------------------------------------------------------------- figure
plt.loglog(Ns, rms_sm, "o-", label=f"sample mean ({k_sm:.2f}/sqrt N)")
plt.loglog(Ns, rms_hm, "s-", label=f"hit-or-miss ({k_hm:.2f}/sqrt N)")
plt.loglog(Ns, 2.385 / np.sqrt(Ns), "k--", lw=1, label="2.385 / sqrt N")
plt.xlabel("N"); plt.ylabel("rms error"); plt.legend(); plt.title("Monte Carlo error ~ 1/sqrt(N)")
plt.savefig("mc_integrals.png", dpi=120)
print("saved mc_integrals.png")
! mc_fortran.f90  --  Lecture 13 from scratch in Fortran
!   1. sample mean of x^2 on [0,2] with its error bar
!   2. hit-or-miss estimate of pi
!   3. inversion (exponential), Box-Muller (Gaussian), rejection (half-normal)
!   4. importance sampling of the rare event P(X > 4)
! Compile & run:  gfortran -O2 mc_fortran.f90 -o mc_fortran && ./mc_fortran
program mc_fortran
  implicit none
  integer,  parameter :: dp = kind(1.0d0), n = 1000000, m = 10000
  real(dp), parameter :: pi = 4.0_dp*atan(1.0_dp)
  real(dp), allocatable :: x(:), y(:), u(:), v(:), z(:), fx(:), w(:)
  real(dp) :: est, err, p_hat, Mconst, lam
  integer  :: k, nacc, nseed, t0, t1, rate
  integer, allocatable :: seed(:)

  call random_seed(size=nseed);  allocate(seed(nseed));  seed = 13
  call random_seed(put=seed)                      ! explicit seed
  allocate(x(n), y(n), u(n), v(n), z(n), fx(n))

  ! ---- 1. sample mean of x^2 on [0,2], 1e4 points
  call random_number(x(1:m))                      ! [0,1)
  x(1:m) = 2.0_dp*x(1:m)                          ! [0,2)
  fx(1:m) = x(1:m)**2
  est = 2.0_dp*sum(fx(1:m))/m
  err = 2.0_dp*sqrt(sum((fx(1:m) - sum(fx(1:m))/m)**2)/(m - 1))/sqrt(real(m, dp))
  print '(a,f7.4,a,f7.4,a)', '1. int x^2 dx on [0,2] = ', est, ' +- ', err, '   (8/3 = 2.6667)'

  ! ---- 2. hit-or-miss: pi
  call random_number(x);  call random_number(y)
  p_hat = count(x**2 + y**2 < 1.0_dp) / real(n, dp)
  print '(a,f8.5,a,f8.5)', '2. pi = ', 4*p_hat, ' +- ', 4*sqrt(p_hat*(1 - p_hat)/n)

  ! ---- 3a. inversion: Exp(lambda = 2), whole-array operation, no loop
  call random_number(u)
  z = -log(1.0_dp - u)/2.0_dp
  print '(a,f7.4,a)', '3a. Exp(2): mean ', sum(z)/n, '   (0.5)'

  ! ---- 3b. Box-Muller: two uniforms -> two N(0,1)
  call system_clock(t0, rate)
  call random_number(u(1:n/2));  call random_number(v(1:n/2))
  u(1:n/2)   = 1.0_dp - u(1:n/2)                  ! (0,1]: no LOG(0)
  z(1:n/2)   = sqrt(-2*log(u(1:n/2)))*cos(2*pi*v(1:n/2))
  z(n/2+1:n) = sqrt(-2*log(u(1:n/2)))*sin(2*pi*v(1:n/2))
  call system_clock(t1)
  print '(a,f8.4,a,f7.4,a,f6.1,a)', '3b. N(0,1): mean ', sum(z)/n, ', variance ', &
        sum(z**2)/n - (sum(z)/n)**2, '  (', 1000.0_dp*(t1 - t0)/rate, ' ms for 1e6)'

  ! ---- 3c. rejection: half-normal from Exp(1), M = sqrt(2e/pi)
  Mconst = sqrt(2*exp(1.0_dp)/pi)
  call random_number(u);  call random_number(v)
  z = -log(1.0_dp - u)                            ! z ~ Exp(1)   (the envelope g)
  nacc = 0;  est = 0.0_dp
  do k = 1, n
     if (v(k) < exp(-0.5_dp*(z(k) - 1.0_dp)**2)) then   ! = f/(M g) for this pair
        nacc = nacc + 1                           ! accepted: z(k) is half-normal
        est = est + z(k)
     end if
  end do
  print '(a,f7.4,a,f7.4,a,f7.4,a)', '3c. rejection: accepted ', real(nacc, dp)/n, &
        ' (1/M = ', 1/Mconst, '), mean ', est/nacc, ' (0.7979)'

  ! ---- 4. importance sampling: P(X>4), proposal g = 4 + Exp(rate 4)
  lam = 4.0_dp
  allocate(w(m))
  call random_number(u(1:m))
  x(1:m) = 4.0_dp - log(1.0_dp - u(1:m))/lam      ! samples from g (inversion!)
  w = exp(-0.5_dp*x(1:m)**2)/sqrt(2*pi) / (lam*exp(-lam*(x(1:m) - 4.0_dp)))   ! f/g
  est = sum(w)/m
  err = sqrt(sum((w - est)**2)/(m - 1))/sqrt(real(m, dp))
  print '(a,es11.4,a,es9.2,a)', '4. P(X>4) = ', est, ' +- ', err, '   (exact 3.1671E-05)'
end program mc_fortran

sampling.py
"""
sampling.py  --  Lecture 13, part II: from uniform numbers to any distribution
  1. inversion: exponential   x = -ln(1-u)/lambda
  2. a periodogram bin of noise with spectrum S:  P = -S ln u
  3. Box-Muller: two uniforms -> two N(0,1)
  4. rejection: half-normal from an exponential envelope, M = sqrt(2e/pi)
  Every sampler is tested on its moments AND with a Kolmogorov-Smirnov test.
Run:  python sampling.py   -> prints numbers, saves sampling.png
"""
import numpy as np
from scipy import stats
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

rng = np.random.default_rng(2027)
n = 10**6

# ---------------------------------------------------------------- 1. inversion
lam = 2.0
u = rng.random(n)
x_exp = -np.log(1.0 - u) / lam
ks = stats.kstest(x_exp[:10**5], stats.expon(scale=1 / lam).cdf)
print(f"1. Exp(2) by inversion: mean {x_exp.mean():.4f} (0.5), var {x_exp.var():.4f} (0.25), KS p = {ks.pvalue:.2f}")

# ---------------------------------------------------------------- 2. periodogram bin
S = 3.7
P = -S * np.log(1.0 - rng.random(n))
print(f"2. periodogram bin, S={S}: mean {P.mean():.4f}, std {P.std():.4f}  (both = S)")

# ---------------------------------------------------------------- 3. Box-Muller
u1 = 1.0 - rng.random(n // 2)          # (0,1]: ln(0) = -inf must never happen
u2 = rng.random(n // 2)
r = np.sqrt(-2.0 * np.log(u1))
z = np.concatenate([r * np.cos(2 * np.pi * u2), r * np.sin(2 * np.pi * u2)])
ks = stats.kstest(z[:10**5], "norm")
print(f"3. Box-Muller: mean {z.mean():+.4f}, var {z.var():.4f}, excess kurtosis {stats.kurtosis(z):+.4f},"
      f" KS p = {ks.pvalue:.2f}")

# ---------------------------------------------------------------- 4. rejection
# target f(x) = sqrt(2/pi) exp(-x^2/2), x>0 ; envelope g(x) = exp(-x) ; f <= M g
M = np.sqrt(2 * np.e / np.pi)
xg = rng.exponential(1.0, n)                       # 1. draw from g
v = rng.random(n)                                  #    and v ~ U(0,1)
f = np.sqrt(2 / np.pi) * np.exp(-xg**2 / 2)
accept = v < f / (M * np.exp(-xg))                 # 2. accept if v < f/(M g)
x_half = xg[accept]
ks = stats.kstest(x_half[:10**5], stats.halfnorm.cdf)
print(f"4. rejection: accepted {accept.mean():.4f} (1/M = {1/M:.4f}), mean {x_half.mean():.4f}"
      f" (exact {np.sqrt(2/np.pi):.4f}), KS p = {ks.pvalue:.2f}")

# ---------------------------------------------------------------- figure
fig, ax = plt.subplots(1, 3, figsize=(14, 4))
t = np.linspace(0, 3, 200)
ax[0].hist(x_exp, 100, range=(0, 3), density=True, alpha=.6); ax[0].plot(t, lam * np.exp(-lam * t), "k")
ax[0].set_title("inversion: Exp(2)")
t = np.linspace(-4, 4, 200)
ax[1].hist(z, 100, range=(-4, 4), density=True, alpha=.6); ax[1].plot(t, stats.norm.pdf(t), "k")
ax[1].set_title("Box-Muller: N(0,1)")
t = np.linspace(0, 4, 200)
ax[2].hist(x_half, 100, range=(0, 4), density=True, alpha=.6)
ax[2].plot(t, stats.halfnorm.pdf(t), "k", label="f"); ax[2].plot(t, M * np.exp(-t), "r--", label="M g")
ax[2].legend(); ax[2].set_title(f"rejection: accepted {accept.mean():.2f}")
fig.tight_layout(); fig.savefig("sampling.png", dpi=120)
print("saved sampling.png")
