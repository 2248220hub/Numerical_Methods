09. Convolution and Correlation/

A telescope blurs the sky with its PSF, an RC circuit smooths a voltage, a moving average smooths a light curve: all are convolutions with an impulse response h.

y = x ∗ h has length N + M − 1. Directly: N·M operations. With FFTs: O(Nfft log Nfft) — but the DFT product is a circular convolution.
  • LTI systems and the impulse response
  • Flip-and-slide picture
  • Output length N + M − 1
  • Convolution theorem (DTFT and DFT)
  • Circular convolution ⊛N

BASICThe linear convolution

A system is linear (response to a sum = sum of responses) and time-invariant (a delayed input gives a delayed output). Then it is completely described by its response to a single impulse, h[n], and its output for any input is

DEFINITIONLinear convolutionhover the symbols ↓
\h{yn}{y[n]}=(x*h)[n]=\h{sum}{\sum_{k=-\infty}^{+\infty}}\h{xn}{x[k]}\,\h{hn}{h[n-k]}
Input of length N and kernel of length M: output of length N + M − 1, cost N·M multiply–adds. In practice M ≪ N (a smoothing kernel, a PSF, an FIR filter) and the data may be an endless stream.
y = np.convolve(x, h)            # mode='full': N + M - 1 samples
y = 0.0_dp
do n = 1, N + M - 1
   do k = max(1, n-M+1), min(n, N)
      y(n) = y(n) + x(k)*h(n-k+1)
   end do
end do

Read it as: flip h, slide it to position n, multiply by the overlapping x and add. The widget does exactly this.

COREThe convolution theorem

THEOREMConvolution theoremhover the symbols ↓
(x*h)[n]\ \Longleftrightarrow\ X(f)\,H(f)\qquad\text{DFT: }\ \mathrm{IDFT}_N\{\h{Xk}{X[k]}\h{Hk}{H[k]}\}=(x\circledast_N h)[n]=\h{sum}{\sum_{m=0}^{N-1}}x[m]\,h[(n-m)\bmod N]
The DFT version is a circular convolution: indices wrap modulo N. Zero-pad both sequences to Nfft ≥ N + M − 1 and circular = linear. Cost: two FFTs, one product, one inverse FFT. For short kernels (M ≲ 50–100) the direct sum is still faster: scipy.signal.choose_conv_method decides.
nfft = scipy.fft.next_fast_len(N + M - 1)
y = np.fft.irfft(np.fft.rfft(x, nfft) * np.fft.rfft(h, nfft), nfft)[:N + M - 1]
# or simply: scipy.signal.fftconvolve(x, h)
xp = 0; xp(1:N) = x;  hp = 0; hp(1:M) = h          ! zero padding to nfft
call fftw_execute_dft_r2c(pf, xp, Xk);  call fftw_execute_dft_r2c(pf, hp, Hk)
Xk = Xk*Hk/nfft                                    ! FFTW is unnormalised
call fftw_execute_dft_c2r(pb, Xk, xp);  y = xp(1:N+M-1)

Correlation c = x ⋆ h ⟺ X H*. For a real, even kernel the two operations coincide; for a causal or asymmetric one (a chirp, an RC response) they do not.

DEFINITIONCorrelationhover the symbols ↓
\h{cn}{c[n]}=\h{sum}{\sum_k}x[k]\,h[k-n]\ \Longleftrightarrow\ \h{Xk}{X}\,\h{Hk}{H}^{*}
For a real kernel H*(f) = H(−f): correlating with h[n] is convolving with h[−n]. Everything said about convolution (zero padding, overlap-save, overlap-add) applies unchanged: in code only H → np.conj(H).
c = np.fft.irfft(np.fft.rfft(x, nfft) * np.conj(np.fft.rfft(h, nfft)), nfft)
Xk = Xk*conjg(Hk)/nfft

COREMatched filtering

Data d = A·h shifted by t₀ + white noise. The linear filter that maximises the output signal-to-noise ratio at t₀ is the template itself, time-reversed: correlate with h. The peak lag estimates t₀; the peak height over the rms of the output is the detection statistic.

ESTIMATORMatched filter in coloured noisehover the symbols ↓
\rho(t_0)=\frac{\big|\sum_k \tilde d[k]\,\tilde h^*[k]\,e^{j2\pi kt_0/N}/S_n[k]\big|}{\sqrt{\sum_k|\tilde h[k]|^2/S_n[k]}}
Dividing by the noise PSD Sn (estimated as in Lecture 10) "whitens" the data: frequencies where noise is strong count less. With white noise it reduces to plain correlation. This is how gravitational-wave searches work.

Code lab result: a template buried in noise with amplitude 0.3 is found at lag 2600 (true 2600), with peak/rms = 3.8 — by eye the record looks like pure noise.

The DFT silently assumes the data are one period of a periodic sequence and that the kernel is as long as the data. Neither is true.

A kernel with m₊ positive and m₋ negative lags spoils m₊ outputs at the start and m₋ at the end. A buffer of K ≥ max(m₊, m₋) zeros removes the wrap-around.

  • Wrap-around pollution
  • Which samples are spoiled
  • Zero padding: K ≥ max(m₊, m₋)
  • Edges: zero, periodic, reflect, nearest

COREStoring the kernel

Pad h to Nfft. Lag −k lives at index Nfft − k (indices are modulo Nfft):

CONVENTIONWrap-around storagehover the symbols ↓
\big[\,h_0,\ h_1,\ \dots,\ h_{m_+},\ 0,\ \dots,\ 0,\ h_{-m_-},\ \dots,\ h_{-1}\,\big],\qquad m_++m_-=M-1
Causal kernel: m₋ = 0 (only the past). Centred kernel: m₊ = m₋ = (M−1)/2. Getting this wrong shifts the output by m₋ samples.
hb = np.zeros(nfft)
hb[:M - m_minus] = h[m_minus:]           # lags 0 .. m_plus
if m_minus: hb[nfft - m_minus:] = h[:m_minus]   # lags -m_minus .. -1
buf = 0.0_dp
buf(1:m_plus+1)            = h(m_minus+1:M)     ! lags 0 .. m_plus
buf(nfft-m_minus+1:nfft)   = h(1:m_minus)       ! lags -m_minus .. -1

CORESpoiled samples and the buffer zone

  • Without padding, the first m₊ outputs mix in data from the end of the record, the last m₋ from the start. Only N − m₊ − m₋ samples are correct.
  • Append K ≥ max(m₊, m₋) zeros (symmetric kernel: K ≥ (M−1)/2; causal: K ≥ M−1): what wraps is now zero. Code lab: step response with N = 64, M = 15 — error 0.773 on the first 14 samples without padding, 2×10⁻¹⁶ with Nfft = N + M − 1.

Edges of the record

boundarymeaningwhen
zero (constant)data vanish outsideonly if they really do; otherwise a step at the edge biases ~M/2 outputs
periodic (wrap)what the plain DFT doestruly periodic data (a full circle of a ring, a periodic box)
reflect / nearestmirror or extend the last valueimages, light curves: continuous at the edge

Output sizes: full (N + M − 1), same (N), valid (N − M + 1, edge-free). Subtract the mean or trend first, or taper the edges; always flag outputs within one kernel width of an edge or a mask. Libraries: scipy.ndimage.convolve(mode=…), astropy.convolution.convolve(boundary=…).

One giant FFT is not always possible (memory, streaming data, latency) nor optimal (cost O(N log N) vs O(N log M)).

Overlap-save: overlapping inputs, discard the wrapped outputs. Overlap-add: disjoint zero-padded inputs, add the overlapping outputs. Same cost; O&S parallelises more easily.

  • Full vs valid convolution of a block
  • Overlap-save algorithm and indices
  • Overlap-add algorithm
  • Choosing Nfft ≈ 4–8 M

COREOverlap-save (O&S)

  1. Pad h to Nfft, compute H[k] once.
  2. Prepend M − 1 zeros to x. Cut blocks of Nfft samples starting every B = Nfft − M + 1: consecutive blocks overlap by M − 1.
  3. Each block: yj = IFFT{FFT(xj)·H} — a circular convolution.
  4. Discard the first M − 1 outputs (wrapped; for a general kernel: m₊ at the start, m₋ at the end), keep B.
  5. Concatenate the kept pieces.
ALGORITHMBlock indiceshover the symbols ↓
\text{block }j:\ x_p[jB,\ jB+N_{\rm fft}),\qquad B=\h{Nfft}{N_{\rm fft}}-\h{M}{M}+1,\qquad \text{keep } y_j[m_+,\ m_++B)
def overlap_save(x, h, nfft, m_minus=0):
    M = len(h); B = nfft - M + 1; m_plus = M - 1 - m_minus
    H = kernel_spectrum(h, m_minus, nfft)
    xp = np.concatenate((np.zeros(M-1), x, np.zeros(nfft)))
    Ny = len(x) + M - 1;  y = np.empty(Ny)
    for s in range(0, Ny, B):
        yb = irfft(rfft(xp[s:s+nfft]) * H, nfft)
        n = min(B, Ny - s)
        y[s:s+n] = yb[m_plus:m_plus+n]     # discard m_plus at start, m_minus at end
    return y
do j = 1, nblk
   s = (j-1)*B + 1                        ! 1-based block start
   buf = xp(s : s+nfft-1)
   call fftw_execute_dft_r2c(pf, buf, Xk)
   Xk = Xk*Hk/nfft
   call fftw_execute_dft_c2r(pb, Xk, buf)
   n = min(B, Ny - s + 1)
   y(s : s+n-1) = buf(m_plus+1 : m_plus+n)
end do

COREOverlap-add (O&A)

  1. H[k] once, as above.
  2. Cut x into disjoint blocks of B = Nfft − M + 1 samples.
  3. Zero-pad each block to Nfft: its circular convolution is now the full linear one, B + M − 1 = Nfft samples.
  4. Add yj into the output from sample jB (for a general kernel: spread m₋ left, m₊ right): the last M − 1 samples overlap the next block's first M − 1.
def overlap_add(x, h, nfft, m_minus=0):
    M = len(h); B = nfft - M + 1
    H = kernel_spectrum(h, m_minus, nfft)
    y = np.zeros(len(x) + M - 1 + nfft)
    for s in range(0, len(x), B):
        yb = irfft(rfft(x[s:s+B], nfft) * H, nfft)
        y[s:s+nfft] += np.roll(yb, m_minus)    # spreads m_minus left, m_plus right
    return y[:len(x) + M - 1]
overlap-saveoverlap-add
input blocksoverlap by M − 1disjoint, zero-padded
output blocksdisjoint, concatenatedoverlap by M − 1, added
discarded workM − 1 outputs per blocknone
costidentical: same Nfft, same number of blocks
parallel writesdisjoint: no synchronisationoverlapping: needs care

Both agree with np.convolve to 1.6×10⁻¹⁴ for every m₋ = 0 … M−1 (code lab). Library: scipy.signal.oaconvolve.

Filtering applies a response, Y = XH. Deconvolution tries to remove it: X̂ = Y/H. Where the instrument kills a frequency, the noise there gets multiplied by a huge number.

Wiener: X̂ = Φ·Y/H with Φ = Ssignal/(Ssignal + Snoise) ∈ [0, 1]. Invert where the signal dominates, suppress where noise dominates.
  • Why plain inversion fails
  • Wiener filter and the factor Φ
  • Estimating Sn from the data
  • Tikhonov with a constant λ
  • Discrepancy, L-curve, GCV; Richardson–Lucy

COREThe Wiener filter

Model: Y = HX + N, with Sx the PSD of the true signal and Sn that of the noise. The linear estimate X̂ = WY that minimises the mean squared error is

ESTIMATORWiener deconvolutionhover the symbols ↓
\hat X[k]=\h{Wk}{W[k]}\,Y[k],\qquad W=\frac{\h{Hk}{H}^{*}}{|H|^2+\h{Sn}{S_n}/\h{Sx}{S_x}}=\underbrace{\frac1H}_{\text{inversion}}\cdot\underbrace{\frac{|H|^2S_x}{|H|^2S_x+S_n}}_{\h{Phi}{\Phi}\,\in\,[0,1]}
Sn ≪ |H|²Sx: Φ → 1, pure inversion. Noise dominates: Φ → 0, output suppressed. H* here is not a correlation: 1/H = H*/|H|², and the noise term added to the positive denominator prevents division by zero.
P = np.abs(Y)**2                          # or a Welch estimate
Phi = np.clip((P - Sn) / P, 0, 1)
Xhat = Phi * Y / H
phi = max(0.0_dp, min(1.0_dp, (abs(Yk)**2 - Sn)/abs(Yk)**2))
Xk  = phi*Yk/Hk

Estimating the noise from the data

  1. |Y|² with Welch (Lecture 10).
  2. Sn: the flat floor at high f, a signal-free region, or the detector model.
  3. Signal: |Y|² − Sn, clipped at 0; Φ = (|Y|² − Sn)/|Y|².
  4. X̂ = ΦY/H. The "threshold" is where the signal sinks into the floor: read from the data, not chosen. Φ is a ratio: 20–30% errors on Sn matter little.

With several bands each one above its own noise level gets its own window: no global threshold. Smooth the edges of Φ — sharp edges ring in time. Bands with Sx ≈ Sn get Φ ≈ 0.5: Wiener minimises the total error, it does not preserve amplitudes.

ADVANCEDWithout a noise model: Tikhonov

ESTIMATORTikhonov regularisationhover the symbols ↓
\hat X[k]=\frac{\h{Hk}{H^*[k]}}{|H[k]|^2+\h{lam}{\lambda}}\,Y[k]
λ too small: noise amplified, ringing. λ too large: under-deconvolved. Choose by the discrepancy principle (residual ≈ Nσ²), the L-curve corner, or generalised cross-validation (no σ needed). Code lab: blurred 0.464, plain inverse 10⁹ (!), best Tikhonov 0.329, Wiener from the data 0.333 (rms errors). For photon-counting images: Richardson–Lucy, where the iteration count plays the role of λ.
Xhat = np.conj(H) * Y / (np.abs(H)**2 + lam)
Xk = conjg(Hk)*Yk/(abs(Hk)**2 + lam)

In real time you only have the past: the filter must be causal. The price is a delay — constant for a symmetric FIR, frequency-dependent for an IIR.

A symmetric FIR made causal is a pure delay of (M−1)/2 samples. An IIR has a group delay that depends on f: pulses get skewed and their peaks move.
  • FIR: a convolution with a compact kernel
  • IIR: a recursion, no block FFT
  • Linear phase and pure delay
  • Group delay τg(f)
  • Zero phase: filtfilt

always stable; linear phase if h is symmetricsharp responses with few coefficients; can be unstable; non-linear phase

PROPERTYLinear phase and group delayhover the symbols ↓
H(f)=|H(f)|\,e^{-j2\pi f(M-1)/2}\ \ (\text{symmetric causal FIR}),\qquad \h{taug}{\tau_g(f)}=-\frac1{2\pi}\frac{d\varphi}{df}
Linear phase = every frequency delayed by the same (M−1)/2 samples: shape preserved. For the RC filter y[n] = a y[n−1] + (1−a)x[n] the delay depends on frequency (≈ τ at low f). Code lab: a pulse centred at 104.5 comes out at 104.5 (centred Hann), 114.5 (causal Hann, M = 21: delay 10) and 110.0 (RC with τ = 6).
y = scipy.signal.lfilter([1 - a], [1, -a], x)      # causal RC
y0 = scipy.signal.filtfilt([1 - a], [1, -a], x)    # zero phase, offline
y(1) = (1-a)*x(1)
do n = 2, N
   y(n) = a*y(n-1) + (1-a)*x(n)
end do

Timing measurements (arrival times, pulsar phases, transient epochs): correct for the delay, or use a zero-phase kernel.

y = h ∗ x is a matrix–vector product. Its matrix is constant along diagonals (Toeplitz). Zero padding turns it into a circulant, whose eigenvectors are the Fourier modes.

The FFT multiplies by H in its eigenbasis: O(N log N). Deconvolution solves Hx = y, ill-conditioned when eigenvalues Hk → 0; Wiener is least squares with a Gaussian prior.
  • Toeplitz and circulant matrices
  • The DFT diagonalises circulants
  • Condition number and deconvolution
  • Wiener as generalised least squares
  • OpenMP: O&S writes disjoint slices; MPI: the halo
THEOREMCirculant diagonalisationhover the symbols ↓
\mathbf H=\mathbf F^{-1}\,\mathrm{diag}(H_k)\,\mathbf F,\qquad \text{eigenvectors: Fourier modes, eigenvalues: } H_k
Condition number = max|Hk|/min|Hk|: a Gaussian blur has exponentially small Hk at high k ⇒ huge condition number ⇒ plain inversion amplifies noise (Lecture on linear systems).
RESULTWiener as least squares with a priorhover the symbols ↓
\hat{\mathbf x}=\big(\mathbf H^\dagger\mathbf N^{-1}\mathbf H+\mathbf S^{-1}\big)^{-1}\mathbf H^\dagger\mathbf N^{-1}\mathbf y\ \xrightarrow{\ \text{Fourier basis}\ }\ \hat X_k=\frac{H_k^*}{|H_k|^2+S_{n,k}/S_{x,k}}\,Y_k
N, S: noise and signal covariances, diagonal in Fourier space for stationary processes. The same formula with non-diagonal matrices is CMB map-making.

CODEParallel blocks

  • OpenMP, overlap-save: each iteration reads an overlapping slice but writes a disjoint slice of y — no race, no critical section. FFTW plans once outside the parallel region; inside, new-array execute on private buffers.
  • OpenMP, overlap-add: neighbours write the same M − 1 samples — a race. Use private buffers and a cheap serial pass for the tails, or process even blocks then odd blocks.
  • MPI: process p owns outputs [ap, bp) and needs inputs x[ap − M + 1 … bp − 1]: its block plus a halo of M − 1 samples. Then no further communication; Gatherv collects.
overlap_save.f90
! overlap_save.f90  --  Lecture 9: overlap-save convolution with FFTW and OpenMP
!   any kernel (h(1) is lag -m_minus), blocks processed in parallel: each block writes a
!   disjoint slice of the output, so there is no race condition.
!   The driver compares with a direct double loop and times the two.
! Build:  gfortran -O2 -fopenmp overlap_save.f90 -I/usr/include -lfftw3 -o ols && ./ols
module ols_mod
  use, intrinsic :: iso_c_binding
  use, intrinsic :: iso_fortran_env, only: dp => real64
  implicit none
  include 'fftw3.f03'
contains
  subroutine overlap_save(x, h, nfft, m_minus, y)
    real(dp), intent(in)  :: x(:), h(:)
    integer,  intent(in)  :: nfft, m_minus
    real(dp), intent(out) :: y(:)                     ! size(x) + size(h) - 1
    real(dp), allocatable :: xp(:), buf(:)
    complex(dp), allocatable :: Hk(:), Xk(:)
    type(c_ptr) :: pf, pb
    integer :: M, B, Ny, nblk, j, s, n, m_plus
    M = size(h); B = nfft - M + 1; Ny = size(x) + M - 1; m_plus = M - 1 - m_minus
    nblk = (Ny + B - 1)/B
    allocate(xp(nblk*B + M - 1 + nfft), buf(nfft), Hk(nfft/2+1), Xk(nfft/2+1))
    xp = 0.0_dp
    xp(M:M+size(x)-1) = x                             ! M-1 leading zeros
    ! plans created ONCE, outside the parallel region (planning is not thread-safe)
    pf = fftw_plan_dft_r2c_1d(nfft, buf, Xk, ior(FFTW_ESTIMATE, FFTW_UNALIGNED))
    pb = fftw_plan_dft_c2r_1d(nfft, Xk, buf, ior(FFTW_ESTIMATE, FFTW_UNALIGNED))
    buf = 0.0_dp; buf(1:m_plus+1) = h(m_minus+1:M)    ! lags 0..m_plus
    if (m_minus > 0) buf(nfft-m_minus+1:nfft) = h(1:m_minus)   ! lags -m_minus..-1
    call fftw_execute_dft_r2c(pf, buf, Hk)             ! kernel spectrum, once
    !$omp parallel do default(none) private(j, s, n, buf, Xk) &
    !$omp& shared(nblk, B, nfft, Ny, m_plus, xp, Hk, y, pf, pb)
    do j = 1, nblk
       s = (j-1)*B + 1                                 ! 1-based block start
       buf = xp(s:s+nfft-1)
       call fftw_execute_dft_r2c(pf, buf, Xk)           ! new-array execute: thread-safe
       Xk = Xk*Hk/nfft                                  ! FFTW is unnormalised
       call fftw_execute_dft_c2r(pb, Xk, buf)
       n = min(B, Ny - s + 1)
       y(s:s+n-1) = buf(m_plus+1:m_plus+n)              ! discard m_plus / m_minus
    end do
    !$omp end parallel do
    call fftw_destroy_plan(pf); call fftw_destroy_plan(pb)
  end subroutine overlap_save
end module ols_mod

program ols
  use ols_mod
  !$ use omp_lib
  implicit none
  integer, parameter :: nx = 2000000, M = 101
  real(dp), allocatable :: x(:), h(:), y(:), yd(:)
  integer :: i, k, mm, t0, t1, rate
  allocate(x(nx), h(M), y(nx+M-1), yd(nx+M-1))
  call random_number(h); h = h - 0.5_dp
  call random_number(x); x = x - 0.5_dp
  ! direct convolution: y(i) = sum_k h(k) x(i-k+1)   (O(N M))
  call system_clock(t0, rate)
  yd = 0.0_dp
  do i = 1, nx + M - 1
     do k = max(1, i-nx+1), min(M, i)
        yd(i) = yd(i) + h(k)*x(i-k+1)
     end do
  end do
  call system_clock(t1)
  print '(a, f8.1, a)', 'direct convolution         ', 1000.0_dp*(t1-t0)/rate, ' ms'
  do mm = 0, M - 1, 50                               ! causal (0), centred (50), anti-causal (100)
     call system_clock(t0)
     call overlap_save(x, h, 1024, mm, y)
     call system_clock(t1)
     ! output indices as np.convolve(x, h) for every m_minus (m_minus only labels the lags of h)
     print '(a, i3, a, es9.2, a, f7.1, a)', 'overlap-save m_minus =', mm, ':  max error ', &
          maxval(abs(y - yd)), ',  ', 1000.0_dp*(t1-t0)/rate, ' ms'
  end do
  !$ print '(a, i0)', 'OpenMP threads: ', omp_get_max_threads()
end program ols

Tested (4 threads): error 4×10⁻¹⁵ against a direct double loop; 171 ms direct vs 20–33 ms overlap-save.

"""
fast_convolution.py  --  Lecture 9: convolution with the FFT, in blocks, and its inverse.
  1. circular vs linear convolution: wrap-around pollution and zero padding
  2. overlap-add and overlap-save (any kernel: causal, centred, asymmetric), checked vs np.convolve
  3. cost per output sample against the FFT length (optimum ~ 4-8 M)
  4. correlation = convolution with the time-reversed kernel: a matched filter finds a pulse
  5. deconvolution: plain inverse, Tikhonov (best constant lambda), Wiener from the spectra
  6. a causal filter delays: centred Hann vs causal Hann vs RC (IIR)
Run:  python fast_convolution.py   -> prints numbers, saves fast_convolution.png
"""
import numpy as np
from scipy.fft import rfft, irfft
from scipy.signal import lfilter
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

rng = np.random.default_rng(9)


# ---------------------------------------------------------------- 1. wrap-around
N, M = 64, 15
x = np.zeros(N); x[40:] = 1.0                       # a step near the end of the record
h = np.exp(-np.arange(M) / 4.0); h /= h.sum()        # causal kernel
lin = np.convolve(x, h)                              # N + M - 1 samples
circ = irfft(rfft(x, N) * rfft(h, N), N)             # Nfft = N: circular
pad = irfft(rfft(x, N + M - 1) * rfft(h, N + M - 1), N + M - 1)
print("1. step convolved with a causal kernel (N = 64, M = 15)")
print(f"   Nfft = N        : max error on the first M-1 samples {np.max(np.abs(circ[:M-1] - lin[:M-1])):.3f} (wrap-around)")
print(f"   Nfft = N + M - 1: max error everywhere {np.max(np.abs(pad - lin)):.1e}")


# ---------------------------------------------------------------- 2. overlap-add / save
def kernel_spectrum(h, m_minus, nfft):
    """h[0] is lag -m_minus. Wrap-around storage: lags 0..m_plus first, negative lags at the end."""
    hb = np.zeros(nfft)
    hb[: len(h) - m_minus] = h[m_minus:]
    if m_minus:
        hb[nfft - m_minus:] = h[:m_minus]
    return rfft(hb)


def overlap_add(x, h, nfft, m_minus=0):
    M = len(h); B = nfft - M + 1
    H = kernel_spectrum(h, m_minus, nfft)
    y = np.zeros(len(x) + M - 1 + nfft)
    for s in range(0, len(x), B):                    # disjoint blocks of B samples
        yb = irfft(rfft(x[s:s + B], nfft) * H, nfft)
        y[s:s + nfft] += np.roll(yb, m_minus)        # spreads m_minus left, m_plus right
    return y[: len(x) + M - 1]


def overlap_save(x, h, nfft, m_minus=0):
    M = len(h); B = nfft - M + 1; m_plus = M - 1 - m_minus
    H = kernel_spectrum(h, m_minus, nfft)
    xp = np.concatenate((np.zeros(M - 1), x, np.zeros(nfft)))
    Ny = len(x) + M - 1
    y = np.empty(Ny)
    for s in range(0, Ny, B):                        # overlapping blocks of nfft samples
        yb = irfft(rfft(xp[s:s + nfft]) * H, nfft)
        n = min(B, Ny - s)
        y[s:s + n] = yb[m_plus:m_plus + n]           # discard m_plus at start, m_minus at end
    return y


x = rng.standard_normal(10_000)
h = rng.standard_normal(31)
ref = np.convolve(x, h)
worst = max(max(np.max(np.abs(f(x, h, 256, mm) - ref)) for f in (overlap_add, overlap_save)) for mm in range(31))
print(f"\n2. overlap-add and overlap-save vs np.convolve, every m_minus = 0..30: max error {worst:.1e}")

# ---------------------------------------------------------------- 3. FFT length
print("\n3. cost per output sample ~ Nfft log2 Nfft / (Nfft - M + 1), M = 101")
M = 101
for nfft in (128, 256, 512, 1024, 4096, 16384):
    print(f"   Nfft = {nfft:6d} ({nfft/M:5.1f} M): {nfft*np.log2(nfft)/(nfft-M+1):6.1f}")

# ---------------------------------------------------------------- 4. matched filter
L = 4096
template = np.sin(2 * np.pi * np.linspace(0, 8, 200) * np.linspace(1, 3, 200)) * np.hanning(200)   # a short chirp
data = rng.standard_normal(L)
t0 = 2600
data[t0:t0 + 200] += 0.6 * template                  # buried: amplitude below the noise rms
corr = irfft(rfft(data, 2 * L) * np.conj(rfft(template, 2 * L)), 2 * L)[:L]   # correlation: H -> H*
print(f"\n4. matched filter: peak of the correlation at lag {np.argmax(corr)} (true {t0}),"
      f" peak / rms = {corr.max()/corr.std():.1f}")

# ---------------------------------------------------------------- 5. deconvolution
N = 4096
f = np.fft.rfftfreq(N)
Xtrue = (rng.standard_normal(f.size) + 1j * rng.standard_normal(f.size)) / np.sqrt(1 + (f / 0.01) ** 2)
x_true = irfft(Xtrue, N); x_true /= x_true.std()                     # red-noise "sky"
Hf = np.exp(-0.5 * (f / 0.02) ** 2)                                   # Gaussian blur
sig_n = 0.02
y = irfft(rfft(x_true) * Hf, N) + sig_n * rng.standard_normal(N)
Y = rfft(y)
rms = lambda xh: np.sqrt(np.mean((xh - x_true) ** 2))
inv = irfft(np.where(Hf > 1e-12, Y / np.maximum(Hf, 1e-12), 0), N)
lams = np.logspace(-6, 0, 61)
errs = [rms(irfft(np.conj(Hf) * Y / (np.abs(Hf) ** 2 + l), N)) for l in lams]
Sx = np.abs(rfft(x_true)) ** 2                                         # (the truth: for reference only)
Sn = N * sig_n ** 2
from scipy.ndimage import uniform_filter1d
Ps = uniform_filter1d(np.abs(Y) ** 2, 33)                              # smoothed |Y|^2 (single bins scatter 100%)
cut = np.argmax(Ps < 1.5 * Sn)                                         # where the data sink into the noise floor
signal = np.where(np.arange(f.size) < cut, np.clip(Ps - Sn, 0, None), 0.0)   # |H|^2 S_x from the data
Phi = signal / (signal + Sn)                                           # in [0, 1]; 0 above the cut
wien = irfft(np.where(Phi > 0, Phi * Y / np.maximum(Hf, 1e-12), 0), N)
print(f"   noise floor reached at f = {f[cut]:.3f} cycles/sample")
print(f"\n5. deconvolution rms error: blurred data {rms(y):.3f}, plain inverse {rms(inv):.2e},"
      f" best Tikhonov {min(errs):.3f} (lambda = {lams[np.argmin(errs)]:.1e}), Wiener from the data {rms(wien):.3f}")

# ---------------------------------------------------------------- 6. delay of causal filters
pulse = np.zeros(400); pulse[100:110] = 1.0
hk = np.hanning(21); hk /= hk.sum()
centred = np.convolve(pulse, hk, mode="same")
causal = np.convolve(pulse, hk)[:400]
a = np.exp(-1 / 6.0)
rc = lfilter([1 - a], [1, -a], pulse)                                   # y[n] = a y[n-1] + (1-a) x[n]
centroid = lambda v: np.sum(np.arange(v.size) * v) / np.sum(v)
print(f"\n6. centroid of a pulse at 104.5: centred {centroid(centred):.1f}, causal Hann {centroid(causal):.1f}"
      f" (delay (M-1)/2 = 10), RC {centroid(rc):.1f} (delay tau = 6)")

fig, ax = plt.subplots(1, 3, figsize=(15, 4))
ax[0].plot(lin, "k", lw=2, label="linear"); ax[0].plot(circ, "r--", label="circular, Nfft = N")
ax[0].legend(); ax[0].set_title("wrap-around pollution")
ax[1].semilogx(lams, errs); ax[1].axhline(rms(wien), color="g", label="Wiener from data")
ax[1].set(xlabel="lambda", ylabel="rms error", title="Tikhonov vs Wiener"); ax[1].legend()
ax[2].plot(pulse, "k"); ax[2].plot(centred, label="centred"); ax[2].plot(causal, label="causal Hann"); ax[2].plot(rc, label="RC")
ax[2].set(xlim=(80, 170), title="causal filters delay"); ax[2].legend()
fig.tight_layout(); fig.savefig("fast_convolution.png", dpi=110)
print("saved fast_convolution.png")
