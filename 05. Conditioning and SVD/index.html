05. Conditioning, EVD and SVD/

Data are never exact: photon noise in b, discretisation error in A, rounding everywhere. To ask whether 0.01% noise gives 0.01% error in x we must measure vectors and operators.

Above: the unit "circles" of three vector norms, and what a matrix does to the Euclidean one.

‖A‖ = max ‖Ax‖/‖x‖ is the largest stretch of A. For the 2-norm it is the largest singular value σmax.

DEFINITIONℓp normshover the symbols ↓

DEFINITIONInduced normhover the symbols ↓

THEOREMCondition number and error boundhover the symbols ↓
A\,\delta\mathbf x=\delta\mathbf b\ \Rightarrow\ \|\delta\mathbf x\|\le\|A^{-1}\|\,\|\delta\mathbf b\|,\quad \|\mathbf b\|\le\|A\|\,\|\mathbf x\|\ \Rightarrow\ \frac{\|\delta\mathbf x\|}{\|\mathbf x\|}\le\h{kappa}{\kappa(A)}\,\frac{\|\delta\mathbf b\|}{\|\mathbf b\|},\qquad \kappa(A)=\|A\|\,\|A^{-1}\|

COREA 2×2 collapse

A = [[1, 1], [1, 1+ε]], b = (2, 2+ε): x = (1, 1). A⁻¹ = (1/ε)[[1+ε, −1], [−1, 1]], so κ∞ = (2+ε)²/ε ≈ 4/ε. Perturb b by δb = (0, ε) — a relative change of ε/2 — and the solution jumps to (0, 2): a 100% error. Checked for ε = 10⁻², 10⁻⁶, 10⁻¹⁰: κ∞ = 4.04×10², 4.0×10⁶, 4.0×10¹⁰ and always x = (0, 2).

THEOREMErrors in A and bhover the symbols ↓
(A+\delta A)(\mathbf x+\delta\mathbf x)=\mathbf b+\delta\mathbf b,\quad \kappa\frac{\|\delta A\|}{\|A\|}<1\ \Rightarrow\ \frac{\|\delta\mathbf x\|}{\|\mathbf x\|}\le\frac{\kappa}{1-\kappa\frac{\|\delta A\|}{\|A\|}}\Big(\frac{\|\delta\mathbf b\|}{\|\mathbf b\|}+\frac{\|\delta A\|}{\|A\|}\Big)
Backward stability of LU with pivoting: the computed x̂ is the exact solution of (A + δA)x̂ = b with ‖δA‖/‖A‖ ~ εmach. Hence the rule of thumb error ≈ κ εmach.

A computed x̂ leaves a residual r = b − Ax̂. The exact correction d solves Ad = r — and the LU factors are already there: each correction costs 2n².

Above: LU in single precision (Math.fround), residual in double, a few corrections.

The residual must be computed in higher precision: b and Ax̂ agree to almost all digits and their difference is a cancellation.
  • Residual vs error
  • The refinement loop
  • Why the residual needs more precision
  • Mixed precision on GPUs
  • When it fails: κ εlow ≥ 1
ALGORITHMIterative refinementhover the symbols ↓
\mathbf r^{(k)}=\mathbf b-A\mathbf x^{(k)}\ \ (\text{high precision}),\qquad LU\,\mathbf d^{(k)}=P\,\mathbf r^{(k)},\qquad \mathbf x^{(k+1)}=\mathbf x^{(k)}+\mathbf d^{(k)}
Stop when ‖d‖/‖x‖ < tol. Each step multiplies the error by about κ εlow: it converges if κ εlow < 1. Small residual ≠ small error: ‖e‖/‖x‖ ≤ κ ‖r‖/‖b‖.
lu32 = la.lu_factor(A.astype(np.float32))           # O(n^3) in single precision
x = la.lu_solve(lu32, b.astype(np.float32)).astype(float)
for k in range(5):
    r = b - A @ x                                   # double precision residual
    x += la.lu_solve(lu32, r.astype(np.float32))
call sgetrf(n, n, a32, n, ipiv, info)               ! single-precision LU
do k = 1, 6
   r = b - matmul(A, x)                             ! double precision
   r32 = real(r, sp)
   call sgetrs('N', n, 1, a32, n, ipiv, r32, n, info)
   x = x + real(r32, dp)
end do

A symmetric matrix maps the unit circle to an ellipse whose axes are the eigenvectors. A non-symmetric one shears: its eigenvectors are not orthogonal, its eigenvalues may be complex.

Above: edit the matrix entries and watch the circle, the eigenvectors and the ellipse.

Symmetric: A = QΛQᵀ, real λ, orthogonal Q, perfectly stable. Non-symmetric: A = XΛX⁻¹ can be ill-conditioned, complex or not exist. Never use the EVD to solve Ax = b.

  • κ₂ = |λ|max/|λ|min for symmetric A

THEOREMSpectral theoremhover the symbols ↓
A=A^T\ \Rightarrow\ A=\h{Qm}{Q}\h{Lam}{\Lambda}Q^T,\quad Q^TQ=I,\quad \Lambda=\mathrm{diag}(\lambda_1,\dots,\lambda_n)\in\mathbb R^n,\qquad \kappa_2(A)=\frac{\max|\lambda_i|}{\min|\lambda_i|}
Covariance matrices, Hessians of a potential, inertia tensors, Laplacians: all symmetric. Eigenvalues move by at most ‖δA‖₂ under a symmetric perturbation (Weyl): measured 3×10⁻¹⁰ for ‖δA‖ = 1.2×10⁻⁹. [[2, 1], [1, 3]]: λ = 1.382, 3.618, κ = 2.618.

  • Defective matrices: fewer than n independent eigenvectors, X⁻¹ does not exist.

THEOREMSingular value decompositionhover the symbols ↓
\h{A}{A}=\h{Um}{U}\h{Sigm}{\Sigma}\h{Vm}{V}^T,\quad U\in\mathbb R^{m\times m},\ V\in\mathbb R^{n\times n}\ \text{orthogonal},\quad \Sigma=\mathrm{diag}(\h{sigi}{\sigma_1}\ge\sigma_2\ge\dots\ge\sigma_r>0,0,\dots)
σi = √λi(AᵀA), always real and non-negative. κ₂ = σ₁/σr. A vi = σi ui for i ≤ r, A vj = 0 for j > r. Cost ≈ 2mn² + 11n³ (LAPACK dgesdd).

Rank–nullity: r + (n − r) = n. Physical null spaces: a projection along the line of sight loses one dimension; a differential (AC-coupled) CMB scan cannot measure the monopole — a constant sky map is in the kernel (see the map-maker of Lecture 6).

The SVD solver truncates singular values below its default cutoff: it returns a stable, slightly regularised solution rather than the exact one. """
conditioning_svd.py  --  Lecture 5: norms, condition number, iterative refinement, EVD and SVD.

  1. Vector and matrix norms (the 3x3 matrix of the notes); ||A||_2 = sigma_max, ||A||_F = sqrt(sum sigma^2)
  2. The 2x2 example: kappa ~ 4/eps and a 100% error from a tiny perturbation of b
  3. Hilbert matrices: kappa, digits lost, observed error in float32 and float64 against the bound
  4. Iterative refinement: LU in float32, residual in float64 -> double-precision accuracy
  5. EVD: symmetric (stable, orthogonal) vs non-symmetric (sensitive eigenvalues)
  6. SVD: numerical rank, kernel vectors, the four subspaces
  7. Least squares: normal equations vs QR vs SVD on an ill-conditioned polynomial fit;
     truncated SVD; minimum-norm solution of an underdetermined system

Run:  python conditioning_svd.py          Figure: conditioning_svd.png
"""
import warnings
import numpy as np
import scipy.linalg as la
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

warnings.filterwarnings("ignore", category=la.LinAlgWarning)    # we WANT to solve ill-conditioned systems here
rng = np.random.default_rng(3)
np.set_printoptions(precision=4, suppress=True)

# ---------------------------------------------------------------- 1. norms
A = np.array([[10.0, -1.0, 2.0], [-1.0, 11.0, -1.0], [2.0, -1.0, 10.0]])
x = np.array([1.0, -2.0, 3.0])
s = la.svdvals(A)
print("1. norms")
print(f"   x = {x}: ||x||_1 = {la.norm(x, 1):.4f}, ||x||_2 = {la.norm(x):.4f}, ||x||_inf = {la.norm(x, np.inf):.4f}")
print(f"   ||A||_1 = {la.norm(A, 1):.4f} (max column sum), ||A||_inf = {la.norm(A, np.inf):.4f} (max row sum),"
      f" ||A||_2 = {la.norm(A, 2):.4f} = sigma_max {s[0]:.4f}, ||A||_F = {la.norm(A, 'fro'):.4f} = sqrt(sum sigma^2) {np.sqrt((s ** 2).sum()):.4f}")
B = rng.standard_normal((3, 3))
print(f"   submultiplicativity: ||AB||_2 = {la.norm(A @ B, 2):.3f} <= ||A|| ||B|| = {la.norm(A, 2) * la.norm(B, 2):.3f}")

# ---------------------------------------------------------------- 2. the 2x2 example
print("\n2. A = [[1, 1], [1, 1+eps]], b = [2, 2+eps], perturbation db = [0, eps]")
for eps in (1e-2, 1e-6, 1e-10):
    A2 = np.array([[1.0, 1.0], [1.0, 1.0 + eps]]); b2 = np.array([2.0, 2.0 + eps])
    x0 = la.solve(A2, b2); x1 = la.solve(A2, b2 + np.array([0.0, eps]))
    k = la.norm(A2, np.inf) * la.norm(la.inv(A2), np.inf)
    rel_b = eps / la.norm(b2, np.inf); rel_x = la.norm(x1 - x0, np.inf) / la.norm(x0, np.inf)
    print(f"   eps = {eps:.0e}: kappa_inf = {k:.3e} (4/eps = {4 / eps:.1e}); x = {x0}, perturbed x = {x1};"
          f" relative change b {rel_b:.1e} -> x {rel_x:.2f}")

# ---------------------------------------------------------------- 3. Hilbert matrices
print("\n3. Hilbert matrices H_ij = 1/(i+j-1), exact x = ones")
print(f"{'n':>3} {'kappa_2':>10} {'digits lost':>12} {'err f64':>10} {'err f32':>10} {'bound kappa*eps64':>18}")
H_rows = []
for n in range(2, 14):
    H = la.hilbert(n); xt = np.ones(n); b = H @ xt
    k = np.linalg.cond(H)
    e64 = la.norm(la.solve(H, b) - xt) / la.norm(xt)
    e32 = la.norm(la.solve(H.astype(np.float32), b.astype(np.float32)).astype(float) - xt) / la.norm(xt)
    H_rows.append((n, k, e64, e32))
    print(f"{n:3d} {k:10.2e} {np.log10(k):12.1f} {e64:10.1e} {e32:10.1e} {k * np.finfo(float).eps:18.1e}")


# ---------------------------------------------------------------- 4. mixed-precision iterative refinement
def refine(A, b, iters=8):
    lu32 = la.lu_factor(A.astype(np.float32))                       # O(n^3) work in single precision
    x = la.lu_solve(lu32, b.astype(np.float32)).astype(np.float64)
    hist = []
    for _ in range(iters):
        r = b - A @ x                                                # residual in DOUBLE precision
        d = la.lu_solve(lu32, r.astype(np.float32)).astype(np.float64)
        x = x + d
        hist.append(x.copy())
    return hist


n = 300
Q1, _ = la.qr(rng.standard_normal((n, n))); Q2, _ = la.qr(rng.standard_normal((n, n)))
A = Q1 @ np.diag(np.logspace(0, -4, n)) @ Q2.T                     # kappa = 1e4
xt = rng.standard_normal(n); b = A @ xt
hist = refine(A, b)

! refine_mixed.f90 -- Lecture 5: condition number from the SVD (LAPACK dgesvd) and mixed-precision
! iterative refinement: LU factorisation in SINGLE precision (sgetrf), residual r = b - A x in DOUBLE
! precision, corrections solved with the single-precision factors (sgetrs).
!
! Build:  gfortran -O2 refine_mixed.f90 -llapack -lblas -o refine_mixed && ./refine_mixed
program refine_mixed
  implicit none
  integer, parameter :: sp = kind(1.0), dp = kind(1.0d0)
  integer, parameter :: n = 300
  real(dp) :: a(n,n), q1(n,n), q2(n,n), xt(n), b(n), x(n), r(n), s(n), work(10*n*n), tau(n)
  real(dp) :: u(1,1), vt(1,1), tmp(n,n)
  real(sp) :: a32(n,n), r32(n)
  integer :: ipiv(n), info, i, k
  external :: dgesvd, dgeqrf, dorgqr, sgetrf, sgetrs

  call random_seed(put=[(7, i = 1, 64)])
  ! A = Q1 diag(logspace(0, -4)) Q2^T: condition number 1e4 by construction
  call random_number(q1); call random_number(q2)
  call dgeqrf(n, n, q1, n, tau, work, size(work), info); call dorgqr(n, n, n, q1, n, tau, work, size(work), info)
  call dgeqrf(n, n, q2, n, tau, work, size(work), info); call dorgqr(n, n, n, q2, n, tau, work, size(work), info)
  do i = 1, n
    q1(:,i) = q1(:,i) * 10.0_dp**(-4.0_dp*real(i-1,dp)/real(n-1,dp))
  end do
  a = matmul(q1, transpose(q2))

  tmp = a                                            ! dgesvd destroys its input
  call dgesvd('N', 'N', n, n, tmp, n, s, u, 1, vt, 1, work, size(work), info)
  print '(a, es10.3, a, es10.3, a, es10.3)', "sigma_max = ", s(1), "  sigma_min = ", s(n), "  kappa_2 = ", s(1)/s(n)

  call random_number(xt); b = matmul(a, xt)
  a32 = real(a, sp)
  call sgetrf(n, n, a32, n, ipiv, info)              ! the O(n^3) work, in single precision
  r32 = real(b, sp)
  call sgetrs('N', n, 1, a32, n, ipiv, r32, n, info)
  x = real(r32, dp)
  print '(a, es10.2)', "single-precision LU alone:  relative error ", norm2(x - xt)/norm2(xt)
  do k = 1, 6
    r = b - matmul(a, x)                             ! residual in double precision
    r32 = real(r, sp)
    call sgetrs('N', n, 1, a32, n, ipiv, r32, n, info)   ! correction: O(n^2) in single precision
    x = x + real(r32, dp)
    print '(a, i0, a, es10.2)', "refinement step ", k, ": relative error ", norm2(x - xt)/norm2(xt)
  end do
end program refine_mixed
