07. Discrete Signal Analysis/

A light curve, a strain record, a CMB scan are continuous functions x(t). A computer can only store x[n] = x(nT) rounded to one of 2B levels.

Above: move the sampling rate and the number of bits and watch the stored signal (dots) depart from the true one.

Two independent cuts: sampling (time axis, interval T) and quantisation (amplitude axis, step Δ). Each has its own error and its own rule.

  • The detector signal chain: photons → ADU

  • Quantisation step Δ and bits B

BASICSignals in astrophysics are continuous

  • Gravitational-wave strain h(t) in a laser interferometer; light curves I(t) from Kepler/TESS photometry.
  • Radio sky brightness I(l, m); CCD/CMOS pixel arrays I[i, j] — a spatial sampling of the telescope PSF.
  • CMB time-ordered data d(t) recorded while a telescope scans the sky.

A digital computer has finite memory and finite precision: it cannot store a function, only a list of numbers. We discretise along two orthogonal axes:

DEFINITIONThe two discretisationshover the symbols ↓
\underbrace{\h{xn}{x[n]}=x(\h{n}{n}\h{T}{T})}_{\text{sampling (domain)}},\qquad \underbrace{\h{Qx}{Q(x)}=\h{Delta}{\Delta}\cdot\text{round}(x/\h{Delta}{\Delta})}_{\text{quantisation (range)}},\qquad \h{fs}{f_s}=\frac1{\h{T}{T}}
T: sampling interval [s]; fs: sampling rate [Hz]; Δ: quantisation step (the least significant bit, LSB).
t = np.arange(N) / fs                  # sample times nT
x = np.sin(2*np.pi*f0*t)               # x[n]
xq = Delta * np.round(x / Delta)       # quantised
t = [(n, n = 0, N-1)] / fs
x = sin(2*pi*f0*t)
xq = Delta * anint(x / Delta)

BASICThe detector signal chain

  1. Physical field: photons hν on a CCD pixel, or CMB temperature fluctuations along the scan.
  2. Transducer: photo-electrons in the pixel well, or a resistance change in a cryogenic bolometer (TES).
  3. Conditioning: charge → voltage, pre-amplifier (or SQUID readout): a continuous voltage V(t).
  4. ADC: voltage → integer codes, 16-bit ADU for CCDs (65 536 levels), 24-bit Σ∆ for CMB time streams.
  5. File: FITS images or time-ordered data, the numbers we analyse.

Round a sine to B bits and look at the error e[n] = x − Q(x): it stays within ±Δ/2 and looks like white noise.

Reduce the amplitude (under-use of the range) or push it over full scale (clipping) and watch the SQNR.

SQNR ≈ 6.02 B + 1.76 dB for a full-scale sine. Using a quarter of the range loses 2 bits (12 dB); exceeding it clips and creates fake harmonics.

BASICThe quantisation step

DEFINITIONQuantisation step (LSB)hover the symbols ↓
\h{Delta}{\Delta}=\frac{\h{VFS}{V_{FS}}}{2^{\h{B}{B}}}=\frac{V_{\max}-V_{\min}}{2^{B}},\qquad \h{Qx}{Q(x)}=\h{Delta}{\Delta}\cdot\Big\lfloor\frac{x}{\Delta}+\frac12\Big\rfloor
Mid-tread quantiser: zero is a level. Within full scale the error is bounded: −Δ/2 ≤ e ≤ +Δ/2.
def simulate_adc(x, B, Vmin, Vmax):
    Delta = (Vmax - Vmin) / 2**B
    code = np.floor(x / Delta + 0.5)
    code = np.clip(code, -2**(B-1), 2**(B-1) - 1)     # saturation
    return Delta * code, Delta
code = floor(v/delta + 0.5_dp)
code = max(-2.0_dp**(B-1), min(2.0_dp**(B-1) - 1.0_dp, code))
q = delta*code

COREThe power of the quantisation error

Model e[n] as uniform on [−Δ/2, +Δ/2] (true when the signal varies over many levels), density p(e) = 1/Δ:

RESULTQuantisation noise powerhover the symbols ↓
\h{Pe}{P_e}=\h{sigmae}{\sigma_e^2}=\int_{-\Delta/2}^{\Delta/2}e^2\,\frac{1}{\h{Delta}{\Delta}}\dd e=\frac1\Delta\Big[\frac{e^3}{3}\Big]_{-\Delta/2}^{\Delta/2}=\frac{\h{Delta}{\Delta}^2}{12}

Signal-to-quantisation-noise ratio

  1. Full-scale sine x = (VFS/2) sin ωt: power Px = (VFS/2)²/2 = VFS²/8 = (2BΔ)²/8.
  2. Ratio: Px/Pe = [(2BΔ)²/8]/[Δ²/12] = 1.5 · 22B.
  3. In decibels: 10 log₁₀ 1.5 + 20 B log₁₀ 2 = 1.76 + 6.02 B.
RESULTSQNR rule of thumbhover the symbols ↓
\mathrm{SQNR}=10\log_{10}\frac{P_x}{\h{Pe}{P_e}}=10\log_{10}\!\big(1.5\cdot2^{2\h{B}{B}}\big)\approx 6.02\,\h{B}{B}+1.76\ \mathrm{dB}
Measured (code lab): 4 bits 23.6 dB (formula 25.8: the uniform model is rough with only 16 levels), 8 bits 49.1 (49.9), 12 bits 73.8 (74.0), 16 bits 98.0 (98.1).

COREManaging the dynamic range

  • Under-utilisation: a signal using a fraction ρ of full scale has Beff = B + log₂ ρ. A quarter of the range loses 2 bits (12 dB). Fix: analogue gain before the ADC.
  • Clipping: above Vmax the output is flat: a non-linear distortion that creates fake spectral lines (harmonics).
  • DC offset: a unipolar sensor (0–1 V) in a bipolar ADC (±2.5 V) uses at most a fifth of the codes: shift and scale first.

Sampling at fs replicates the spectrum at every multiple of fs. Exact recovery needs fs > 2fmax; otherwise f folds to |f − k fs|.

CORESampling as a multiplication

MODELDirac comb and ideal samplinghover the symbols ↓
\h{comb}{Ш_T(t)}=\h{sum}{\sum_{n=-\infty}^{\infty}}\delta(t-nT),\qquad \h{xs}{x_s(t)}=x(t)\,Ш_T(t)=\h{sum}{\sum_n}x(nT)\,\delta(t-nT)
The sequence x[n] ≡ x(nT) are the weights of the impulses. 2-D: the pixel pitch p of a CCD samples the PSF; undersampling (PSF FWHM < 2p) aliases spatially.

The spectrum of the sampled signal

  1. The transform of a comb is a comb: \(\mathcal F\{Ш_T\}=\frac{2\pi}T\sum_m\delta(\Omega-m\Omega_s)\), with Ωs = 2π/T.
  2. A product in time is a convolution in frequency: \(X_s=\frac1{2\pi}X*\mathcal F\{Ш_T\}\).
  3. Convolving with a shifted δ shifts: every term gives a copy of X centred at mΩs.
RESULTSpectrum of a sampled signalhover the symbols ↓
\h{Xs}{X_s(j\Omega)}=\frac{1}{\h{T}{T}}\h{sum}{\sum_{m=-\infty}^{\infty}}X\big(j(\Omega-m\,\h{Oms}{\Omega_s})\big)
The original spectrum, scaled by 1/T and repeated at every multiple of the sampling frequency. No information is lost if the copies do not overlap.
THEOREMNyquist–Shannon sampling theoremhover the symbols ↓
X(j\Omega)=0\ \text{for}\ |\Omega|\gt\Omega_B\quad\text{and}\quad \h{fs}{f_s}\gt 2\h{fmax}{f_{\max}}\ \Longrightarrow\ x(t)\ \text{is determined exactly by}\ x[n]
Nyquist rate 2fmax; Nyquist frequency fs/2 = the highest unaliased frequency. The inequality is strict: sin(2πfmaxt) sampled at exactly 2fmax with zero phase gives only zeros. Band-pass sampling allows fs ≥ 2(fH − fL) for a band [fL, fH] (radio down-conversion).
fnyq = fs / 2
fnyq = fs/2

COREAliasing

RESULTAlias frequencyhover the symbols ↓
\h{falias}{f_{\rm alias}}=|f-k\,\h{fs}{f_s}|,\qquad k=\mathrm{round}(f/f_s)

f_alias = abs(f - round(f / fs) * fs)

Preventing aliasing

An analogue low-pass anti-aliasing filter must sit before the ADC: it attenuates everything above fs − fmax (what would fold into [0, fmax]) down to the noise floor. Oversampling (fs ≫ 2fmax) relaxes the filter's roll-off.

Undersampled starsStars smaller than a pixel alias high spatial frequencies: distorted photometry and PSF shapes.
Wagon wheelsA film at 24 frames/s shows spokes turning backwards: temporal aliasing.

If the sampling theorem holds, the continuous signal can be rebuilt exactly: place a sinc at every sample, scaled by its value, and add them up.

Ideal reconstruction = keep the baseband copy (an ideal low-pass filter) = convolve the samples with sinc(t/T).

COREKeep the baseband copy

RESULTIdeal low-pass filter and its impulse responsehover the symbols ↓
H(j\Omega)=\begin{cases}T,&|\Omega|\le\Omega_s/2\\0,&\text{otherwise}\end{cases}\quad\Longrightarrow\quad h(t)=\frac{T}{2\pi}\int_{-\Omega_s/2}^{\Omega_s/2}e^{j\Omega t}\dd\Omega=\h{sinc}{\mathrm{sinc}}\Big(\frac tT\Big)=\frac{\sin(\pi t/T)}{\pi t/T}
THEOREMWhittaker–Kotelnikov–Shannon interpolationhover the symbols ↓
x(t)=\h{sum}{\sum_{n=-\infty}^{\infty}}\h{xn}{x[n]}\ \h{sinc}{\mathrm{sinc}}\Big(\frac{t-n\h{T}{T}}{\h{T}{T}}\Big)
Each sinc is 1 at its own sample and 0 at all the others: the sum passes exactly through the samples, and in between it is the only band-limited curve that does. The tails decay only as 1/t: in practice the sum is truncated (code lab: error 8×10⁻⁴ with 401 samples) or replaced by shorter kernels (Lanczos).
x_t = np.sum(x_n * np.sinc((t - n*T) / T))      # np.sinc(u) = sin(pi u)/(pi u)
do i = 1, size(t)
  u = (t(i) - n*T)/T
  xt(i) = sum(xn * merge(1.0_dp, sin(pi*u)/(pi*u), abs(u) < 1e-12_dp))
end do

Periodic in time ⇒ discrete in frequency. Discrete in time ⇒ periodic in frequency. The DFT is both.

The DTFT of x[n] is a continuous, 2π-periodic function of ω = ΩT = 2πf/fs. Real data ⇒ even magnitude, odd phase: only 0 … π (0 … fs/2) is needed.

end do

Magnitude even, phase odd: negative frequencies are redundant for real detector data, hence one-sided spectra on [0, fs/2]. Parseval: energy is the same in both domains.

The DFT only sees N samples and N frequencies fk = k fs/N. A tone exactly on a bin lands in one bin; a tone between bins spreads over all of them (leakage).

Bin spacing Δf = fs/N = 1/Tobs. Zero padding only interpolates the spectrum: it does not improve resolution.

CORETwo steps to a computable transform

  1. Truncate in time to n = 0 … N−1 (multiply by a rectangular window).
  2. Sample the DTFT at ωk = 2πk/N, k = 0 … N−1.
TRANSFORMN-point DFT pairhover the symbols ↓
\h{Xk}{X[k]}=\h{sum}{\sum_{n=0}^{N-1}}\h{xn}{x[n]}\,e^{-j\frac{2\pi}{N}kn},\qquad \h{xn}{x[n]}=\frac1{\h{N}{N}}\h{sum}{\sum_{k=0}^{N-1}}\h{Xk}{X[k]}\,e^{j\frac{2\pi}{N}kn}
X = np.fft.fft(x)           # forward, no 1/N
x = np.fft.ifft(X)          # inverse carries 1/N
call dft(z, Zk, -1)         ! dft_direct.f90
call dft(Zk, z2, +1);  z2 = z2/N
LINEAR ALGEBRATwiddle factor and DFT matrixhover the symbols ↓
\h{WN}{W_N}=e^{-j2\pi/N},\qquad \h{Xk}{X[k]}=\h{sum}{\sum_n}x[n]\,\h{WN}{W_N}^{kn},\qquad \mathbf X=\mathbf F_N\mathbf x,\quad \mathbf F_N^{-1}=\frac1N\mathbf F_N^*
n = np.arange(N); W = np.exp(-2j*np.pi*np.outer(n, n)/N)
X = W @ x                   # O(N^2)
do k = 0, N-1
  do j = 0, N-1
    W(k+1, j+1) = exp(cmplx(0.0_dp, -2*pi*mod(k*j, N)/real(N, dp), dp))
  end do
end do
X = matmul(W, x)

Orthogonality of the basis

  1. \(\sum_{n=0}^{N-1}W_N^{kn}W_N^{-rn}=\sum_n W_N^{(k-r)n}\).
  2. k = r: every term is 1, the sum is N.
  3. k ≠ r: a geometric series, \(\frac{1-W_N^{(k-r)N}}{1-W_N^{k-r}}=\frac{1-1}{1-W_N^{k-r}}=0\). Hence \(\sum_n W^{kn}W^{-rn}=N\delta_{kr}\).

COREPeriodicity, grid and symmetry

  • Implicit periodicity: the DFT treats x[n] and X[k] as one period of periodic sequences; shifts are circular, x[(n−n₀) mod N] ⇔ WNkn₀X[k]; a product of DFTs is a circular convolution (Lecture 9: zero padding).
  • Grid: fk = k fs/N, spacing Δf = fs/N = 1/(NT) = 1/Tobs.
  • Real input: X[k] = X*[(N−k) mod N]; X[0] and (N even) X[N/2] are real. N real numbers ↔ N/2+1 unique bins.
GRIDFrequency of bin khover the symbols ↓
\h{fk}{f_k}=k\,\h{df}{\Delta f}=\frac{k\,\h{fs}{f_s}}{\h{N}{N}},\qquad \h{df}{\Delta f}=\frac{1}{T_{\rm obs}}
f = np.fft.rfftfreq(N, 1/fs)       # 0 .. fs/2
f = [(k, k = 0, N/2)] * fs / N

"""
discretisation.py  --  Lecture 7: from a continuous signal to numbers, and the DFT.
  1. B-bit quantisation: measured SQNR against 6.02 B + 1.76 dB, under-utilisation, clipping
  2. aliasing: a 9 Hz tone sampled at 10 Hz looks like 1 Hz
  3. sinc (Whittaker-Shannon) reconstruction from the samples
  4. the direct O(N^2) DFT as a matrix, checked against numpy.fft
  5. the DFT grid: on-bin and off-bin tones (leakage), zero padding
  6. windows: a weak tone next to a strong one, rectangular vs Hann
Run:  python discretisation.py      -> prints numbers, saves discretisation.png
"""
import time
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

rng = np.random.default_rng(7)


# ---------------------------------------------------------------- 1. quantisation
def simulate_adc(x, B_bits, V_min, V_max):
    """B-bit mid-tread uniform quantiser with saturation (symmetric range)."""
    N_levels = 2 ** B_bits
    Delta = (V_max - V_min) / N_levels               # quantisation step (LSB)
    code = np.floor(x / Delta + 0.5)                  # nearest level
    code = np.clip(code, -N_levels // 2, N_levels // 2 - 1)   # two's-complement range
    return Delta * code, Delta


t = np.arange(200_000) / 200_000.0
print("1. quantisation of a full-scale sinusoid (V_FS = 5 V)")
print(f"   {'B':>3} {'Delta [V]':>11} {'var(e)':>11} {'Delta^2/12':>11} {'SQNR meas.':>11} {'6.02B+1.76':>11}")
for B in (4, 8, 12, 16):
    x = 2.5 * 0.9999 * np.sin(2 * np.pi * 7.123 * t)  # just below full scale: no clipping
    xq, D = simulate_adc(x, B, -2.5, 2.5)
    e = x - xq
    sqnr = 10 * np.log10(x.var() / e.var())
    print(f"   {B:3d} {D:11.3e} {e.var():11.3e} {D**2/12:11.3e} {sqnr:11.2f} {6.02*B+1.76:11.2f}")
for rho in (1.0, 0.25):
    x = 2.5 * 0.9999 * rho * np.sin(2 * np.pi * 7.123 * t)
    xq, D = simulate_adc(x, 12, -2.5, 2.5)
    print(f"   12 bits, signal using {rho:.2f} of full scale: SQNR = {10*np.log10(x.var()/(x-xq).var()):.1f} dB"
          f"  (B_eff = B + log2(rho) = {12 + np.log2(rho):.0f})")
xq, D = simulate_adc(2.8 * np.sin(2 * np.pi * 3 * t), 8, -2.5, 2.5)
print(f"   over-range 2.8 V into +-2.5 V: {np.mean(np.abs(xq) >= 2.5 - D):.1%} of the samples clipped")

# ---------------------------------------------------------------- 2. aliasing
f_sig, fs = 9.0, 10.0
k = round(f_sig / fs)
print(f"\n2. a {f_sig} Hz tone sampled at {fs} Hz appears at |f - k fs| = {abs(f_sig - k*fs):.1f} Hz")
n = np.arange(20)
same = np.allclose(np.cos(2*np.pi*f_sig*n/fs), np.cos(2*np.pi*abs(f_sig-k*fs)*n/fs))
print(f"   samples of the 9 Hz and of the 1 Hz cosine identical: {same}")

# ---------------------------------------------------------------- 3. sinc reconstruction
fs = 10.0; T = 1 / fs
n = np.arange(-200, 201)                             # many samples: the sinc tails are long
x_n = np.sin(2 * np.pi * 1.3 * n * T) + 0.5 * np.cos(2 * np.pi * 3.7 * n * T)
tt = np.linspace(-1, 2, 601)
x_rec = np.array([np.sum(x_n * np.sinc((ti - n * T) / T)) for ti in tt])   # np.sinc = sin(pi u)/(pi u)
x_true = np.sin(2 * np.pi * 1.3 * tt) + 0.5 * np.cos(2 * np.pi * 3.7 * tt)
print(f"\n3. sinc interpolation of a band-limited signal (fmax = 3.7 Hz < fs/2 = 5 Hz): "
      f"max error {np.max(np.abs(x_rec - x_true)):.1e} (truncated sum)")


# ---------------------------------------------------------------- 4. direct DFT
def dft_matrix(x):
    """Direct O(N^2) DFT: X = W x with W[k, n] = exp(-2 pi i k n / N)."""
    N = len(x)
    n = np.arange(N)
    W = np.exp(-2j * np.pi * np.outer(n, n) / N)
    return W @ x


x = rng.standard_normal(1024)
assert np.allclose(dft_matrix(x), np.fft.fft(x))
print("\n4. direct DFT == numpy.fft.fft:", True)
print(f"   {'N':>6} {'direct [ms]':>12} {'np.fft [ms]':>12} {'N^2/(N/2 log2 N)':>17}")
for N in (256, 512, 1024, 2048):
    x = rng.standard_normal(N)
    t0 = time.perf_counter(); dft_matrix(x); t1 = time.perf_counter()
    for _ in range(100): np.fft.fft(x)
    t2 = time.perf_counter()
    print(f"   {N:6d} {1e3*(t1-t0):12.2f} {1e3*(t2-t1)/100:12.4f} {N**2/(N/2*np.log2(N)):17.0f}")

# ---------------------------------------------------------------- 5. grid, leakage, padding
N, fs = 64, 64.0                                     # bins of 1 Hz
n = np.arange(N)
for f0 in (10.0, 10.5):
    X = np.abs(np.fft.rfft(np.cos(2 * np.pi * f0 * n / fs)))
    print(f"\n5. tone at {f0} Hz on a 1 Hz grid: bins with > 1% of the peak = {np.sum(X > 0.01*X.max())}")
Xp = np.abs(np.fft.rfft(np.cos(2*np.pi*10.5*n/fs), 1024))
print(f"   zero-padded to 1024: peak at {np.argmax(Xp)*fs/1024:.3f} Hz (finer grid, same resolution)")
x = rng.standard_normal(N)
X = np.fft.fft(x)
print(f"   Hermitian symmetry X[k] = conj X[N-k]: {np.allclose(X[1:], np.conj(X[1:][::-1]))};"
      f"  Parseval: {np.sum(x**2):.6f} = {np.sum(np.abs(X)**2)/N:.6f}")

# ---------------------------------------------------------------- 6. windows
fs, N = 1000.0, 1000
n = np.arange(N)
x = np.sin(2*np.pi*150.3*n/fs) + 1e-3*np.sin(2*np.pi*175.0*n/fs)   # weak line 60 dB below
f = np.fft.rfftfreq(4*N, 1/fs)
spec = {}
for name, w in (("rectangular", np.ones(N)), ("Hann", np.hanning(N)), ("Blackman", np.blackman(N))):
    S = np.abs(np.fft.rfft(x * w, 4*N))**2
    S /= S.max()
    spec[name] = 10*np.log10(S + 1e-30)
    i175 = np.argmin(np.abs(f - 175))
    print(f"6. {name:<12}: level at 175 Hz {spec[name][i175]:6.1f} dB, "
          f"floor at 190 Hz {spec[name][np.argmin(np.abs(f-190))]:6.1f} dB")

fig, ax = plt.subplots(1, 3, figsize=(15, 4))
ax[0].plot(t[:4000], (2.5*np.sin(2*np.pi*7.123*t) - simulate_adc(2.5*0.9999*np.sin(2*np.pi*7.123*t), 4, -2.5, 2.5)[0])[:4000])
ax[0].set(title="quantisation error, 4 bits", xlabel="t [s]")
ax[1].plot(tt, x_true, "k", lw=2, label="x(t)"); ax[1].plot(tt, x_rec, "r--", label="sinc sum")
ax[1].plot(n[:0], []); ax[1].set(title="sinc reconstruction", xlabel="t [s]"); ax[1].legend()
for k_, v in spec.items(): ax[2].plot(f, v, label=k_)
ax[2].set(xlim=(100, 250), ylim=(-140, 5), title="weak tone at 175 Hz, -60 dB", xlabel="f [Hz]"); ax[2].legend()
fig.tight_layout(); fig.savefig("discretisation.png", dpi=110)
print("saved discretisation.png")
! dft_direct.f90  --  Lecture 7 in Fortran
!   1. B-bit quantisation of a sinusoid: measured SQNR against 6.02 B + 1.76 dB
!   2. the direct O(N^2) DFT and its inverse: round trip, Parseval, a tone on its bin
!   3. timing: doubling N multiplies the time by ~4
! Compile & run:  gfortran -O2 dft_direct.f90 -o dft_direct && ./dft_direct
module dft_mod
  implicit none
  integer,  parameter :: dp = kind(1.0d0)
  real(dp), parameter :: pi = 4.0_dp*atan(1.0_dp)
contains
  subroutine dft(xin, xout, sgn)
    ! xout(k) = sum_j xin(j) exp(sgn * 2 pi i k j / npts),  k, j = 0..npts-1 (stored 1..npts)
    ! (Fortran is case-insensitive: x and X would be the SAME name)
    complex(dp), intent(in)  :: xin(:)
    complex(dp), intent(out) :: xout(:)
    integer, intent(in) :: sgn
    integer :: k, j, npts
    complex(dp) :: w
    npts = size(xin)
    do k = 0, npts - 1
       xout(k+1) = (0.0_dp, 0.0_dp)
       do j = 0, npts - 1
          ! mod(k*j, npts): the phase argument stays small, hence accurate
          w = exp(cmplx(0.0_dp, sgn*2.0_dp*pi*real(mod(k*j, npts), dp)/npts, dp))
          xout(k+1) = xout(k+1) + xin(j+1)*w
       end do
    end do
  end subroutine dft

  pure elemental real(dp) function quantise(v, delta, B)
    ! mid-tread quantiser with saturation to the B-bit two's-complement range
    real(dp), intent(in) :: v, delta
    integer, intent(in) :: B
    real(dp) :: code
    code = floor(v/delta + 0.5_dp)
    code = max(-2.0_dp**(B-1), min(2.0_dp**(B-1) - 1.0_dp, code))
    quantise = delta*code
  end function quantise
end module dft_mod

program dft_direct
  use dft_mod
  implicit none
  integer, parameter :: ns = 200000
  real(dp) :: t(ns), x(ns), xq(ns), delta, sqnr
  complex(dp), allocatable :: z(:), Z1(:), z2(:)
  integer :: B, i, N, kmax(1), t0, t1, rate
  real(dp) :: r(4096)

  ! ---- 1. quantisation
  do i = 1, ns
     t(i) = real(i-1, dp)/ns
  end do
  x = 2.5_dp*0.9999_dp*sin(2.0_dp*pi*7.123_dp*t)
  print '(a)', '  B   SQNR measured   6.02B+1.76'
  do B = 4, 16, 4
     delta = 5.0_dp/2.0_dp**B
     xq = quantise(x, delta, B)
     sqnr = 10.0_dp*log10(variance(x)/variance(x - xq))
     print '(i3, f15.2, f13.2)', B, sqnr, 6.02_dp*B + 1.76_dp
  end do

  ! ---- 2. DFT round trip, Parseval, a tone on bin 50
  N = 256
  allocate(z(N), Z1(N), z2(N))
  call random_number(r(1:N))
  z = cmplx(r(1:N) - 0.5_dp, 0.0_dp, dp)
  call dft(z, Z1, -1)
  call dft(Z1, z2, +1)
  z2 = z2/N                                       ! the inverse carries 1/N
  print '(a, es10.2)', 'round trip max error  ', maxval(abs(z2 - z))
  print '(a, 2f14.8)', 'Parseval  sum|x|^2, sum|X|^2/N:', sum(abs(z)**2), sum(abs(Z1)**2)/N
  do i = 1, N
     z(i) = cmplx(cos(2.0_dp*pi*50.0_dp*(i-1)/N), 0.0_dp, dp)
  end do
  call dft(z, Z1, -1)
  kmax = maxloc(abs(Z1(1:N/2)))
  print '(a, i0, a, f8.3)', 'pure tone: peak at k = ', kmax(1) - 1, ', |X| = ', abs(Z1(kmax(1)))
  deallocate(z, Z1, z2)

  ! ---- 3. O(N^2): timing
  print '(a)', '     N    time [ms]'
  N = 512
  do while (N <= 4096)
     allocate(z(N), Z1(N))
     call random_number(r(1:N)); z = cmplx(r(1:N), 0.0_dp, dp)
     call system_clock(t0, rate); call dft(z, Z1, -1); call system_clock(t1)
     print '(i6, f12.2)', N, 1000.0_dp*(t1 - t0)/rate
     deallocate(z, Z1)
     N = 2*N
  end do
contains
  real(dp) function variance(a)
    real(dp), intent(in) :: a(:)
    variance = sum((a - sum(a)/size(a))**2)/size(a)
  end function variance
end program dft_direct
