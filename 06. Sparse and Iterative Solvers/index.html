06. Sparse and Iterative Solvers/

A matrix is sparse when its number of non-zeros, nnz, is much smaller than n². A CMB pointing matrix has one or two non-zeros per row; a 3D Poisson operator seven.

Above: click cells of the 5×5 matrix to add or remove entries and watch the three formats change.

CSR: values, column indices, and a row pointer of length n + 1. Row i lives in val[ptr[i] : ptr[i+1]].

  • Where sparse matrices come from
  • CSR, CSC, COO
  • 0-based vs 1-based indices
  • Which format for which operation

BASICWhere they come from

  • CMB map-making: the pointing matrix links each time sample to one sky pixel: one non-zero per row.
  • Poisson and diffusion solvers: ∇²Φ = 4πGρ on a 3D grid couples each cell to six neighbours.
  • Finite elements, networks, graphs: each node talks to a few others.

The 2D Poisson matrix on a k×k grid has n = k² rows and about 5n non-zeros. Its Cholesky factor fills the whole band of width k: nnz(L) ~ n^{3/2}.

Above: the sparsity pattern of A and of its Cholesky factor L for three orderings of the unknowns.

Iterative methods only need y = Ax: memory O(nnz), no fill-in. Direct sparse solvers reorder (RCM, minimum degree, nested dissection) to limit the fill.

f(x) = ½xᵀAx − bᵀx has gradient Ax − b: its minimum is the solution. The residual r = b − Ax is the downhill direction.

Above: click to choose the starting point; change κ and compare steepest descent with conjugate gradient.

The exact line-search step is α = rᵀr / rᵀAr. In a long narrow valley (large κ) steepest descent zig-zags: the number of steps grows like κ.
  • Ax = b as a minimisation
  • Gradient and residual
  • Optimal step length
  • Zig-zag in narrow valleys
  • Convergence ∝ κ
THEOREMQuadratic formhover the symbols ↓
f(\mathbf x)=\tfrac12\mathbf x^T\h{A}{A}\mathbf x-\mathbf b^T\mathbf x,\qquad \nabla f=A\mathbf x-\mathbf b=-\h{rk}{\mathbf r},\qquad A\ \text{SPD}\Rightarrow\ \min f\ \Leftrightarrow\ A\mathbf x=\mathbf b
The level sets of f are ellipses with axes along the eigenvectors of A and lengths ∝ 1/√λ: κ is the squared aspect ratio of the bowl.
ALGORITHMSteepest descenthover the symbols ↓
\mathbf r_k=\mathbf b-A\mathbf x_k,\qquad \h{alpha}{\alpha_k}=\frac{\mathbf r_k^T\mathbf r_k}{\mathbf r_k^TA\mathbf r_k},\qquad \mathbf x_{k+1}=\mathbf x_k+\alpha_k\mathbf r_k
αk solves d f(xk + α rk)/dα = 0: the lowest point along the line. Consecutive residuals are orthogonal: the path turns by 90° at every step. Error reduction per step ≤ (κ−1)/(κ+1). 2×2 with κ = 10: 13 steps; 2D Poisson k = 64 (κ = 1712): 2253 iterations to 10⁻⁶.

Ar = A @ r

x += alpha * r;  r -= alpha * Ar
call spmv(A, r, ar)
alpha = dot_product(r, r) / dot_product(r, ar)
x = x + alpha*r;  r = r - alpha*ar

CG keeps the cheapness of steepest descent (one product Ap per step, a few vectors in memory) but removes the zig-zag by remembering the previous direction.

Above: residual histories of steepest descent and CG on the 2D Poisson problem.

piᵀApj = 0 (A-orthogonality). Iterations to a given accuracy grow like √κ, not κ.

DEFINITIONConjugate directionshover the symbols ↓
\h{pk}{\mathbf p_i}^TA\,\mathbf p_j=0\quad(i\ne j),\qquad \langle\mathbf u,\mathbf v\rangle_A=\mathbf u^TA\mathbf v
For A = I conjugate means orthogonal. Minimising f along n A-conjugate directions, one after the other, reaches the exact minimum: CG terminates in ≤ n steps in exact arithmetic (2 steps for the 2×2 example). For large n we stop much earlier, at a tolerance.
ALGORITHMConjugate gradienthover the symbols ↓
\begin{aligned}&\mathbf r_0=\mathbf b-A\mathbf x_0,\ \mathbf p_0=\mathbf r_0;\quad \h{alpha}{\alpha_k}=\frac{\mathbf r_k^T\mathbf r_k}{\mathbf p_k^TA\mathbf p_k},\ \ \mathbf x_{k+1}=\mathbf x_k+\alpha_k\mathbf p_k,\ \ \mathbf r_{k+1}=\mathbf r_k-\alpha_kA\mathbf p_k\\ &\h{beta}{\beta_k}=\frac{\mathbf r_{k+1}^T\mathbf r_{k+1}}{\mathbf r_k^T\mathbf r_k},\quad \mathbf p_{k+1}=\mathbf r_{k+1}+\beta_k\mathbf p_k\end{aligned}
One mat-vec, two dot products, three vector updates per step; memory: x, r, p, Ap. Error bound: ‖ek‖A ≤ 2((√κ−1)/(√κ+1))k‖e₀‖A, so k ≈ ½√κ ln(2/tol). In floating point the directions slowly lose conjugacy; convergence is delayed, not lost.
r = b - A @ x; p = r.copy(); rr = r @ r
for k in range(maxit):
    Ap = A @ p; alpha = rr / (p @ Ap)
    x += alpha * p; r -= alpha * Ap
    rr_new = r @ r
    if np.sqrt(rr_new) < tol * nb: break
    p = r + (rr_new / rr) * p; rr = rr_new
do it = 1, maxit
   call spmv(a, p, ap)
   alpha = rz / dot_product(p, ap)
   x = x + alpha*p;  r = r - alpha*ap
   if (norm2(r)/nr0 < tol) exit
   rz_new = dot_product(r, r)
   p = r + (rz_new/rz)*p;  rz = rz_new
end do

A scanning telescope records a time stream d = Pm + offsets + noise. Solving for the map m and the slow offsets is a least-squares problem whose matrix is never built: Pᵀ is "bin the samples into pixels", P is "read the map along the scan".

(AᵀN⁻¹A) m = AᵀN⁻¹ d is solved by CG with A applied on the fly. Its null space (a constant map minus constant offsets) is the monopole, invisible to a differential instrument.
  • Operators instead of matrices
  • Pointing matrix P and its transpose
  • Destriping with per-scan offsets
  • The kernel: the monopole
  • CG on a singular, consistent system
MODELMap-making normal equationshover the symbols ↓
\mathbf d=A\mathbf z+\mathbf n,\quad A=[\,P\ \ F\,],\ \ \mathbf z=\begin{pmatrix}\mathbf m\\ \mathbf a\end{pmatrix};\qquad (A^TN^{-1}A)\,\mathbf z=A^TN^{-1}\mathbf d
P: one non-zero per row (the pixel seen at each time). F: one non-zero per row (the scan the sample belongs to), multiplying the offsets a. With white noise N ∝ I. Each CG iteration: one pass reading the map along the scan (A z) and one pass binning back (Aᵀ t): O(nsamples).
def apply_A(z):  return z[:npix][pix] + np.repeat(z[npix:], slen)
def apply_AT(t): return np.concatenate([np.bincount(pix, t, npix), t.reshape(nscan, slen).sum(1)])
N = scipy.sparse.linalg.LinearOperator((nu, nu), matvec=lambda z: apply_AT(apply_A(z)))
z, info = scipy.sparse.linalg.cg(N, apply_AT(d))
! matvec: t = map(pix(:)) + offs(scan_of(:));  then bin: m_out(pix(i)) += t(i), a_out(scan_of(i)) += t(i)

Test (sparse_iterative.py): 16 384 samples, 64 pixels, 1024 scans of 16 samples, offsets with σ = 2, white noise 0.1. CG converges in 28 iterations; map error 0.007 (after removing the mean) against 0.089 for the naive binned map that ignores the offsets. The mean of the map is not recovered (off by 0.06): (AᵀA)(1, …, 1 | −1, …, −1)ᵀ = 0 exactly — the monopole lies in the null space (Lecture 5). CG started from zero never moves along it.

κ sets the iteration count. A preconditioner M reshapes the bowl into something rounder, at the cost of solving Mz = r once per iteration.

Above: a diffusion problem whose coefficient jumps by orders of magnitude, solved with three preconditioners.

Good M: close to A (κ(M⁻¹A) small) and cheap to apply. Jacobi = diag(A): free, fixes bad scaling. IC(0): Cholesky that keeps A's sparsity: strong, but costs a triangular solve per step.

# ---------------------------------------------------------------- 2. memory and SpMV
def poisson2d(k):
    """5-point Laplacian on a k x k grid, Dirichlet boundaries: n = k^2 unknowns, about 5 non-zeros per row."""
    T = sp.diags([-np.ones(k - 1), 2 * np.ones(k), -np.ones(k - 1)], [-1, 0, 1])
    I = sp.identity(k)
    return (sp.kron(I, T) + sp.kron(T, I)).tocsr()

# ---------------------------------------------------------------- 4. SD vs CG
def steepest_descent(A, b, x0, tol=1e-6, maxit=100_000, path=False):
    x = x0.copy(); r = b - A @ x; nr0 = np.linalg.norm(r); pts = [x.copy()]
    for k in range(maxit):
        Ar = A @ r; alpha = (r @ r) / (r @ Ar)
        x += alpha * r; r -= alpha * Ar; pts.append(x.copy())
        if np.linalg.norm(r) / nr0 < tol: return x, k + 1, pts
    return x, maxit, pts


def cg(A, b, x0, tol=1e-6, maxit=100_000, M_solve=None):
    x = x0.copy(); r = b - A @ x; z = r if M_solve is None else M_solve(r); p = z.copy()
    rz = r @ z; nr0 = np.linalg.norm(r); pts = [x.copy()]; hist = [1.0]
    for k in range(maxit):
        Ap = A @ p; alpha = rz / (p @ Ap)
        x += alpha * p; r -= alpha * Ap; pts.append(x.copy())
        hist.append(np.linalg.norm(r) / nr0)
        if hist[-1] < tol: return x, k + 1, pts, hist
        z = r if M_solve is None else M_solve(r)
        rz_new = r @ z; p = z + (rz_new / rz) * p; rz = rz_new
    return x, maxit, pts, hist


A2 = np.array([[1.0, 0.0], [0.0, 10.0]]); R = np.array([[np.cos(0.5), -np.sin(0.5)], [np.sin(0.5), np.cos(0.5)]]); A2 = R @ A2 @ R.T

def diffusion2d(k, c):
    """-div(c grad u) on a k x k grid with cell coefficients c (k+1 x k+1 faces approximated by averages)."""
    idx = np.arange(k * k).reshape(k, k); rows, cols, vals = [], [], []
    for i in range(k):
        for j in range(k):
            d = 0.0
            for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                ii, jj = i + di, j + dj
                cf = 0.5 * (c[i, j] + c[min(max(ii, 0), k - 1), min(max(jj, 0), k - 1)])
                d += cf
                if 0 <= ii < k and 0 <= jj < k:
                    rows.append(idx[i, j]); cols.append(idx[ii, jj]); vals.append(-cf)
            rows.append(idx[i, j]); cols.append(idx[i, j]); vals.append(d)
    return sp.csr_matrix((vals, (rows, cols)), shape=(k * k, k * k))


def ic0(A):
    """Incomplete Cholesky with zero fill: L has the sparsity pattern of tril(A)."""
    L = sp.tril(A, format="csr").astype(float).tolil(); n = A.shape[0]
    Lr = [dict(zip(L.rows[i], L.data[i])) for i in range(n)]
    for i in range(n):
        for j in sorted(Lr[i]):
            if j < i:
                s = sum(Lr[i][kk] * Lr[j][kk] for kk in Lr[i] if kk < j and kk in Lr[j])
                Lr[i][j] = (Lr[i][j] - s) / Lr[j][j]
        Lr[i][i] = np.sqrt(Lr[i][i] - sum(v * v for kk, v in Lr[i].items() if kk < i))
    rows = [i for i in range(n) for _ in Lr[i]]; cols = [j for i in range(n) for j in Lr[i]]; vals = [v for i in range(n) for v in Lr[i].values()]
    return sp.csr_matrix((vals, (rows, cols)), shape=(n, n))

! cg_csr.f90 -- Lecture 6: the 2D Poisson matrix in CSR storage, a parallel (OpenMP) sparse
! matrix-vector product, and the conjugate gradient method with and without a Jacobi preconditioner.
! The right-hand side comes from a known solution, so the true error can be printed.
!
! Build:  gfortran -O2 -fopenmp cg_csr.f90 -o cg_csr && OMP_NUM_THREADS=4 ./cg_csr
module csr_mod
  implicit none
  integer, parameter :: dp = kind(1.0d0)
  type :: csr_matrix
    integer :: n = 0, nnz = 0
    real(dp), allocatable :: val(:)
    integer, allocatable :: col(:), ptr(:)          ! 1-based: row i occupies val(ptr(i) : ptr(i+1)-1)
  end type csr_matrix
contains

  ! 5-point Laplacian on a k x k grid (Dirichlet boundaries), assembled row by row directly in CSR
  function poisson2d(k) result(a)
    integer, intent(in) :: k
    type(csr_matrix) :: a
    integer :: i, j, row, p
    a%n = k*k
    allocate(a%val(5*k*k), a%col(5*k*k), a%ptr(k*k+1))
    p = 1
    do j = 1, k
      do i = 1, k
        row = (j-1)*k + i
        a%ptr(row) = p
        if (j > 1) call put(row - k, -1.0_dp)
        if (i > 1) call put(row - 1, -1.0_dp)
        call put(row, 4.0_dp)
        if (i < k) call put(row + 1, -1.0_dp)
        if (j < k) call put(row + k, -1.0_dp)
      end do
    end do
    a%ptr(a%n + 1) = p
    a%nnz = p - 1
  contains
    subroutine put(c, v)
      integer, intent(in) :: c
      real(dp), intent(in) :: v
      a%col(p) = c; a%val(p) = v; p = p + 1
    end subroutine put
  end function poisson2d

  ! y = A x: one pass over the non-zeros, rows are independent -> trivially parallel
  subroutine spmv(a, x, y)
    type(csr_matrix), intent(in) :: a
    real(dp), intent(in) :: x(:)
    real(dp), intent(out) :: y(:)
    integer :: i, p
    real(dp) :: s
    !$omp parallel do private(p, s) schedule(static)
    do i = 1, a%n
      s = 0.0_dp
      do p = a%ptr(i), a%ptr(i+1) - 1
        s = s + a%val(p) * x(a%col(p))
      end do
      y(i) = s
    end do
    !$omp end parallel do
  end subroutine spmv

  ! (Preconditioned) conjugate gradient. If dinv is present, M = diag(A) (Jacobi).
  subroutine cg(a, b, x, tol, iters, dinv)
    type(csr_matrix), intent(in) :: a
    real(dp), intent(in) :: b(:), tol
    real(dp), intent(inout) :: x(:)
    integer, intent(out) :: iters
    real(dp), intent(in), optional :: dinv(:)
    real(dp), allocatable :: r(:), z(:), p(:), ap(:)
    real(dp) :: rz, rz_new, alpha, nr0
    allocate(r(a%n), z(a%n), p(a%n), ap(a%n))
    call spmv(a, x, ap); r = b - ap
    if (present(dinv)) then; z = dinv * r; else; z = r; end if
    p = z; rz = dot_product(r, z); nr0 = norm2(r)
    do iters = 1, 10*a%n
      call spmv(a, p, ap)
      alpha = rz / dot_product(p, ap)
      x = x + alpha * p
      r = r - alpha * ap
      if (norm2(r) / nr0 < tol) return
      if (present(dinv)) then; z = dinv * r; else; z = r; end if
      rz_new = dot_product(r, z)
      p = z + (rz_new / rz) * p
      rz = rz_new
    end do
  end subroutine cg
end module csr_mod

program cg_csr
  use csr_mod
  !$ use omp_lib
  implicit none
  integer, parameter :: ks(4) = [64, 128, 256, 512]
  type(csr_matrix) :: a
  real(dp), allocatable :: xt(:), b(:), x(:), dinv(:)
  integer :: ik, k, it, i, nthreads
  integer(8) :: c0, c1, rate
  real(dp), parameter :: pi = acos(-1.0_dp)

  nthreads = 1
  !$ nthreads = omp_get_max_threads()
  call system_clock(count_rate=rate)
  print '(a,i0,a)', "2D Poisson, CSR storage, ", nthreads, " thread(s)"
  print '(a)', "     k          n        nnz   CSR [MB]   CG iters   time [ms]   max error   kappa est."
  do ik = 1, size(ks)
    k = ks(ik)
    a = poisson2d(k)
    allocate(xt(a%n), b(a%n), x(a%n))
    do i = 1, a%n                                     ! a smooth solution that is NOT an eigenvector
      xt(i) = bump(real(mod(i-1,k)+1,dp)/(k+1)) * bump(real((i-1)/k+1,dp)/(k+1))
    end do
    call spmv(a, xt, b)
    x = 0.0_dp
    call system_clock(c0); call cg(a, b, x, 1.0e-8_dp, it); call system_clock(c1)
    print '(i6, i11, i11, f11.2, i11, f12.1, es12.2, f12.0)', k, a%n, a%nnz, &
          (8.0_dp*a%nnz + 4.0_dp*(a%nnz + a%n + 1))/1.0e6_dp, it, 1.0e3_dp*real(c1-c0,dp)/real(rate,dp), &
          maxval(abs(x - xt)), (cos(pi/(2*(k+1))) / sin(pi/(2*(k+1))))**2
    deallocate(xt, b, x)
  end do

  ! Jacobi preconditioning on a badly scaled system: S A S with S = diag(10^u), u in [0, 3]
  k = 128
  a = poisson2d(k)
  allocate(xt(a%n), b(a%n), x(a%n), dinv(a%n))
  call random_seed(put=[(11, i = 1, 64)])
  call random_number(xt); xt = 10.0_dp**(3.0_dp*xt)        ! reuse xt as the scaling S
  do i = 1, a%n
    a%val(a%ptr(i):a%ptr(i+1)-1) = a%val(a%ptr(i):a%ptr(i+1)-1) * xt(i) * xt(a%col(a%ptr(i):a%ptr(i+1)-1))
  end do
  do i = 1, a%n
    dinv(i) = 1.0_dp / (4.0_dp * xt(i)**2)
  end do
  call random_number(xt); call spmv(a, xt, b)
  x = 0.0_dp; call cg(a, b, x, 1.0e-8_dp, it)
  print '(/,a,i0,a,es9.2)', "badly scaled Poisson (k = 128): CG         ", it, " iterations, error ", maxval(abs(x - xt))
  x = 0.0_dp; call cg(a, b, x, 1.0e-8_dp, it, dinv)
  print '(a,i0,a,es9.2)', "                               Jacobi-PCG ", it, " iterations, error ", maxval(abs(x - xt))
contains
  pure real(dp) function bump(s)
    real(dp), intent(in) :: s
    bump = s*(1.0_dp - s)*exp(2.0_dp*s)
  end function bump
end program cg_csr
