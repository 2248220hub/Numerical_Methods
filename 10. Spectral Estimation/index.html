10. Spectral Estimation/

The power spectrum describes the process that generates the data, not the single record we measured: observing again would give a different |FFT|². We must estimate the process from one realisation.

Take 16 times more data and the cloud of points gets denser, not narrower: the scatter of |X|²/N around the true PSD stays equal to the PSD itself.
  • Why we need Sn(f)
  • Wide-sense stationarity
  • Wiener–Khinchin theorem
  • Biased autocorrelation estimate
  • Non-parametric vs parametric estimation

BASICThe model signal

Throughout this lesson: a periodic signal (fundamental 7 Hz and harmonics at 14, 21, 28 Hz) sampled at 100 Hz, buried in noise with PSD Sn(f) = 10⁻³(1 + 1 Hz/f): white above 1 Hz, rising below. Its |FFT|² scatters wildly around Sn: in the line-free band 32–45 Hz the ratio P/Sn has mean 1.08 and standard deviation 1.05 for T = 64 s — and still 0.99 for T = 1024 s.

COREWhat we want to estimate

DEFINITIONWiener–Khinchin theoremhover the symbols ↓
\h{Pxx}{P_{xx}(f)}=\h{sum}{\sum_{k=-\infty}^{+\infty}}\h{Rxx}{R_{xx}(k)}\,e^{-j2\pi fk},\qquad R_{xx}(k)=E\big[x[n]\,x^*[n-k]\big],\qquad f\in[-\tfrac12,\tfrac12]
For a wide-sense stationary (WSS) process — mean and autocorrelation independent of time — the PSD is the DTFT of the autocorrelation. f is in cycles/sample: multiply by fs for Hz.
R = np.correlate(x, x, 'full') / N         # biased estimate, lags -(N-1)..N-1
P = np.abs(np.fft.fft(R)) / 1              # its transform = the periodogram
do k = 0, N-1
   R(k) = sum(x(k+1:N)*x(1:N-k))/N         ! biased: divide by N, not N-k
end do
ESTIMATORBiased autocorrelation estimatehover the symbols ↓
\hat R_{xx}(k)=\frac1N\h{sum}{\sum_{n=k}^{N-1}}x[n]\,x^*[n-k],\qquad 0\le k\le N-1
Dividing by N (not N − k) makes it biased but guarantees a non-negative spectrum. Non-parametric estimation (this lesson, mostly): no model of the process, only Fourier transforms. Parametric: assume S(f; θ) and fit θ (section 6).

One Fourier bin is one complex coefficient: two Gaussian numbers. Their squared sum is χ² with 2 degrees of freedom — an exponential distribution, as wide as it is high.

More data buy resolution, not stability: doubling N doubles the number of bins, each still estimated from 2 degrees of freedom.

  • Variance: Isserlis' theorem

  • Inconsistency; scipy normalisation

\h{Pper}{\hat P_{\rm PER}(f)}=\frac1N\Big|\h{sum}{\sum_{n=0}^{N-1}}x[n]\,e^{-j2\pi fn}\Big|^2=\frac1N|X(f)|^2=\sum_{k=-(N-1)}^{N-1}\hat R_{xx}(k)\,e^{-j2\pi fk}

print(np.trapezoid(P, f), x.var())        # Parseval: equal

P = 2*abs(Xk)**2/(N*fs);  P(1) = P(1)/2;  P(N/2+1) = P(N/2+1)/2   ! one-sided, units^2/Hz

Normalisation: scipy returns the one-sided PSD in units²/Hz, 2|X|²/(N fs) for 0 < f < fs/2. The formulas here are two-sided with fs = 1: a factor 2/fs apart. Always check Parseval: ∫P df = variance of the data.

COREBias

RESULTExpected periodogramhover the symbols ↓
E[\hat P_{\rm PER}(f)]=\int_{-1/2}^{1/2}P_{xx}(\nu)\,\h{WB}{W_B(f-\nu)}\,d\nu,\qquad W_B(f)=\frac1N\Big(\frac{\sin\pi fN}{\sin\pi f}\Big)^2
E[R̂(k)] = (1 − |k|/N)R(k): a triangular (Bartlett) weight — not a choice, only N − |k| products exist at lag k. Its transform is the Fejér kernel ≥ 0, width ~1/N (resolution 1/T in Hz), sidelobes −13 dB. As N → ∞ it tends to δ(f): asymptotically unbiased.

COREVariance and distribution

RESULTCovariance of periodogram bins (Gaussian process)hover the symbols ↓
\mathrm{Cov}\big[\hat P(f_1),\hat P(f_2)\big]\approx P_{xx}(f_1)P_{xx}(f_2)\big[F_N^2(f_1+f_2)+F_N^2(f_1-f_2)\big],\quad F_N(f)=\frac{\sin\pi Nf}{N\sin\pi f}
Fourth moments of a Gaussian reduce to products of second moments (Isserlis 1918). f₁ = f₂: Var = P²xx (2P² at 0 and ½). f₁ − f₂ = m/N: covariance ≈ 0 — Fourier bins are uncorrelated.
RESULTDistribution of one binhover the symbols ↓
\hat P_{\rm PER}(f_k)\sim P_{xx}(f_k)\,\frac{\chi^2_2}{2},\qquad \lim_{N\to\infty}\mathrm{Var}[\hat P_{\rm PER}(f)]=P_{xx}^2(f)\neq0
Standard deviation = mean: an exponential distribution. P(P̂ > t·Pxx) = e−t: a 4.6× fluctuation happens in 1% of bins, so in a spectrum of 10⁴ bins you see a hundred of them. The estimator is inconsistent.
p_exceed = np.exp(-t)      # periodogram bin above t times the true PSD
p_exceed = exp(-t)

We cannot repeat the universe, but we can cut our record into pieces and pretend each piece is a new realisation. Averaging K periodograms shrinks the scatter by √K.

L sets the resolution (bins of fs/L), K sets the variance (∝ 1/K). With 50% overlap and Hann, K ≈ 2N/L nearly independent segments.
  • Bartlett: disjoint segments
  • Welch: overlap + taper, normalisation U
  • Variance with overlap
  • χ²ν confidence intervals
  • Choosing L; Blackman–Tukey

COREBartlett

Split the N samples into K disjoint segments of length L (N = KL), compute each periodogram, average. Bias: Fejér kernel of width ~1/L. Variance ≈ P²xx/K. Letting L → ∞ and K → ∞ together: consistent.

COREWelch

ESTIMATORWelch estimatorhover the symbols ↓
\h{Pw}{\hat P_W(f)}=\frac1{\h{K}{K}\,\h{L}{L}\,\h{U}{U}}\h{sum}{\sum_{i=0}^{K-1}}\Big|\sum_{n=0}^{L-1}\h{wn}{w[n]}\,x[n+iD]\,e^{-j2\pi fn}\Big|^2,\qquad U=\frac1L\sum_{n=0}^{L-1}w^2[n],\quad K=\Big\lfloor\frac{N-L}{D}\Big\rfloor+1
Segments shifted by D (typically L/2); each multiplied by a taper. U is the mean power of the taper: without it a Hann-tapered estimate (U = 3/8) is 2.7 times too low. Overlap and taper are independent choices: the taper fights leakage, the overlap recovers the down-weighted edge samples and buys variance.
f, P = scipy.signal.welch(x, fs, window='hann', nperseg=L, noverlap=L//2, detrend='constant')
K = (N - L)/D + 1
do i = 1, K
   s = (i-1)*D + 1
   seg = w*(x(s:s+L-1) - sum(x(s:s+L-1))/L)
   call fftw_execute_dft_r2c(plan, seg, Xk)
   P = P + abs(Xk)**2
end do
P = 2*P/(K*L*U*fs)          ! one-sided density (halve the f = 0 and Nyquist bins)
RESULTConfidence intervalhover the symbols ↓
\hat P_W(f)\sim P_{xx}(f)\,\frac{\chi^2_\nu}{\nu},\quad \nu=2K_{\rm eff}\qquad\Longrightarrow\qquad \frac{\nu\hat P}{\chi^2_{\nu,1-\alpha/2}}\le P_{xx}(f)\le\frac{\nu\hat P}{\chi^2_{\nu,\alpha/2}}
Overlapping segments are correlated: Keff ≤ K (Hann, 50%: Keff ≈ 0.95 K). On a log axis the band has constant width. Model signal, Hann, L = 512 (bins 0.2 Hz), K = 24, ν = 45.6: scatter 0.21 (1/√K = 0.20), band 0.69–1.58 × estimate, true Sn inside in 95% of 214 line-free bins.
lo, hi = nu / scipy.stats.chi2.ppf([0.975, 0.025], nu)     # multiply the estimate by these
! chi2 quantiles: tabulate them, or use a Wilson-Hilferty approximation

Choosing L

  • Smooth spectrum: MSE ≈ A/L⁴ (bias²) + BL/N (variance) ⇒ Lopt ∝ N1/5: most extra data go into averaging.
  • Lines to resolve: fix L so the required resolution spans 1–2 bins, spend all extra data on K.
  • Check: double L; if the estimate moves outside the χ²ν band, the bias is not negligible yet.

Blackman–Tukey (1958) smooths instead: weight R̂(k) with a lag window of length M ≪ N. Equivalent to smoothing the periodogram; positive only if the window's transform is ≥ 0 (triangular yes, Hann no). Today essentially replaced by Welch.

Every segment is multiplied by some window — the rectangular one if you do nothing. Its transform is the kernel placed around every line.

Smoother is faster: a window with p − 1 continuous derivatives has sidelobes decaying as 6(p + 1) dB/octave. Leakage is bias, not variance: averaging does not remove it.

  • Rectangular, triangular, Hann, Hamming, Tukey, Planck
  • Smoothness ⇔ sidelobe decay
  • Symmetric vs periodic forms
  • Practical rules

COREFour numbers

  • −3 dB main-lobe width (bins of 1/L): resolution of two close lines.
  • ENBW = L Σw²/(Σw)² bins: width of the rectangle with the same white-noise power. ENBW > 1: edge samples down-weighted, statistics lost.
  • Highest sidelobe (dB): leakage from a nearby strong line.
  • Sidelobe decay (dB/octave): leakage from a distant strong feature.
DEFINITIONSWindow formulas (symmetric, n = 0 … L−1)hover the symbols ↓
w_{\rm Hann}=\tfrac12-\tfrac12\cos\frac{2\pi n}{L-1},\quad w_{\rm Hamming}=0.54-0.46\cos\frac{2\pi n}{L-1},\quad w_{\rm Planck}=\frac1{1+e^{Z(n)}},\ Z=\frac mn-\frac m{m-n}
For spectral estimation use the periodic form (L instead of L − 1; scipy sym=False, the default of welch). Tukey(α): cosine edges over a fraction α, flat centre (α = 0 rectangular, α = 1 Hann). Planck taper (gravitational-wave analysis): edges with all derivatives zero, C∞.

w = [(0.5_dp - 0.5_dp*cos(2*pi*n/L), n = 0, L-1)]   ! periodic Hann

Rules

  • Broadband smooth spectrum: Hann (safe default); Tukey or Planck keep more data at full weight.
  • Close lines of similar amplitude: narrow main lobe (rectangular, Tukey with small α).
  • Weak line near a strong one: low first sidelobe (Hann, Hamming). Code lab: two lines 20 dB apart at 0.20 and 0.22 — weak line / valley contrast 1.7 rectangular, 27.4 Hann.
  • Weak features far from a dominant one (steep red noise): fast decay (Hann, Planck) and prewhiten. Never Hamming.
  • Whatever the window, resolution ~ ENBW/L: to separate lines, increase L.

Real detectors are white only above a knee frequency. Below it, a longer integration brings in more slow drift: averaging stops helping.

S(f) = σ²[1 + (fk/f)α]. Fit it with the Whittle likelihood on the raw periodogram: every bin, exact χ²₂ distribution, no bias.

  • Colours: white, pink, red
  • Where the colours come from
  • Timmer–König generation

MODELWhite noise with a 1/f kneehover the symbols ↓
\h{Sf}{S(f)}=\h{sigma2}{\sigma^2}\Big[1+\Big(\frac{\h{fk}{f_k}}{f}\Big)^{\h{alpha}{\alpha}}\Big]
σ²: white level (sensitivity). fk: knee, where both terms are equal. α: colour below the knee — 0 white, 1 pink/flicker (equal power per octave), 2 red/brown (random walk). Names: "1/f noise, knee frequency" (CMB, radiometers), "flicker noise, corner frequency" (electronics).
S = lambda f: sigma2 * (1 + (fk / f)**alpha)
S = sigma2*(1.0_dp + (fk/f)**alpha)

Why 1/f is everywhere: a sum of relaxation processes e−t/τ (Lorentzian spectra) with τ spread uniformly in log τ gives S ∝ 1/f. Averaging: the scatter of a block mean falls as 1/√T for white noise (1 → 0.25 → 0.061 for T = 1, 16, 256 s), barely for pink (0.82, 0.61), not at all for red (1.00, 0.98). Beyond 1/fk, modulate, chop or scan faster than the knee.

ESTIMATORWhittle likelihoodhover the symbols ↓
-\ln\mathcal L(\theta)=\h{sum}{\sum_j}\Big[\ln S(f_j;\theta)+\frac{\hat P_j}{S(f_j;\theta)}\Big]
Each periodogram bin is S·χ²₂/2: this is its exact log-likelihood. Least squares on log Welch is easy but log of χ²ν/ν is biased low by ≈ 1/ν. Red spectra are the norm in astrophysics. For them the decay rate of the sidelobes — not the first sidelobe — decides the window.

Prewhitening: filter with a simple A(z) (first difference, or a fitted AR model) to flatten the spectrum, estimate, then divide by |A(f)|².

The rectangular window's sidelobes fall as f⁻² in power: a spectrum ∝ f⁻⁴ falls faster, so the leakage from the strong low frequencies fills the high-frequency bins. Code lab (f⁻⁴ over a white floor, Welch L = 512): at 40 Hz the rectangular estimate is 3×10⁷ times too high, Hann within 11%. Hann's sidelobes fall as f⁻⁶.

Welch tells which frequencies are present over the whole record. When they occur is in the phases, which |X|² discards. Keep the segment periodograms instead of averaging them.

A chirp of rate ṙ is sharpest with a window of about 1/√ṙ; shorter smears frequency, longer smears time. Gabor: Δt·Δf ≥ 1/(4π).

The STFT was defined in the FFT lesson: X[m, k] = Σ x[n + mH] w[n] e−j2πkn/L. Here the point of view is estimation: each frame is a periodogram (χ²₂ scatter in every pixel) and Welch is the time average of the spectrogram.

"""
spectral_estimation.py  --  Lecture 10: a power spectrum from one finite record, with error bars.
  Model signal: 100 Hz sampling, harmonics at 7, 14, 21, 28 Hz in white + 1/f noise (knee 1 Hz).
  1. the periodogram is inconsistent: scatter of P/S does not shrink with T
  2. Welch: scatter ~ 1/sqrt(K), chi^2_nu band and its coverage
  3. a weak line next to a strong one: rectangular vs Hann
  4. coloured noise (Timmer & Koenig): generate alpha = 0, 1, 2 and measure the slope back
  5. the knee: least squares on log Welch vs Whittle on the periodogram (bias and scatter)
  6. a steep spectrum: leakage of the rectangular window, Hann, and prewhitening
Run:  python spectral_estimation.py      (about 20 s)  -> prints numbers, saves spectral_estimation.png
"""
import numpy as np
from scipy import signal as sp
from scipy.stats import chi2
from scipy.optimize import minimize
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

rng = np.random.default_rng(10)
fs = 100.0


def coloured_noise(n, S, rng):
    """Timmer & Koenig (1995): complex Gaussian Fourier coefficients with E|X|^2 ~ S(f), inverse FFT.
    S is a one-sided PSD in units^2/Hz."""
    f = np.fft.rfftfreq(n, 1 / fs)
    s = np.zeros_like(f); s[1:] = S(f[1:])
    X = np.sqrt(n * fs * s / 4) * (rng.standard_normal(f.size) + 1j * rng.standard_normal(f.size))
    X[-1] = X[-1].real * np.sqrt(2)                   # Nyquist bin real (n even)
    return np.fft.irfft(X, n)


Sknee = lambda f, s2=1e-3, fk=1.0, a=1.0: 2 * s2 * (1 + (fk / f) ** a)   # one-sided (factor 2)


def model_signal(T, rng):
    n = int(T * fs); t = np.arange(n) / fs
    x = coloured_noise(n, Sknee, rng)
    for k, A in zip((1, 2, 3, 4), (0.05, 0.03, 0.02, 0.01)):
        x += A * np.sin(2 * np.pi * 7 * k * t)
    return x


# ---------------------------------------------------------------- 1. periodogram

! welch_omp.f90  --  Lecture 10: Welch's method in Fortran with FFTW (r2c) and OpenMP
!   white Gaussian noise of variance sigma^2 (Box-Muller), periodic Hann window, 50% overlap,
!   mean removed per segment; one-sided PSD in units^2/Hz. Checks:
!     * E[P] = 2 sigma^2 / fs for white noise, whatever the window (the U normalisation)
!     * relative scatter of the estimate ~ 1/sqrt(K)
!     * same result with 1 and with several threads
! Build:  gfortran -O2 -fopenmp welch_omp.f90 -I/usr/include -lfftw3 -o welch_omp && ./welch_omp
module welch_mod
  use, intrinsic :: iso_c_binding
  use, intrinsic :: iso_fortran_env, only: dp => real64
  implicit none
  include 'fftw3.f03'
  real(dp), parameter :: pi = 4.0_dp*atan(1.0_dp)
contains
  subroutine welch(x, fs, L, P)
    real(dp), intent(in)  :: x(:), fs
    integer,  intent(in)  :: L
    real(dp), intent(out) :: P(:)                    ! L/2 + 1 bins
    real(dp), allocatable :: w(:), seg(:)
    complex(dp), allocatable :: Xk(:)
    type(c_ptr) :: plan
    real(dp) :: U
    integer :: Kseg, D, i, s, n
    D = L/2
    Kseg = (size(x) - L)/D + 1
    allocate(w(L), seg(L), Xk(L/2+1))
    w = [(0.5_dp - 0.5_dp*cos(2.0_dp*pi*n/L), n = 0, L-1)]   ! PERIODIC Hann (denominator L)
    U = sum(w**2)/L                                          ! mean power of the taper
    plan = fftw_plan_dft_r2c_1d(L, seg, Xk, ior(FFTW_ESTIMATE, FFTW_UNALIGNED))   ! once, outside
    P = 0.0_dp                                               ! must be initialised
    !$omp parallel do default(none) private(i, s, seg, Xk) shared(x, w, Kseg, D, L, plan) reduction(+:P)
    do i = 1, Kseg
       s = (i-1)*D + 1
       seg = x(s:s+L-1)
       seg = w*(seg - sum(seg)/L)                            ! remove the mean, taper
       call fftw_execute_dft_r2c(plan, seg, Xk)              ! new-array execute: thread-safe
       P = P + abs(Xk)**2
    end do
    !$omp end parallel do
    P = P/(real(Kseg, dp)*L*U*fs)
    P(2:L/2) = 2.0_dp*P(2:L/2)                               ! one-sided: double all but DC, Nyquist
    call fftw_destroy_plan(plan)
  end subroutine welch
end module welch_mod

program welch_omp
  use welch_mod
  !$ use omp_lib
  implicit none
  integer, parameter :: n = 2**22, L = 1024
  real(dp), parameter :: fs = 100.0_dp, sigma = 0.7_dp
  real(dp), allocatable :: x(:), u1(:), u2(:)
  real(dp) :: P(L/2+1), P1(L/2+1), mean_ratio, scatter
  integer :: Kseg, t0, t1, rate, nth

  allocate(x(n), u1(n/2), u2(n/2))
  call random_number(u1); call random_number(u2); u1 = 1.0_dp - u1        ! (0,1]: no log(0)
  x(1:n/2)   = sigma*sqrt(-2*log(u1))*cos(2*pi*u2)                       ! Box-Muller
  x(n/2+1:n) = sigma*sqrt(-2*log(u1))*sin(2*pi*u2)

  nth = 1
  !$ nth = omp_get_max_threads()
  !$ call omp_set_num_threads(1)
  call system_clock(t0, rate); call welch(x, fs, L, P1); call system_clock(t1)
  print '(a, f8.1, a)', '1 thread : ', 1000.0_dp*(t1-t0)/rate, ' ms'
  !$ call omp_set_num_threads(nth)
  call system_clock(t0); call welch(x, fs, L, P); call system_clock(t1)
  print '(a, i0, a, f8.1, a, es9.2)', 'threads = ', nth, ': ', 1000.0_dp*(t1-t0)/rate, &
        ' ms,  max relative difference ', maxval(abs(P - P1)/P1)

  Kseg = (n - L)/(L/2) + 1
  mean_ratio = sum(P(2:L/2))/(L/2 - 1)/(2*sigma**2/fs)
  scatter = sqrt(sum((P(2:L/2)/(2*sigma**2/fs) - mean_ratio)**2)/(L/2 - 2))
  print '(a, i0)',  'segments K = ', Kseg
  print '(a, f8.4, a)', 'mean of P / (2 sigma^2/fs)   = ', mean_ratio, '   (1 expected)'
  print '(a, f8.4, a, f8.4)', 'relative scatter of P        = ', scatter, '   1/sqrt(K) = ', 1.0_dp/sqrt(real(Kseg, dp))
end program welch_omp
